# booking-platform

Интерфейс платформы записи на услуги в Армении на моковых данных (Next.js 16, React 19, Tailwind 4).

- Правила и устройство проекта — [AGENTS.md](AGENTS.md), [CONVENTIONS.md](CONVENTIONS.md), [AREAS.md](AREAS.md).
- Запуск: `bash scripts/ensure-dev.sh` → http://localhost:3710 (демо-режим — плавающая кнопка справа внизу).
- Витрина UI: http://localhost:3710/dev/ui
