## done (все пункты «Готово, когда» проверены)

- **Нарушение F-00-116 / F-03-132** — тумблер «Рейтинг сотрудника — клиенты смогут видеть оценки» в
  `StaffCard.tsx` удалён целиком (переключатель, мутация, поле `ratingEnabled` в `domain/online.ts`). У нас
  вместо рейтинга — звёздочка (F-00-116), и она не за тумблером владельца: клиент ставит её сам после визита.
  Сама звёздочка — отдельная функция другого раздела (не online), её не строил.
- **Нарушение F-00-066/F-00-067** — на `/biz/online/settings` владелец/админ больше не может поменять
  «Сразу / С подтверждением» и «Кого принимаю» ЗА мастера: `StaffRulesForm` получил `isOwnStaff` (сравнение
  `staff.id === текущий staffId`), для чужого мастера оба поля — только просмотр (Badge/текст) с подсказкой
  «Мастер решает сам — здесь только просмотр» (добавлен ключ `settings.decidesForSelf` в en/ru/hy). Сохранение
  теперь не шлёт `confirmMode`/`accepts` в патч, если это не свой мастер. Остальные правила (окно отмены/
  переноса, депозит, отпуск) владелец по-прежнему видит и правит для любого — вне тела этой правки: спецификация
  относит их к «правилам мастера» тоже, но проверяющий отметил нарушение только по confirmMode/accepts, их и чинил.
- **F-00-145** — «Питомец» в «Для кого запись» скрыт для чисто человеческих сфер (маникюр, барбер,
  парикмахерская, косметология, стоматология, массаж): `BookingWizard.tsx` получил `sphereIds` бизнеса,
  список опций строится через новый хелпер `sphereIdsShowPet`. Для `fitness`/`carwash`/`general` и бизнесов без
  указанной сферы опция остаётся — в списке сфер нет отдельной «зоогруминг/ветеринария», решил не гадать за
  пользователя (см. assumed).
- **F-03-095** — «Депозит» переименован везде в клиентском и владельческом тексте на «Частичная предоплата
  или карта в залог» (en/ru): `settings.depositPolicy.*` (лейбл, варианты, суммы, штраф) и
  `booking.details.depositPolicy.*` (заголовки на «Вы записаны»/деталях записи, строка суммы, штраф,
  список после срока). hy для этого блока изначально не заведён (см. partial — не моя правка, пропуск старый).
- **F-03-014** — `LinkSettingsScreen.tsx` подключил `useUnsavedGuard(dirty)` (тот же паттерн, что в
  `SettingsScreen.tsx`): уход по внутренней ссылке при несохранённых правках спрашивает подтверждение,
  закрытие вкладки — системный диалог браузера.

строк спецификации, чтобы не гадать. Остальное — на следующий проход тем же или другим сборщиком раздела.
