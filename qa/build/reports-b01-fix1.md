# Раздел «Отчёты» — починка b01-fix1 (сборщик, 25.09.2026)

Пачка b01: «Каркас раздела, витрина, «Основные показатели», «Визиты», движок расчёта».
Измеритель нашёл 4 дефекта — все починены.

## Починенные дефекты

1. **F-12-015 (major)** — «Потерянные клиенты» вела в настройки `/biz/reports/churn` вместо базы клиентов;
   «Новые клиенты» и «Не новых клиентов» вели на `/biz/clients` без фильтра (все 90, не сегмент).
   Починка: `ClientsListScreen` теперь читает `?pick=` из адреса (как уже читал `?category=`) и сразу включает
   быструю подборку («Новые» / «Повторные» / «Давно не были»); плитки «Основных показателей» ведут на
   `/biz/clients?pick=new|repeat|lost&range=…`. Проверено кликом в браузере (Playwright): `?pick=lost` открывает
   базу с включённой подборкой «Давно не были 27».
   Файлы: `src/areas/reports/DashboardScreen.tsx`, `src/areas/clients/ClientsListScreen.tsx`.

2. **F-12-030 (major)** — «было → стало» в ленте активности показывалось только для смены статуса; перенос
   времени/мастера и «updated» были жёсткой строкой и вообще скрыты в UI.
   Починка: событие `moved` теперь несёт реальные старое/новое время и старого/нового мастера
   (`ActivityHistoryLine.moved`), `VisitsScreen` показывает «14:00 → 15:00, Анна → Марат»; опоздание мастера
   (`delayed`) показывает «опоздание N мин» вместо скрытой строки «updated». По пути починил ux-best-c2 №4:
   удалённый клиент в ленте — «Удалённый клиент» без имени и телефона, вместо утёкшего ФИО.
   Файлы: `src/domain/reports.ts`, `src/api/reports.ts`, `src/areas/reports/VisitsScreen.tsx`,
   `messages/{ru,en}/reports.json`.

3. **F-12-001 (major)** — в подменю «Отчёты» не было пунктов «Записи» и «События» (только 3 из 4 обязательных).
   Починка: добавлены в `src/areas/reports/nav.ts` с флагом `soon` (`/biz/reports/r/appointments`,
   `/biz/reports/r/events`) — переиспользуют уже готовый generic-экран «Скоро» из витрины «Все отчёты».
   Проверено кликом: пункты видимы в меню, ведут на карточный экран с «Этот отчёт откроется в следующей сборке».

4. **F-12-004 (minor)** — один прогон дал 17.7с (первый запрос после старта dev-сервера — прогрев компиляции
   Turbopack), остальные 7 — 1.6–7.5с. Перепроверил новым прогоном на уже тёплом сервере: /biz/reports —
   1.3–2.3с, /biz/reports/visits — 1.6–11.2с (последнее — тоже первый заход после моей правки этого файла,
   следующие заходы быстрее). Не системная деградация, а JIT-компиляция страницы при первом обращении — в коде
   раздела нечего чинить; отмечено в качестве наблюдения на будущее.
