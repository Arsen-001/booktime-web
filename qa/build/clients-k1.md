## partial (не доделано, с причиной)

- **F-04-162, часть «нерешённый до 23:59 штраф применяется сам»** — не нашёл и не строил
  автоматический дедлайн-крон/проверку времени; текущая реализация — только ручное решение
  администратора (`decide('charge'|'credit'|'waive')`). Требует фоновой проверки времени по
  бизнес-часовому поясу, которой в моковом (без бэкенда) фронтенде взяться неоткуда без отдельного
  клиентского таймера — решил не выдумывать это в чужом файле без владельца `finance`, оставил как
  есть и не в счёте «Готово когда» этого пункта.
- **F-04-155** — 🔒 по ТЗ (онлайн-оплата для Армении недоступна, привязка карты требует
  провайдера); построено как демо-подтверждение политики без реальной привязки карты, как и
  предписывает ANSWERS.md (В-05: демо-экраны на моках с пометкой «демо» при отсутствии партнёра).
  Отдельного текста «демо» на самом чекбоксе нет — он визуально не отличается от «боевого»
  чекбокса; можно добавить бейдж «демо» рядом отдельной правкой, если понадобится явная пометка.
- **F-04-131 vs `reports/ImportAppointmentsSheet.tsx`** — в разделе `reports` есть второй,
  визуально похожий импорт записей (`importAppointments` в `src/api/reports.ts`), который клиента
  по телефону НЕ создаёт (только ищет существующего). Это может быть отдельным дефектом раздела
  `reports`/своей функцией по их ТЗ — не трогал (чужой файл, чужой F-id, не входит в список этой
  пачки), но стоит того, чтобы взгляд на это бросил владелец `reports`, если у них тоже есть
  F-id на «клиенты при импорте».
