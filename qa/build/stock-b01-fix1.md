   и «Отчёты» (`/biz/stock/reports`) — теперь все 8 пунктов ТЗ на месте. Под них построены полноценные

   «истекает срок», «просрочено» и разбивка по категориям, всё на реальных данных каталога.
2. **F-08-001 · «i»/«?» у заголовка** — раньше это была только всплывающая подсказка (`Tooltip`), статья
   не открывалась. Новый `src/areas/stock/HelpArticleButton.tsx` — общая для раздела кнопка-модалка (наше
   окно, портал, без системного `title`): клик открывает статью справки по этой странице. Подключил на все

   `help.*` в `messages/{ru,en}/stock.json`.
3. **F-08-005 · «Переместить товары» недостижимо** — на `WarehousesScreen` не было входа в перемещение.
   Добавил новый `src/areas/stock/MoveGoodsModal.tsx` (склад-источник/назначение, поиск товара, количество
   с проверкой «не больше, чем на складе», комментарий) и вызов из двух мест: кнопка «Переместить товары»
   в шапке страницы и значок ⇄ в каждой строке склада (предзаполняет склад-источник). API — новая функция
   `createMoveOperation` в `src/api/stock.ts` (документ типа `move`, число товара, история). Меню «Операции
   с товарами → Перемещение» по-прежнему ведёт на «Склады» — это по ТЗ (F-08-048/059), просто там теперь
   есть чем перемещать.
4. **F-08-015 · Нет чекбоксов и меню «Действия»** — `StockCatalogScreen`: включил `selectable` у таблицы,
   добавил `BulkActionBar` («Выбрано: N») с «Быстрое управление» (новый `StockQuickEditModal` — правит цену
   продажи / критичный / желаемый остаток сразу у всех отмеченных, пустое поле = не менять) и
   «Архивировать выбранные» (подтверждение → `archiveGoods`). Новые api-функции `archiveGoods`,
   `quickUpdateGoods` в `src/api/stock.ts`.
5. **F-08-020 · Остаток в одной единице** — колонка «Остаток» в каталоге теперь показывает обе единицы,
   когда они разные: «11 флак. (110 мл)» (продажа + в скобках списание, через `unitRatio`). Чтобы это было
   видно не только в коде, поправил сид (`src/mock/slices/stock.ts`, version → 3): гель-лаки продаются

6. **F-08-046 · Фильтров 5 из 9** — `OperationsScreen`: добавил «Поиск контрагента», «Поиск клиента (имя
   или телефон)», «Услуга с расходником» (список услуг бизнеса через `useCoreList('services', …)`) и
   «Статус оплаты» (Все / Оплаченные / Неоплаченные). `OperationFilters`/`listOperations` в `api/stock.ts`

7. **F-08-047 · Не хватает 3 колонок, «Дата» и «Товар» не кликабельны** — добавил колонки «Комментарий»,
