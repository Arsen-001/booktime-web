# Отчёт сборки — schedule, пачка b01

Каркас раздела и главный экран «График работы»: таблица «Сотрудники × дни», панель настройки,
шаблоны, типы дня, режимы календаря мастера, быстрые инструменты, базовый расчёт окон.

Собрано 25.09.2026.

## Что построено

**Модель и API** (`src/domain/schedule.ts`, `src/mock/slices/schedule.ts`, `src/api/schedule.ts`):
типы дня (6 системных + «Нерабочий день»), шаблоны графика (без шаблона / по дням недели / по
сменам / свои сохранённые), таблица `getScheduleTable`, правка ячеек `setCells`/`deleteCells` с
предупреждением о задетых записях (`findAffectedBookings`), слепок/восстановление для «Отменить»
(`snapshotCells`/`restoreCells`), копирование графика (`copySchedule`, `copyFromLastWeek`), режим
календаря и отметки (`getCalendarMode`/`setCalendarMode`/marks), быстрые инструменты (`openWholeDay`,
`markCalendarRange`, `copyMarksFromLastWeek`, `setVacationUntil`), напоминание о пустой неделе
(`hasEmptyNextWeek`), хелперы для других разделов (`getDayHours`, `getWorkDays`, `getScheduledMinutes`,
`getScheduleEnd`, `setDayHours`), история правок (`getHistory`). Запись overrides всегда идёт ОДНИМ
`coreUpdate`/`coreCreate` (не create-затем-update) — поймал и починил гонку, из-за которой первая
правка графика у сотрудника без графика на миг «терялась» (см. ниже).

**Экраны**:
- `/biz/schedule` (`ScheduleScreen`) — таблица «Сотрудники × дни», навигация неделя/месяц, фильтры,
  ⚙ вид, выбор ячеек → панель, массовое удаление с подтверждением при записях, «⋯» → копирование.
- `/biz/schedule/calendar` (`CalendarScreen`) — «Мой календарь»: переключатель режима, выбор мастера
  для владельца/админа, недельный список дней с рабочим временем/перерывами, быстрые инструменты
  (открыть весь день, отметить время, как на прошлой неделе, в отпуске до…), баннер пустой недели.
- `/biz/schedule/templates` (`TemplatesScreen`) — список своих шаблонов, создание/правка/удаление.
- Компоненты: `SchedulePanel`, `ScheduleGrid`, `ScheduleFilters`(в экране), `ScheduleViewMenu`,
  `CopyScheduleModal`, `TemplateFormModal`, `DayTypeSelect`, `BreaksEditor`, `AffectedBookingsNotice`.

**Тексты**: `messages/ru/schedule.json`, `messages/en/schedule.json` заполнены полностью (армянский —
`{}`, по правилу проекта дольём отдельным проходом, ключей показывает ru-fallback).

## assumed

- Формат «часы + перерывы» дня хранится как `DayHours` ядра напрямую (несколько интервалов =
  перерывы между ними) — так же, как старый редактор Altegio (F-02-017), без отдельного поля
  «перерывы» в моей модели.
- «Тип» дня по умолчанию для НЕ отмеченных явно дат выводится из наличия часов (`work`/`null`), а не
  хранится всегда — компактнее, но значит: клетка без явной записи в срезе и без часов в шаблоне
  недели показывает «—», не «Нерабочий день».
- F-02-014 «удаление рабочих дней»: не подсвечиваю выбранные ячейки красным перед удалением отдельно
  от обычного выделения (тот же синий `ring`) — удаление всё равно требует явного клика «Удалить» и
  предупреждает о записях, но визуальной красной подсказки «сейчас удалю» нет.
- «Первичный» филиал/место работы сотрудника для записи графика — `staff.locationIds[0]`; сетевые
  сотрудники с несколькими локациями (F-02-089) получают график только по первой локации из списка —
  это дальше развивать (b02/b03 или отдельная правка), в описании ТЗ этой пачки такой кейс не входил.
- Фильтр «Должность» — одиночный выбор (Select), не множественный чек-лист; при бюджете пачки счёл
  это временным сокращением F-02-003 (см. partial).
- Правила слотов (F-02-041 и далее, доступное время) — НЕ трогал, это b02; `getFreeSlots`/
  `getNearestSlots` не менял, сигнатуры сохранены.
- Собственные типы нерабочих дней сети (F-02-011) — не мои (строит `network`); в `DayTypeSelect` есть
  задел (`DayTypeId` допускает `custom:${string}`), но список пока только системный.
