## Что построено

**Кабинет разработчика** (`/biz/integrations/developers`, свой только тому, кто завёл — ключ `ownerStaffId`,
не `businessId`):
- F-13-028 регистрация одной формой (компания, назначение, контакты, свой Partner Bearer).
- F-13-029 `/developers/help` — ссылки на гайд размещения и на документацию API.
- F-13-032 «Мои приложения» со статусами не опубликовано/на модерации/опубликовано/отклонено.
- F-13-030/031 `/developers/apps/new` — название → латинский ID (правится только сейчас), категория,
  «Непубличное приложение».
- Карточка приложения `/developers/apps/[devAppId]` — вкладки «Общая информация» (F-13-033: ссылка на
  приложение и на запрос отзыва; F-13-046: «Проверить в своём филиале»), «О приложении» (F-13-034: галерея
  до 5, видео, описание/возможности/FAQ **отдельно на ru/en/hy** — наше решение F-00-172), «Настройки для
  разработки» (F-13-035: Registration Redirect Url обязателен для модерации, callback, режимы; F-13-066:
  адрес вебхука непубличного приложения), «Доступ к API» (F-13-036/F-13-060: User ID → User token, права).
- «Отправить на модерацию» блокируется без Registration Redirect Url и описания; демо-кнопки «одобрить/
  отклонить» стоят вместо полноценной очереди модерации (та — в пачке b05, не в счёте b02).

**API и вебхуки** (`/biz/integrations/api`, вкладки вместо прежней заглушки):
- Обзор (F-13-051) — что даёт API, базовый адрес, «видит только данные своего бизнеса».
- Ключи и токены (F-13-052/053/055/059) — партнёрский Bearer-ключ (выпустить → показать один раз в модалке →
  дальше маска + «Отозвать»), User token (список, выпуск, отзыв), ссылка «Разработчик для вашего салона» →
  `/biz/staff`, справочная строка про платность системного пользователя.
- Идентификаторы (F-13-056) — ID бизнеса/филиалов/сотрудников/услуг с копированием; демо-поле проверяет
  правило ключа (латиница/цифры/`.`/`-`/`_`) вживую.
- Вебхуки (F-13-062…065, 068…070) — включатель, список адресов (у демо-бизнеса — «прежний» адрес,
  помеченный и работающий), 16 галочек сущностей, пример тела события, журнал доставок (сидированные
  события), «Добавить» объясняет блокировку с 12 сентября и ведёт в создание непубличного приложения,
  заметки про вебхуки партнёров, обратные вызовы платёжных систем, предупреждение перед импортом Excel.
- MCP и ИИ (F-13-071/072) — адрес MCP-сервера, инструкция подключения (Claude/ChatGPT/Cursor), токен
  ИИ-ассистента с правами «только чтение»/«чтение и запись», выпуск/отзыв.
- Документация (F-13-054/058/061) — моковый справочник по группам методов, порядок вызовов для своего
  виджета записи, флаги уведомлений при записи через API, адрес поддержки.
