# online · b01 «Каркас раздела: ссылки на запись и путь клиента по ссылке» — отчёт сборщика

Дата: 2026-09-25. Маршруты: `/biz/online`, `/biz/online/links/[linkId]`, `/b/[slug]`,
`/b/[slug]/f/[formId]`, `/b/[slug]/book`, `/b/[slug]/booking/[bookingId]`, `/b/[slug]/about`.
Файлы: `src/domain/online.ts`, `src/mock/slices/online.ts`, `src/api/online.ts`,
`src/areas/online/links/**`, `src/areas/online/booking/**`, `src/areas/online/public/**`,
`src/areas/online/extensions/BookingWindow.tsx`, `messages/{ru,en}/online.json`,
`qa/scenarios/online-b01-*.json`.

Построены: данные раздела (тип ссылки, метаданные онлайн-записи), список ссылок с созданием/удалением/
основной/предпросмотром/копированием, каркас экрана «Настроить ссылку», и сквозной путь клиента —
услуги → специалист → дата/время → детали → «Записаться» → «Вы записаны» (доступна по хэшу без
входа), плюс страница «О компании». Всё поверх `useApiQuery`/`useApiMutation`, записи и ссылки
переживают перезагрузку (мок-база в localStorage). Правило видимости мастера онлайн и проверка
занятости окна прямо перед созданием — в `src/api/online.ts`.

## assumed — додумано за источник

- «Сделать ссылку основной» — реализовано только как «назначить другую основной» (снять флажок «в
  никуда» с бизнеса нельзя): у Altegio это не описано, а наше `F-03-004` требует, чтобы локация
  никогда не оставалась без основной ссылки.
- Видимость мастера онлайн (`isStaffOnlineVisible`) считается по уже существующим полям ядра
  (`calendarVisibility !== 'mine'` + активен + график + активная онлайн-услуга), а не по отдельному
  флажку «онлайн-запись включена» — такого поля в `Staff` нет; заявка на него — в `qa/requests/online.md`.
- Источник записи `'link'` используется, когда клиент пришёл по `/b/<slug>/f/<formId>` (через
  конкретную неосновную форму), `'widget'` — когда по основному адресу `/b/<slug>` или `/book` без
  формы; в источниках Altegio деление между «link»/«widget» тоже не описано однозначно.
- Хэш доступа к записи без входа — случайная строка (`newId` + `Math.random`), не криптографическая
  подпись; для мок-демо этого достаточно, для настоящего бэкенда потребуется HMAC.
- «Добавить в календарь» отдаёт `.ics` через `data:` URI и `<a download>` — в реальном браузере
  работает как обычное скачивание/открытие в приложении календаря; QR/промо Altegio.me с этого экрана
  сознательно не делал (F-00-006 — только этот бизнес, без рекламы платформы).
