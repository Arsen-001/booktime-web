# clients — b03-fix1 (25.09.2026)

Починка дефектов из пачки b03 «Работа с клиентом» (найдены измерителем m0).

## Дефекты — что сделано

### 1. F-00-129 / F-04-039 — два одинаковых тоста «Визит добавлен» (major) — ✅ исправлено

Причина: `AddVisitSheet` сам показывает `toast.success(t('history.addVisitSheet.saved'))` при
успешном сохранении (`src/areas/clients/components/AddVisitSheet.tsx`), а вызывающий экран
`ClientsListScreen` (список клиентов, когда визит добавляют без открытой карточки) в своём
`onSaved` показывал **второй** такой же тост — вот и дубль на один клик.

Правка: `src/areas/clients/ClientsListScreen.tsx` — из `onSaved` убран лишний
`toast.success(t('history.addVisitSheet.saved'))`, оставлен только `rowsQ.refetch()`. Тост теперь
один — тот, что показывает сама шторка. Проверено сценарием `qa/scenarios/clients-b03-add-visit-
newclient.json` (добавление визита новому клиенту со списка) — на снимке `after-save-new` один
тост «Визит добавлен».

Карточка клиента (`ClientCardScreen.onSaved`) дубля не имела — там `onSaved` только рефетчит,
тост не дублирует.

### 2. F-00-129 — подсказка «+ Добавить «…»» перекрывает кнопку «Добавить услугу» без разделения (minor) — ✅ исправлено (частично, в рамках своих файлов)

Причина: выпадающий список `Combobox` (F-00-129, автокомплит услуги) — общий компонент
`src/ui/Combobox.tsx`, шириной равен своей колонке (уже с учётом полей суммы и корзины рядом), и
открываясь вниз, наезжает на кнопку «Добавить услугу» без видимого зазора/тени между ними — на
глаз выглядит как слипшиеся элементы.

Правка в своих файлах: `src/areas/clients/components/AddVisitSheet.tsx` — кнопка «Добавить услугу»
обёрнута в блок с верхней границей и отступом (`mt-1 border-t border-border pt-3`), так что между
строками услуг и кнопкой всегда есть чёткая видимая граница независимо от того, открыт автокомплит
или нет. Сам `Combobox` (`src/ui/Combobox.tsx`) — общий файл, его не трогал.

### 3. F-04-075 / F-04-077 / F-04-079 — на телефоне подписи вкладок карточки клиента обрезаны под стрелками ‹› (minor) — ⏳ частично, корень — общий `src/ui/Tabs.tsx`

Причина подтверждена по снимкам (`qa/shots/clients-b03-m0/clients-b03-card-tabs/*`): круглые
кнопки-стрелки `Tabs` (`size-10`, `absolute left-0/right-0`, `bg-surface`) перекрывают часть
подписи соседней вкладки без затухания/зазора — обрыв текста ровно на границе круга («иента»,
«Стати»). Карточка клиента — 5 своих вкладок + до 5 вкладов хоста `clientCard`, на 390px никогда не
поместятся целиком, поэтому скролл и стрелки — это ожидаемо; проблема именно в резкой обрезке без
разделения. Файл `src/ui/Tabs.tsx` — общий (фундамент), сам не правил.

Сделал в своих файлах: `src/areas/clients/ClientCardScreen.tsx` — каждой из 5 вкладок карточки
клиента добавлена иконка (`User`, `History`, `BarChart3`, `Phone`, `FolderOpen`, всё через
поддерживаемое поле `TabItem.icon`, без правки `Tabs.tsx`). Иконка ближе к центру вкладки, поэтому
даже когда подпись обрезана стрелкой, иконка соседней/активной вкладки видна целиком — вкладку
можно опознать по значку, а не только по обрывку текста. Проверено сценарием
`qa/scenarios/clients-b03-card-tabs.json` — на снимке `stats-tab` иконки телефона/графика видны
полностью рядом с обрезанным текстом.

Полностью убрать наезд (без обрезки текста вообще) можно только правкой общего `Tabs.tsx` —
запрос оставлен в `qa/requests/clients.md` (раздел «b03-fix1 · `src/ui/Tabs.tsx`: стрелки-скроллеры
перекрывают текст…») с тремя вариантами решения на выбор хозяина фундамента.
