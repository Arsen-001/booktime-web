# platform — правка g1-1-fix1 (дефекты измерителя после g1-1)

Три дефекта из списка измерителя — все исправлены.

## done

- **F-00-169** — «Без проверки» показывала 3 материала с `source: 'user'` («Загрузил бизнес»), хотя
  правило гласит: без очереди проверки проходят только шаблон/визит/reuse. Причина была в
  `src/mock/slices/platform.ts`: `status` и `source` в генераторе `moderationItems` считались двумя
  независимыми формулами по разным индексам (`statuses[(bi*3+k) % 7]` и
  `kind === 'story' && k === 2 ? 'template' : 'user'`), и при рассинхроне статус мог выйти `'auto'`,
  а источник — остаться `'user'`. Исправлено: `source` теперь считается ОТ `status` — когда
  `status === 'auto'`, источник всегда `'template'` или `'reuse'` (никогда `'user'`); для остальных
  статусов формула источника осталась прежней. Проверено прогоном браузера (Playwright) по вкладке
  «Без проверки»: все 3 карточки показывают «Из шаблона»/«Уже одобренное», ни одной «Загрузил бизнес».
- **F-00-183** — В карточке бизнеса (вкладка «Сведения») подпись поля источника была жёстко взята из
  `t('businesses.source.self')` вместо `t('businesses.sourceLabel')` — из-за этого у ЛЮБОГО бизнеса
  строка начиналась с «Сам зарегистрировался: …», включая подключённых на визите (противоречие самому
  себе). Исправлено в `src/areas/platform/BusinessesScreen.tsx:112` — теперь подпись
  `t('businesses.sourceLabel')` («Источник»), значение — фактический `r.meta.source`. Проверено на
  Kaytsak Barbershop: «Источник: Подключили на визите» — согласованно.
- **F-00-177** — На телефоне (390×844) всплывающий тост «Сегодня перезвонить: N» на миг перекрывал
  поля следующей карточки списка визитов. У экрана и так уже есть постоянный баннер с тем же текстом
  (виден всё время, пока есть звонки на сегодня) — транзитный тост дублировал его и создавал наложение.
  Убрал вызов `toast.info(...)` в `useEffect` в `src/areas/platform/VisitsScreen.tsx` (баннер остаётся
  единственным источником этого напоминания), заодно убрал более ненужные импорты `useEffect`/`useRef`.
  Проверено скриншотом на телефоне (platform-nails, ru, phone) — плавающего тоста больше нет, карточки
  визитов не перекрыты.
