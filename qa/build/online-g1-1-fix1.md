### F-03-047 (major) · Онлайн-запись из приложения для бизнеса на телефоне: честное подтверждение

У нас одно приложение бизнеса — отзывчивый веб, не два разных клиента (веб + мобильное приложение),
поэтому «честно указывает, что только на десктопе» переосмыслил как явное подтверждение, что раздел
и правда работает с телефона без ограничений. Добавил баннер на `/biz/online` (data-f="F-03-047") с
текстом «Раздел «Онлайн-запись» работает так же в браузере на телефоне: создать ссылку, изменить шаги
и получить код кнопки для сайта можно без компьютера — отдельного мобильного приложения для бизнеса у
нас нет». Список: создание ссылки, шаги (drag теперь touch-friendly), код кнопки — все три уже
работают на 390px (замер `qa/measure/online/g1-1-fix1-report.json`: 0 вылетов, 0 целей < 40px на
телефоне).

### F-03-086 (block) · «Встать в лист ожидания» на пустом дне виджета

⭐ По нашему решению (F-00-101/102, в отличие от Altegio, где это закрыто) клиент сам встаёт в лист
ожидания. Добавил:
- домен: `WaitlistRequest` (`src/domain/online.ts`);
- срез: `waitlistRequests: WaitlistRequest[]` (`src/mock/slices/online.ts`, version 9 — старый
  локальный кеш браузера пересоздастся из seed);
- API: `joinOnlineWaitlist`, `findWaitlistEntry` (`src/api/online.ts`) — проверка имени и телефона,
  запись сохраняется в срез (переживает перезагрузку);
- UI: `WaitlistJoinButton` в `TimeStep` (`src/areas/online/booking/BookingWizard.tsx`) — кнопка на
  пустом дне открывает модалку (имя, телефон, необязательный комментарий), после отправки — тост и
  постоянная зелёная строка «Вы в листе ожидания на этот день».

Проверено полным сценарием на живых данных (Педикюр классический / Мариам Петросян / воскресенье без
графика в декабре 2026): пустой день → «Встать в лист ожидания» → форма → отправка → тост «Готово —
сообщим, когда появится окно» → строка подтверждения остаётся видна
(`qa/shots/online-fix1-scn15/…waitlist-joined.png`).

Сам лист ожидания (кто видит очередь, пуш при освобождении окна) строит раздел `resources`
(`/biz/waitlist`) — у него пока нет приёмника заявок из виджета. Заявка временно живёт в срезе
`online`; просьба переключить приём — в `qa/requests/online.md`. Это ограничение честно указано в
partial ниже — «Готово когда» бьёт на две части: 1:1-часть (администратор ведёт лист ожидания в
журнале) строит `resources`, наша часть (клиент сам встаёт из виджета) — готова здесь.
