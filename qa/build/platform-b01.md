**Экраны и функции**
- `/platform` — плитки-счётчики (ждут проверки, перезвонить сегодня, открытые обращения, подключено за
  неделю, спрос без предложения) со ссылками, гистограмма записей через приложение за 7 дней (из
  `listBookings` ядра, `source === 'app'`), прогресс волн.
- `/platform/moderation` — очередь (F-00-179), ручная проверка всего нового (F-00-168): вкладки
  «На проверке / Одобрено / Отклонено / Без проверки / Причины отказа», фильтр по виду, карточка
  материала в Sheet с «Одобрить» / «Отклонить» (F-00-170: справочник причин, возврат монет за платное —
  видно в истории и в срезе `coinEntries`), вкладка «Без проверки» показывает `auto`-материалы
  (F-00-169), пометка «снято на визите» у фото с подключения (F-00-171).
- `/platform/connect` — список черновиков + мастер на 7 шагов (F-00-176): название/сфера → «Я на месте»
  (кнопка без карт, координаты моковые) → фото (ImageUpload, сразу approved) → приглашения мастеров
  (+374) → услуги из шаблона сферы (`SPHERE_SERVICE_TEMPLATES`) → часы работы (переключение по дням) →
  промокод. «Готово» создаёт бизнес/филиал/мастеров/услуги через `api/core`, 30 бесплатных дней в
  `bizMeta`, если пришли с визита — связывает и переводит его в «подключён». Черновик — в своём срезе,
  сохраняется на каждый шаг, открывается заново по `?draft=<id>` (переживает перезагрузку).
- `/platform/visits` — список, счётчики подключён/думает/отказ, фильтры статус+район, Sheet
  создания/правки, плашка-напоминание и счётчик «перезвонить сегодня», кнопка «Подключить сейчас» ведёт
  в мастер с привязкой к визиту (F-00-177).
- `/platform/promocodes` — список с статусами (new/issued/used/expired/revoked, считаются от дат),
  создание (ступени 1/3/6/12 мес либо бесплатные дни, личный код на салон, срок), отзыв, отдельная форма
  «Выдать бесплатный месяц» любому бизнесу (F-00-178, смежные F-00-019/020).
- `/platform/support` — одна очередь из всех каналов и от business/client, фильтры статус+канал,
  переписка в Sheet, ответ/закрытие/переоткрытие (F-00-182).
- `/platform/demand` — таблица запросов по районам (люди/запросы/есть ли предложение в районе и
  городе) за неделю/прошлую неделю/месяц, блок «сферы без предложения», блок «Первые» (единственный
  бизнес сферы в районе → кнопка «Наградить», бесплатные дни + монеты) (F-00-180, F-00-181), генератор
  картинки 1080×1080 / 1080×1920 на canvas с реальными цифрами и скачиванием (F-00-202) — сделан как
  раздел на той же странице, а не отдельный маршрут `/platform/demand/image` (упрощение ради времени).
- `/platform/ads` — вкладки «Баннеры / Поставщики / Сторис»: создание объявления (цель по сферам/
  районам/размеру/звёздам, товары-ключи для склада), карточка с отчётом «только показы и нажатия»
  (F-00-166), пауза/возобновление; текст «баннер только через нас» и «поставщик без аккаунта» на экране
  (F-00-163, F-00-164, F-00-165 — офер склада как отдельное место в том же поставщическом объявлении);
  вкладка «Сторис» — настройки (число мест 5/6/10, зона показа, цена, наценки, горизонт продажи) и доска
  занятости по дням (F-00-160). Отдельная страница `/platform/ads/new`/`/platform/ads/stories` из плана
  не заводилась — сделано формами/вкладками на одной странице (упрощение).
- `/platform/businesses` — список бизнесов с источником (сам/визит) и «бесплатно до», карточка: вкладка
  «Копии» (снять копию вручную, список с составом), вкладка «Выгрузка» (CSV клиентов/записей, скачивание
  через Blob), «отметить ушёл, данные выданы», блок-напоминание «что только через поддержку» (F-00-183).
- `/platform/plan` — вкладки «Волна 1/2/3» (список функций волны, отметка «не начато / строится /
  прошла „Готово, когда“» по клику), «Окупаемость» (калькулятор с пометкой «оценка», сохраняется),
  «До постройки» (6 пунктов, решение/заметка/статус на каждый), «Имя и домен» (5 кандидатов, написание на
  3 языках, статус домена, кнопка «выбрать») (F-00-203…208).
- Справочник причин отказа встроен вкладкой в `/platform/moderation` вместо отдельного маршрута
  `/platform/moderation/reasons` (упрощение).

Данные форм сохраняются в моковый срез через `api/platform.ts` и переживают перезагрузку страницы
(включая черновик подключения). У всех списков — скелетон при загрузке, `EmptyState`, `ErrorState` с
повтором (проверено `?api=error`, скриншот приложен — очередь модерации корректно показывает «Не удалось
загрузить» вместо падения). Мутации крутят `loading` на кнопке и показывают toast об ошибке при провале.

- Координаты «Я на месте» — случайная точка внутри Еревана (координат клиента браузера в моковой среде
  нет; в ТЗ и так «без встроенных карт»).

  бюджет времени; данные настоящие (`listBookings` ядра).
- «Подключено за неделю» на Обзоре считает визиты со статусом «подключён», обновлённые за 7 дней (в
  плане это не было явно определено численно).
- Текст сторис-картинки на canvas зашит в двух языках через отдельный переведённый ключ
  (`demand.imagePeopleLabel`), не общий шаблон ICU — картинка на 3 языка (ru/hy/en) из ТЗ не делал
  из-за `hy` не переведён (см. выше); строю ru/en, армянский добавится вместе с общим переводом раздела.
- Причины отказа — свой мини-редактор (добавление) без удаления/переупорядочивания (в ТЗ не сказано,
  что нужно).
- `AdSize`/цели рекламы заполняются в форме, но реального ограничения показа по «звёздам мастера»
  (`minStars`) в `getActiveAds` нет отдельной проверки по рейтингу — рейтинги мастеров не наш срез,
  оставил поле в цели для будущего использования принимающим экраном (client/online), сообщил бы в
  просьбе, если бы кто-то уже вызывал `getActiveAds` — пока никто не вызывает.
