## Дефект

**F-05-076 (major).** Демо-кнопка «Демо: подтвердить ближайшую запись» в карточке подключённого
партнёрского бота (например, Flowsell) всегда падала необработанной ошибкой `ApiError: invalid_transition`
— тост не показывался, пользователь не получал обратной связи.

**Причина:** `simulatePartnerConfirmBooking` (`src/api/notify.ts:647`) звала
`changeBookingStatus(id, 'client_confirmed', 'system')`, а `SYSTEM_TRANSITIONS` в
`src/domain/rules/booking-status.ts` вообще не содержит перехода `awaiting_confirmation → client_confirmed`
ни для одного актёра — переход был запрещён правилами домена в 100% случаев, то есть демо гарантированно
падало именно в сценарии, который должно было показать.

**Правка:** актёр сменён с `'system'` на `'business'`. По «Готово, когда» F-05-076 внешнее партнёрское
приложение работает через API Altegio с теми же правами, что сотрудник в кабинете (`canTransition`:
`actor === 'business'` разрешает любой переход, кроме входа в `awaiting_prepayment`) — `'system'` в этом
домене означает только внутреннюю автоматику самого Altegio (истёк срок предоплаты) и к внешним ботам
отношения не имеет. Добавлен комментарий, объясняющий выбор актёра, чтобы решение не откатили обратно.

Файл: `src/api/notify.ts:642-668` (комментарий + `simulatePartnerConfirmBooking`).
