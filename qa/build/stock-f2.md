## Сделано

### F-08-149 — построено в своих путях, `data-f` поставлен

- **Решение** (❓ ТЗ не записывает состав прав «Товары» по шаблонам, кроме владельца): добавлено
  `STOCK_ROLE_TEMPLATE_IDS` + `stockPermissionsForRoleTemplate()` в `src/domain/stock.ts` — 8 составов
  (специалист = сам приход/списание без себестоимости и инвентаризации, по примеру из справки 1417;
  колл-центр/только просмотр = минимум; бухгалтер = только цифры и выгрузка; менеджер/владелец = полный
  доступ; администратор = операции без удаления и без правки каталога).
- **API** (`src/api/stock.ts`): `applyStockRoleTemplate()` (ставит состав шаблона), `copyStockPermissions()`
  («скопировать права» одной кнопкой), `listPermissionHistory()` — новый `HistoryEntityType: 'permissions'`;
  `setStockPermissions()` теперь тоже пишет строку в историю при каждой ручной правке.
- **Экран**: `/biz/stock/settings/access` (`StockStaffPermissionsScreen.tsx`, тот же временный экран из
  b04-fix1, пока нет пары `staffCard`/`stock`) — в модалке добавлены: выбор и применение шаблона роли,
  «Скопировать права у сотрудника» с поиском по коллегам, кнопка/окно «История изменений прав».
- Все 4 пункта «Готово, когда» закрыты в пределах путей `stock`; чего не хватает от `staff` (сам экран на
  карточке сотрудника) — записано в `qa/requests/stock.md`.
- `data-f="F-08-149"` — на корневом `div` формы прав в `StockStaffPermissionsScreen.tsx`.

### F-08-151 — построено в своих путях, `data-f` поставлен

- **Решение** (⚠️/❓ входит ли продажа без визита в «Продано»): да, по прогону из ТЗ (CYCLE-09/
  CYCLE-REPORT) — зафиксировано в новой функции `getClientPurchaseSummary()` (`src/api/stock.ts`):
  считает `totalSold`/`totalPaid` по ВСЕМ продажам клиента (включая без визита), `visitCount` — только
  по различным `bookingId`. Явно НЕ трогал `listProductSales` (F-08-137) — та функция для приложения
  клиента сознательно фильтрует по визиту (1545), это другая, более узкая задача.
- **API**: `getClientPurchaseSummary(businessId, clientId)`, `searchClientsForPurchases(businessId, query)`
  (поиск по core-клиентам через `readCore().clients`).
- **Экран**: новый `/biz/stock/clients` (`ClientPurchasesScreen.tsx`) — поиск клиента → карточка с
  «Продано / Оплачено / Баланс» и историей покупок товара (метки «Без визита», «Не оплачено»); ссылка
  добавлена в `/biz/stock/settings`. Состояния загрузки/пусто/поиск без результата/ошибка — все три.
- Из «Готово, когда»: 1-й пункт (видно в сумме и истории) закрыт нашим экраном; 2-й (решение про продажу
  без визита) решён и закодирован; 3-й (из поиска журнала понятно, что смотреть в карточке) — не наш путь,
  запрос оставлен `journal`/`clients`.
