## partial — не доделано и почему

- **F-15-027**: нет поля «ответственный» — платформенный `ConnectResult` его не отдаёт (запрос отправлен,
  `qa/requests/settings.md`). Статус подключения показан по прокси-признаку, не по прямому флагу «подключено
  на визите».
- **F-15-043**: уровни поддержки помечены владельцем как «не решено» (❓) — текст на экране это отражает,
  значит по документу это не пробел, а осознанное состояние; оставляю в partial для прозрачности, т.к. само
  «Готово, когда» не может быть проверено действием без решения владельца.
- **F-00-153**: «Скоро» строится из ЗАЯВОК ЭТОГО бизнеса (наш срез), а не из агрегированного спроса всей
  платформы — честное приближение, описано в просьбе к platform.
