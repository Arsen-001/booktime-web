# Раздел client — срез g1-1

Работал в режиме ограниченного бюджета: взял из списка пропусков несколько задач,
которые можно было проверить и исправить надёжно за один проход, и довёл их до
конца с проверкой (tsc/eslint по своим путям + measure.mjs + снимок глазами).
Остальное из списка — НЕ трогал, честно в `partial`, чтобы не выдавать
непроверенное за готовое.

## Сделано (проверено tsc + eslint + measure.mjs, 0 ошибок/предупреждений на затронутых страницах)

1. **F-14-148 / F-14-149 / F-14-152 — картинки для своего приложения никогда не
   проходили проверку.** Корень: `ImageUpload.tsx` ужимал файл до `MAX_SIDE=800`
   ещё ДО проверки размера, а `BrandedAppScreen.tsx` (`MaterialImage`) сверял
   требуемые 2208×1024 с уже сжатым превью — такое условие не выполнялось
   никогда. Исправил `toDataUrl()` — она теперь возвращает и размер ИСХОДНОГО
   файла; добавил `ImageUpload` пропсы `minWidth`/`minHeight`, проверка идёт до
   сжатия. `BrandedAppScreen.tsx` больше не делает свою (сломанную) проверку —
   передаёт `minWidth={width*0.9}`/`minHeight={height*0.9}` в `ImageUpload`.
   Добавил ключ `upload.tooSmall` в `messages/{en,ru,hy}/ui.json`.
2. **F-14-034 / F-00-155 — своя история 1080×1920 отклонялась.** Та же
   первопричина (сравнение со сжатым превью). `StoriesGeneratorScreen.tsx`
   теперь тоже передаёт `minWidth`/`minHeight` в `ImageUpload` вместо
   самодеятельной проверки на `<img>`.
3. **F-14-007 — у поля кода не было `autoComplete="one-time-code"`.** Добавил в
   `LoginScreen.tsx:148` и `BookScreen.tsx:713`.
4. **Нарушение решений — имя Altegio в текстах для людей.** Убрал упоминание
   Altegio из `apps.branded.decisionPending`, `apps.branded.priceNotApproved`,
   `apps.branded.accessMethodTitle` (en+ru) — смысл сохранён (демо-заявка / демо-
   цена / «как передать доступ»), бренд конкурента больше не виден игроку.
5. **Нарушение решений — pushVsSmsHint обещал платный SMS/WhatsApp-канал.**
   Против решения «пуш — единственный канал» (F-14-159/F-00-120). Переписал
   `apps.branded.pushVsSmsHint` (en+ru): пуш — единственный канал, без платного
   запасного.
6. **Чужое имя продукта «LuckyBooking»** в `notifications.senderFallback`
   (en+ru, `messages/*/client.json`) и в SVG-подписи сторис
   (`src/domain/client.ts:465`) — заменил на нейтральное «Booking».

## Не сделано — осталось в `partial`

Весь остальной список пропусков (30+ пунктов: оплата/списания по хэшу,
приватные поля Staff/Business наружу, bookAppointment → placeBooking ядра,
предоплата/отмена/перенос по правилам мастера, лист ожидания,
режим/часы звонков, видимость «По ссылке»/«Только мои клиенты», callback-
заявки, поиск по названию, «сообщить когда появится», переключатель «Я
клиент/Мой бизнес», абонементы/сертификаты через заявку, лента уведомлений,
«В приложении с …», нарушения по отзывам о месте/модерации/workplace/замороженному
бизнесу и т.д.) — НЕ начинал. Это ядерные (`domain/`, серверные по духу)
изменения с завязкой на правила мастера, статус модерации, приватность полей —
каждое требует чтения своего блока ТЗ целиком и отдельной проверки на моках
(перезагрузка, права по персонам), что не укладывается в отведённый бюджет
одного экономного прохода. Ничего из уже построенного не трогал и не ломал.
