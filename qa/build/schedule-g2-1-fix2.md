## Дефекты (4)

### F-02-035 (block) — «ни одного UI-экрана»
Построила рабочий путь в своих путях (раньше функция существовала только в комментарии к API и в
journal под её собственным F-id `F-01-020`, которого `fids.mjs`/`grep` не считают за `F-02-035`):

- `src/areas/schedule/CalendarScreen.tsx` — «убрать с одного дня»: переключатель типа дня → «Нерабочий
  день» теперь вызывает `deleteCells()` вместо голого `setCells()`. Достижимо с `/biz/schedule` (таблица
  → «Переход к сотруднику» → «Неделя») без всякой зависимости от journal/staff.
- `src/areas/schedule/components/SchedulePanel.tsx` — «поставить график на период»: кнопка сохранения
  шаблона (по дням недели / по сменам / готовый шаблон — уже была под F-02-032/033/034) дополнительно
  помечена `F-02-035`.
- Оба места помечены `data-f`, проверены живым сценарием Playwright (см. «Проверка» ниже).

### F-02-027 (major) — снимала весь график вперёд, а не один день; недостижимо
Причина обеих претензий одна: кнопка «Убрать из графика» в `StaffCard.tsx` — это на самом деле
**F-02-020** («Убрать из графика» целиком, по коду и по ТЗ так и задумано — 03 §Карточка, справка 1500),
а не F-02-027. Для F-02-027 (снять ОДИН день) в коде до этой пачки не было ни одной точки входа со своим
тегом — тем же путём (`CalendarScreen.tsx`, описано выше) закрыла и её:

- переключатель дня на «Нерабочий день» через `deleteCells()` — при записях в этот день бросает
  `schedule_has_bookings`, день НЕ снимается, под датой сразу показывается `AffectedBookingsNotice` с
  причиной («администратор видит почему» — второй пункт «Готово, когда»);
- без записей — снимается сразу с тостом «Отменить» 5 секунд (F-00-061, тот же паттерн, что у
  `StaffCard`'овского F-02-020);
- достижимо с `/biz/schedule` (своя таблица, свой путь), не зависит от того, что `/biz/staff` ещё
  `EmptyState`, и от того, есть ли в journal ссылка на карточку сотрудника.

Кнопку `StaffCard.tsx` не трогала — она правильно делает F-02-020 (снятие целиком, есть в ТЗ отдельным
пунктом 03 §Карточка), просто её раньше путали с F-02-027.

### F-00-052 (major) — не проверено живым действием
Код не менялся — он в `src/areas/platform/connect/StepHours.tsx`, чужой путь (раздел `platform`), править
не имею права (правило 1). Вместо повторного «код совпадает» — прошла сценарий вживую через дев-сервер:
`/platform/connect` → «Начать подключение» → «Кто это: Частный мастер» → … → шаг «Часы» → поле «Как ведёт
календарь\*» обязательное, клик «Далее» без выбора не пускает дальше и показывает ошибку. Для «Салон» поле
не появляется вовсе (сохраняется `'free'`). Оба пункта «Готово, когда» подтверждены на реальном прогоне
(не только чтением кода) — скриншоты `qa/shots/connect-probe5/`. Тег `data-f="F-00-052"` по-прежнему
отсутствует (чужой файл) — попросила в `qa/requests/schedule.md` искать по тексту поля, а не только
`fids.mjs`.

### F-02-027 (minor) — кнопка/блок не помечены `data-f`
Закрыто тем же фиксом: блок с переключателем типа дня в `CalendarScreen.tsx` помечен
`data-f="F-02-027 F-02-035"`, `fids.mjs --area schedule` больше не числит `F-02-027` в непомеченных.

  переиспользование уже проверенной функции `src/api/schedule.ts`, только новая точка входа в своих путях.
