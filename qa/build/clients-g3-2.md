### F-04-100 · Разовое сообщение клиенту из окна записи
Плитка «Сообщение клиенту» в `extensions/BookingWindow.tsx` (`data-f="F-04-100"`): текст +
`SegmentedControl` «Пуш / WhatsApp» (по решению F-00-120/121 — платных SMS клиенту нет). Пуш
доступен только если у клиента есть приложение (`row.appUserId`); без приложения канал сам
переключается на WhatsApp и открывает `wa.me/<телефон>` с готовым текстом (WhatsApp самого мастера,
ничего не уходит от нас). Отправка пишется в `messageLog` (`source: 'bookingWindow'`,
`clientId`) — новая функция `api/clients/bulk.ts: sendBookingWindowMessage`. Видно в двух местах
истории:
- в карточке клиента, вкладка «Сообщения и звонки» (`CallsTab.tsx`) — новый блок над звонками,
  через `listClientMessages(clientId)`;
- в общем отчёте раздела (`CrmSummaryScreen` → `MessageLogCard.tsx`) — с пометкой «из окна записи»
  вместо числа адресатов, и с иконкой WhatsApp.

Второй пункт «Готово, когда» (своё напоминание и свой срок инвайта на повторный визит для одной
записи) не сделан — это поля самой записи (`BookingDraft`), которых `journal` не завёл; запрос
подан (`qa/requests/clients.md`, F-04-100).

### F-04-099 · Поиск клиента по лояльности в окне записи
Настоящая настройка «Настройки → Цифровой журнал → Работа с клиентами» не построена разделом
`journal` — как и в прошлой пачке с F-04-046, временный переключатель живёт в `SettingsHub.tsx`
раздела `clients` (`getShowLoyaltySearchInBookingWindow`/`setShowLoyaltySearchInBookingWindow`,
по умолчанию выключен). Сама функция — в `extensions/BookingWindow.tsx` (`data-f="F-04-099"`):
пока в записи `draft.clientId` пуст и настройка включена, вместо мини-карточки показывается поле
поиска по номеру абонемента/сертификата; найденного клиента подставляет в запись через
`onDraftChange({ clientId })` (контракт хоста уже это позволял). Добавил недостающее поле `code`
(номер) в черновые типы `Certificate`/`Subscription` раздела `clients` (`program.ts`) и сид
(`mock/slices/clients.ts`), новая функция поиска — `api/clients/catalog.ts: findClientByLoyaltyCode`.
«Готово, когда»: клиент находится в записи по номеру абонемента — проверено вручную на
`/dev/ext/bookingWindow/clients` (демо-клиент `cl_078`, поиск по коду его подписки находит и
подставляет клиента; неверный код показывает «не найдено»).
