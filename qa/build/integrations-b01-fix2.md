# integrations — b01, починка после измерителя (fix2), 2026-09-25

Пачка b01 «Каркас раздела и главный экран». Разбирал 3 дефекта из отчёта измерителя (все — из карточки
задания, не новые находки).

## Что починено

### F-13-007 (major) — пустая локация не получала встроенное «Наше приложение для клиентов»
`seed()` в `src/mock/slices/integrations.ts` сидировал builtin-install только для первых
`SEEDED_BUSINESSES = 6` бизнесов. Разделил цикл: builtin-инсталл (клиентское приложение + «Картинка
свободных окон») теперь сидируется для **всех** `core.businesses` с филиалами, а демонстрационные
установки в разных статусах (app1/app2/app3) — по-прежнему только у первых 6, чтобы не заваливать
каталог случайными статусами без надобности.
Проверено скриншотом: `qa/shots/integrations/b01-fix2/biz-integrations-installed__owner-empty-nails-ru-light-phone.png` —
персона `owner-empty` теперь видит карточку «Наше приложение для клиентов · Подключено», не EmptyState.

### F-13-011 (minor) — рейтинг/число отзывов на карточке не совпадали с реальным списком в «Отзывы»
`buildApp()` генерировал `rating`/`reviewsCount` формулой от индекса, независимо от массива `reviews`
(который заполнен только для одного приложения). Правки:
1. `reviewsCount: 0` по умолчанию в `buildApp()` — честное состояние «отзывов нет», пока не подтверждено сидом.
2. В конце `seed()` — пересчёт `reviewsCount`/`rating` из фактически засеянных `reviews` (группировка по `appId`,
   `rating` = среднее по реальным отзывам).
3. `src/areas/integrations/AppScreen.tsx`: строка рейтинга под карточкой раньше показывалась при
   `app.rating > 0` (то есть всегда, рейтинг был синтетический и ненулевой) — поменял условие на
   `app.reviewsCount > 0`, как уже было сделано в `AppTile.tsx`. Теперь рейтинг не рисуется у приложений
   без реальных отзывов — вместо этого под вкладкой «Отзывы» честно виден EmptyState «Пока нет отзывов».

Проверено скриншотами:
- `qa/shots/integrations/b01-fix2-reviews2/…ia-1…reviews-app1.png` — «4.5 · 2 отзывов» совпадает с двумя
  реальными отзывами на вкладке.
- `qa/shots/integrations/b01-fix2-reviews3/…ia-2…reviews-empty-app2.png` — рейтинг не показан, вкладка
  «Отзывы» = «Пока нет отзывов».

### shared/infra (major) — `[mock-db] QuotaExceededError`, подписка не переживает reload
Это код `src/mock/db.ts` (`flush()`), не раздела «Интеграции» — по правилам §1 CONVENTIONS такие файлы
не правлю сам. Уже была заявка в `qa/requests/integrations.md` (от измерителя и от меня раньше);
добавил короткую запись-подтверждение, что repro актуально и после моих правок, и что F-13-007 слегка
увеличивает объём `installs` (это требование «Готово, когда», не мог оставить старое поведение ради
экономии квоты). Сам файл `src/mock/db.ts` не трогал.
