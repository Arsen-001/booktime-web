## Что проверено по каждому компоненту из списка

- **BookingStatusBadge**, **WeekdayPicker** — уже использовались (`JournalToolbar.tsx`, `status.ts`, `RecurrenceForm.tsx`).
- **TableCardBody** — уже используется транзитивно: `src/ui/Table.tsx` сама рендерит мобильную карточку через
  `TableCardBody`, и `RecordsScreen.tsx` строится на `Table` — отдельно подключать нечего.
- **PeriodNav** — не использовался. Заменил самодельный блок «Сегодня / ‹ / › / дата» в `JournalToolbar.tsx`
  на `PeriodNav` (тот же `@/lib/date`, значит те же ереванские сутки, но плюс попап-календарь для прыжка на
  любую дату, которого раньше в шапке не было).
- **Fab** — не использовался, хотя его собственный докстринг в `src/ui/Fab.tsx` прямо называет журнал:
  «"Новая запись" над сеткой журнала». Добавил в `JournalScreen.tsx` на телефоне: липкая круглая кнопка
  «+» у большого пальца, открывает то же окно записи (`openWindow`), что и клик по пустой ячейке; скрыта,
  пока окно уже открыто. Старую кнопку «Новая запись» в шапке (F-01-184) на телефоне убрал (`!isMobile &&`),
  на десктопе она осталась — по CONVENTIONS §0 «одно главное действие», а не кнопка и в шапке, и внизу разом.
- **StickyActionBar, SlotButton/SlotRow, ScrollRow, FilterBar, Pagination, Timeline, MoneyInput, PhoneVerify,
  useTour/HintBanner/NextStepCard** — рассмотрел каждый: раздел уже закрывает те же задачи своими путями
  (`Table` с мобильной картой вместо ручной пагинации; `Sheet`-фильтры вместо `FilterBar`; `Popover` для
  статус-карточки вместо `Timeline`; `PhoneInput`/`Combobox` вместо `PhoneVerify`, который — про SMS-код, не
  про ввод номера при записи). Подключать их «для галочки» без реальной задачи не стал — это противоречило бы
  «взять готовое, когда оно решает задачу», а не «вставить компонент».

## Побочная находка и починка (не в списке пропусков, но по CONVENTIONS §0.1)

`qa/measure/journal/ux-r1.md`/`ux-r2.md` (major, не отмечены ✅): переход по датам считался через
`new Date(...).toISOString()` — в Ереване (UTC+4) это ломало «›»/«Сегодня» с полуночи до 4 утра. Проверил
код — `JournalToolbar.tsx` уже переписан на `@/lib/date` (`today()`/`addDays()`) до этой пачки, баг не
воспроизводится; заодно нашёл тот же класс ошибки в другом файле раздела — `useIsBeyondHistoryLimit`
(`src/areas/journal/lib/rights.ts`) считал «сегодня» через `new Date().toISOString().slice(0,10)`, что
сдвигало бы границу истории записей на час назад для всех пользователей в Армении. Починил на `today()`.
Отметил ✅ в обоих файлах измерений.
