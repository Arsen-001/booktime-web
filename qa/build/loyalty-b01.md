- Реферальная акция «для пригласившего» ограничена видом `cashback*` в выпадающем списке (по тексту ТЗ «акция
  с фиксированным % cashback»); F-06-082 («реферальную акцию нельзя привязать к типу карты») — вне пачки, но
  список акций для рефералки я не связываю с конкретным типом карты, что ему не противоречит.
- Права: показываю/скрываю пункты меню и действия по `loyalty.manage` (уже есть в фундаменте); тонких 8 галочек
  F-06-175 нет — их пачка b05, эта просьба уже записана планировщиком в `qa/plan/loyalty.md`, повторно не пишу.
- Статус сертификата/абонемента везде — чистая функция от `now()`, не хранится отдельным полем (кроме
  «использован» и «заморожен», которые меняет действие) — меньше рассинхрона, пересчитывается при каждом чтении.
- Демо-данные строю только для первых 3 бизнесов с клиентами (`SEEDED_BUSINESSES = 3`) — у персон вне этой
  тройки (включая часть `network`-прогонов) экраны корректно показывают пустое состояние/подсказку о типе
  карты, это не баг, а ожидаемое поведение при отсутствии данных для конкретного `businessId`.
