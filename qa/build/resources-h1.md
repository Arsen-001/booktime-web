  оба требуют недельного вида журнала (переключатель «День/Неделя», режим «Ресурсы») — в `src/areas/journal`
  такого экрана нет вообще ни для сотрудников, ни для ресурсов (проверил: `grep -rl "WeekView\|Неделя"` — 0

  принципе, — не точечная правка, а новый большой экран в чужом разделе; оставил как есть, попросил в
  `qa/requests/resources.md`.
- **F-16-031 «Предоплата и абонемент у групповой услуги»** — предоплата услуги целиком — `finance`
  (`F-07-094`, `PrepaymentSettingsScreen`), «запись по абонементу» — `loyalty` (`F-06-128`); в `Service`
  (ядро) нет ни поля предоплаты, ни поля «запись по абонементу» — оба владеет не resources. Не строил чужую

- **F-16-032 «Групповая услуга в сети»** — сеть/филиалы — раздел `network`, там пока нет ни экрана
  распространения услуг по сети в принципе (не только групповых) — зависимость на несуществующую чужую

  — либо тонкая доработка чужого блока с новым полем ядра/среза (нужна отдельная пачка), либо запрос в

  несёт F-16-085/086/088/089 (пачки online). Не стал форсированно врезаться в чужой активно строящийся
