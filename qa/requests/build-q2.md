## 1–2. `src/app/layout.tsx:50-51` — сырые цвета в `themeColor`
- Серьёзность: **major**
- Где: `src/app/layout.tsx`, строки 50 и 51: `'#f7f7fb'` (light), `'#0f0f1a'` (dark)
- Что не так: `themeColor` для `<meta name="theme-color">` — значения продублированы hex-ами вместо
  токенов фона (`--bg`/аналог в `src/styles/tokens.css`), хотя те же цвета фона наверняка уже есть как
  переменные темы.
- Как исправить: если в `tokens.css` есть переменные фона light/dark — взять их значения (Next.js
  `themeColor` не умеет читать CSS-переменные напрямую, но можно один раз продублировать буквальное
  значение с комментарием, откуда оно взято, либо явно пометить `tokens-ok` как системное поле
  метаданных, не элемент интерфейса).

> **Ядро k3 (25.09):** ✅ частично: одна копия значений — `THEME_META` в `src/config/theme-meta.ts` (строки с `tokens-ok` и ссылкой на токен). `src/app/layout.tsx` — не мой файл (помощник «приложение для телефона»): заменить два hex на `THEME_META.lightBackground` / `THEME_META.darkBackground`. `eslint.config.mjs` (`argsIgnorePattern: '^_'`) — не в моих файлах, ❌.

## 3–4. `src/app/manifest.ts:21-22` — сырые цвета в PWA-манифесте
- Серьёзность: **major**
- Где: `src/app/manifest.ts`, строка 21: `background_color: '#f7f7fb'`, строка 22:
  `theme_color: '#4f46e5'`
- Что не так: то же самое для `manifest.json` — `background_color` совпадает с light-фоном из пункта 1,
  а `theme_color` (`#4f46e5`) — самостоятельный синий, не встречающийся в темах layout.tsx (light/dark
  там `#f7f7fb`/`#0f0f1a`), стоит сверить, действительно ли `#4f46e5` — правильный акцент бренда, а не
  цвет-заглушка из шаблона Next.js по умолчанию.
- Как исправить: `manifest.ts` — статический файл метаданных PWA, значения тоже не могут читать CSS
  Custom Properties во время сборки; либо оставить с `tokens-ok` (обоснованное системное поле), либо
  свести оба файла к одной константе (`src/constants` или аналог) с комментарием, откуда взят токен,
  чтобы `layout.tsx` и `manifest.ts` не расходились сами по себе при следующей смене палитры.

> **Ядро k3 (25.09):** ✅ частично: `#4f46e5` — это настоящий `--primary` светлой темы (`tokens.css:28`), не заглушка Next. Константа — `THEME_META.primary` / `THEME_META.lightBackground` в `src/config/theme-meta.ts`; подключить в `manifest.ts` — владельцу файла (помощник «приложение для телефона»).
