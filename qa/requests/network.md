## 2026-09-25 · b01-fix1 · localStorage переполнен — подтверждаю чужую просьбу (F-11-077 block, «план не сохраняется после перезагрузки»)

- **Не мой путь, воспроизвела и подтверждаю.** Измеритель нашёл block: число в ячейке плана
  (`/biz/network/settings/plans`, F-11-077) пропадает после перезагрузки страницы, хотя подпись обещает
  «сохраняется сам». Причина — **не в моих файлах**: `src/mock/db.ts` (`debouncedLocalStorage`, ~строка 167)
  пишет ВСЮ базу одним `JSON.stringify` в один ключ `localStorage['bp-mock-db']`, и она уже у порога квоты
  браузера (~5–10 МБ). Проверила напрямую (Playwright, чистый контекст, персона owner/nails):
  ```
  [mock-db] не удалось сохранить в localStorage QuotaExceededError: Failed to execute 'setItem' ...
  ```
  — это происходит на КАЖДОЙ странице, при полностью пустом localStorage (ни один прежний прогон не мешает).
  `navigator.storage.estimate()` при этом показывает квоту 3+ ГБ (IndexedDB) — ограничение именно у
  `localStorage`, отдельного от общей Storage API квоты API cap на origin.
  Следствие: НИЧЕГО не переживает настоящую перезагрузку страницы (F5, второй таб, «Поделиться ссылкой»),
  ни в одном разделе — это уже подтверждено в `qa/requests/journal.md`, `payroll.md`, `loyalty.md`,
  `finance.md`, `notify.md`, `stock.md` за прошлые пачки; добавляю network как седьмое подтверждение.
- **Что сделала в своих файлах:** F-11-077 работает корректно ВНУТРИ сессии — сохранение без кнопки по
  `onBlur`, значение читается обратно из `listNetworkPlans` и видно сразу (SPA-навигация, без полного
  reload) — это я проверила отдельно и это работает. Блокирует только настоящий reload, который живёт в
  `mock/db.ts`, не в `src/api/network.ts` / `src/areas/network/**`.
- **Прошу (дублирую формулировку из journal.md, чтобы решение принималось один раз, а не 7):**
  `BroadcastChannel('mock-db')`/`storage`-листенер уже нужен отдельно (живое обновление между вкладками);
  для этой проблемы отдельно нужно решить, почему сериализованная база подходит к квоте — разбить
  `core`/`areas` на отдельные ключи `localStorage`, чтобы каждый `flush()` писал только изменившийся кусок,
  а не всю базу целиком (крупная доля объёма — судя по `src/mock/seed/photos.ts`, это SVG-data-URI фото
  салонов/сотрудников; можно вынести их в `IndexedDB`, у которой квота другая и с запасом).
- **Пока жду:** F-11-077 отмечен в моём отчёте как partial именно по этому пункту — не потому что не
  строила, а потому что не могу проверить «переживает reload» без правки чужого файла.

## 2026-09-25 · b01-fix1 · Автопрокрутка меню не видит АКТИВНЫЙ ПОДпункт (F-11-003 major)

- **Не мой путь, но нашла точную причину.** Измеритель: у кабинета сети 13 подпунктов меню, без прокрутки
  видно 2 («Обзор», «Аналитика»), и при заходе на глубокую страницу (например `/biz/network/staff`)
  активный пункт не прокручивается в видимую область — сайдбар остаётся на «Обзор/Аналитика» сверху, а
  реально открытая «Сотрудники сети» невидима без ручной прокрутки. Воспроизвела: `qa/shots/network-b01-fix1-nav-check/`.
- **Причина — в `src/shell/workspace/NavList.tsx`, не в моём `src/areas/network/nav.ts`.** Автопрокрутка
  (строки ~31-43) ищет узел `[data-nav-active]` и подкручивает ближайший скроллящийся контейнер к нему.
  Но атрибут `data-nav-active` выставлен ТОЛЬКО на ссылке верхнего пункта раздела (строка ~94:
  `data-nav-active={isActive || undefined}` на родительском `<Link>`), а вложенные дочерние ссылки
  (строки ~130-145, тот самый цикл `children.map`) этот атрибут не проставляют вовсе. Поэтому для активного
  ПОДпункта эффект находит только родителя «Сеть и филиалы» (он и так виден сразу под «Склад») и не видит,
  что реально нужно докрутить до дочернего элемента ниже.
- **Точечный fix (одна строка, не меняет поведение остальных разделов — только чинит недостающую метку):**
  в `NavList.tsx`, на `<Link>` дочернего пункта (там же, где `aria-current={childActive ? 'page' : undefined}`)
  добавить `data-nav-active={childActive || undefined}`. Эффект уже проверяет ближайший `data-nav-active` — с
  меткой на дочернем пункте он сам подтянется, ничего больше менять не нужно.
- **Пока жду:** сама не правлю `src/shell/**` (общий файл, не мой путь, CONVENTIONS §0.1). Отмечаю
  F-11-003 в отчёте как partial по этому пункту (список пунктов подтверждён рабочим — data-f=13, права
  скрывают лишние верно; сама прокрутка активного — здесь).
