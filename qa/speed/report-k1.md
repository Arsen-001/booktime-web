**Пять упрощений, которые дают больше всего:**
1. **Окно записи.** Первым — поле «Клиент» с поиском уже по 3 цифрам; выбор клиента подставляет его прошлую услугу; в выборе времени только свободные часы под эту услугу; дата — в подзаголовке окна. Запись по звонку: 8 → 3 нажатия, ≈40 → ≈8 с.
2. **«Пришёл / Не пришёл» прямо на прошедшей записи и в уведомлении.** «Пришёл» открывает шторку с уже подставленной суммой и «Готово». 5–6 нажатий (и потерянная сумма) → 2.
3. **Занятость в календаре мастера.** Календарь открывается на сегодня; тап по часу отмечает занятое, протяжка пальцем — отрезок; в предупреждении «не открыто ни одного часа» — кнопка «Открыть по рабочим часам». 7 → 2 и 8 → 2.
4. **Приложение клиента.** Тап по окну в выдаче сразу ведёт в запись на это время; блок «Свободно сегодня рядом» — на первом экране, с чипами сфер. 8 → 3.
5. **Подключение салона.** Кнопка «Далее» во всю ширину, прилипшая к низу экрана, и экран «Салон подключён» со ссылкой для владельца.

**Фундаменту (shell), только в этом ответе:**
- Общий поиск в шапке кабинета на десктопе не отвечает. Его стоит либо подключить с действием «Записать» у клиента, либо убрать до готовности.
- Демо-кнопка перекрывает правый нижний угол — то место, где на телефоне должна быть главная кнопка.
