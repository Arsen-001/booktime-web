**Пять упрощений, которые дают больше всего:**
1. **Окно записи.** Клиент — первым полем, курсор сразу в нём. Выбор клиента сам добавляет его прошлую услугу. Время по умолчанию — ближайшее свободное. Меню «Обычная / Пакет» убрать. Запись по звонку: 5–6 → 3 нажатия.
2. **«Мой календарь» мастера.** Открывается сразу на сегодня. «Занято» ставится тапом по часу. Кнопка «Открыть неделю». Занято: 5 → 2, неделя: 6 → 2.
3. **Запись клиента и гостя.** Услугу из выдачи или ссылки не спрашивать снова. «Оттенок» — не отдельным шагом. Добавить «Любой мастер», согласие — строкой без галочки. Клиент: 6 → 3, гость: 11 → 6.
4. **Заявки и оплата.** Заявки видны в колокольчике и на главной кабинета. У пришедшего клиента наверху окна кнопки «Наличные / Карта», и они сами ставят «Пришёл». Заявка: 5 → 2, «пришёл · оплачено»: 3 → 2.
