# Вопросы владельцу от хранителя ядра (k2, 25.09.2026)

### Номера клиентов не из Армении
- Суть: F-04-047 (Altegio) даёт выбрать код страны у телефона клиента. У нас номер — ключ клиента (F-00-128) и хранится как
  `+374XXXXXXXX`; туристы и диаспора с `+7`/`+1` сейчас не записываются ни в CRM, ни в приложении.
- Варианты: а) только Армения (+374), иностранцев вносить без номера; б) любой код (формат E.164), +374 по умолчанию —
  тогда меняются ключ клиента, вход по SMS-коду и маски во всех разделах; в) иностранный номер только в CRM салона, без
  входа в приложение.
- По умолчанию сделано: а) — ядро (`src/lib/phone.ts`) принимает только +374; clients держит своё поле «другой код» как текст.
- F-04-047, F-00-128.
