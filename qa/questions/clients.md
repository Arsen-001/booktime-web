# Вопросы владельцу — раздел clients

### Визит «Пришёл» без записи об оплате — оплачен или долг?
- Суть: пока раздел finance не разносит платежи по визитам, CRM не знает, заплатил ли клиент за визит «Пришёл». Проверяющие
  разошлись: демо-показ (demo-q2/q3, block) требует «считать оплаченным» — иначе почти каждый клиент «должник»; сквозной
  сценарий e2e-q3 C25.S4b ждёт «Не оплачено» и долг, пока платежа нет.
- Варианты: а) визит «Пришёл» без платежа = оплачен полностью, долг — только при явной частичной оплате; б) визит без платежа =
  долг на всю сумму; в) а) до постройки finance, затем б) по реальным платежам.
- По умолчанию сделано: а) — одно правило `visitPaid` в `src/domain/clients/money.ts` для списка, карточки, истории визитов и
  окна записи (противоречий «оплачено в истории / долг в карточке» больше нет). Переключение — в одной функции.
- F-id: F-04-059, F-04-071, F-04-165, F-04-179, F-00-131.

### Видит ли мастер суммы клиента (продано / оплачено / баланс)?
- Суть: F-00-132 «кто в салоне видит деньги — не решено». Сборщик b05 включил мастеру «Просмотр счетов», ревью ux-r2 №7 просит скрыть.
- Варианты: а) мастер видит суммы своих клиентов; б) не видит, пока владелец не включит галочку «Просмотр счетов»; в) видит только свои визиты.
- По умолчанию сделано: б) — `defaultMasterFineRights().viewAccounts = false`; сводка по клиентам без права на отчёты считает
  только свои визиты и подписана «Ваша выручка».
- F-id: F-00-132, F-04-200.
