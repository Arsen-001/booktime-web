## Сквозные правила для всех пачек

- **Роли у нас** (⭐ F-00-037): у салона один аккаунт, внутри — владелец, администраторы, мастера; шаблоны ролей Altegio (8) — 1:1 поверх этого. Мастер и владелец входят по номеру и коду, администратор — логином и паролем, которые выдаёт владелец (F-00-033/034; экраны входа строит settings).
- **Платность** (⭐ F-00-013/014/016): место считается по роли, а не по правам: мастер — 4 000 ֏ (в салоне минимум за двух), первый администратор бесплатно, следующие по 2 000 ֏; лимита мест нет — при добавлении показываем новую плату. Цены читать из settings (billing), не хардкодить; нет api — просьба и временная константа в `src/areas/staff/`.
- **Права**: в фундаменте 28 грубых прав (`src/config/permissions.ts`). Полный каталог (13 групп / 207 прав + 4 переключателя + «Медицинские документы») — наш, в `src/areas/staff/permissions/` и срезе `staff.rights[staffId]`; при «Сохранить» сводим тонкие права к грубым и зовём `setStaffPermissions()` — так `PermissionGate` во всех разделах сразу прячет закрытое (F-00-039). Ключи тонких прав для других разделов (journal просил 8 + 31) — просьбой фундаменту в `qa/requests/staff.md`.
- **Журнал изменений** (⭐ F-00-040) — наш срез `staff.audit[]` и api `logChange({ entity, entityId, action, before, after })` / `listChanges(filter)` делаем **в b01**, чтобы journal, clients, services, stock писали в него с самого начала; страница /biz/staff/log — в b05. История прав (F-10-070) и история записи у journal (F-01-096) читают его же.
- **Карточка сотрудника — наш хост `staffCard`**: вкладки вкладчиков (schedule, services, online, payroll, resources) вставляем через `useExtensions('staffCard')` + `<ExtensionSlot>`; их содержимое строят они. Наш вклад в чужие экраны — только `src/areas/staff/extensions/SettingsHub.tsx`.
- **Опасные действия**: вместо «вы уверены?» — «Отменить» 5 секунд (F-00-061); удаление навсегда — ввод имени (F-10-155). Каждое действие с сотрудником и правами пишется в журнал изменений.
- **Чужие данные не видны** (F-00-010): телефон клиента по праву маскируется везде, где его показывает staff (карточка, уведомления сотруднику, выгрузка в календарь).
- **Персоны**: owner — всё; admin — по галочкам владельца (без «Роли и права» и без выдачи «Владельца»); master — только своя карточка и приглашения; individual — свой профиль и входящие приглашения салонов (списка команды нет); network — «Все филиалы» с колонкой филиала. Сферы: «Медицинские документы» только в dental; слова — `useTerms()`.
- Что нужно из общего (поле `positionId` у `Staff`, ключи прав, api цен подписки, переключатель мест работы у человека с несколькими бизнесами) — просьбой в `qa/requests/staff.md`, пока — в своём срезе.
- В каждой пачке: метки `data-f="F-…"` на элементах функций; `node scripts/fids.mjs --area staff`, `node scripts/measure.mjs --area staff --persona owner,admin,master --lang ru,hy --device phone,desktop` (+ `--query "api=error"` и `api=slow`), `node scripts/check-tokens.mjs --area staff`; tsc — `npx tsc --noEmit --incremental --tsBuildInfoFile .tsbuild/staff.tsbuildinfo` с фильтром по своим путям.
