## Сквозные решения ⭐ (действуют во всех пачках)

- Статусы — 8 из ядра (`BookingStatus`): Altegio-четыре + «ждёт подтверждения», «ждёт предоплату», «отменена клиентом», «отменена мастером»; отмена позже срока = неявка (F-00-068, F-00-098).
- Вместо «вы уверены?» — «Отменить» на 5 секунд; закрытие с несохранёнными правками черновик не теряет (F-00-061).
- Двойная запись на одно время невозможна; «занято» мастером убирает окно сразу (F-00-045, F-00-001).
- Домашние записи мастера салона видны администратору в колонке мастера как «занята · дома» без имени и суммы (F-00-046, F-00-047).
- Запись постоянного клиента — 3 нажатия и до 10 секунд: клиент из недавних, прошлая услуга подставлена (F-00-004, F-00-060).
- Деньги через продукт не принимаем, только записываем способ и сумму; «пришёл · сумма» в 1–2 нажатия (F-00-126, F-00-127); предоплата ручная (F-00-097).
- Клиент = номер телефона +374, один номер — одна карточка (F-00-128, F-00-002). Источник записи: приложение / веб по ссылке / вручную мастером / администратором (F-00-093).
- У мастера места работы (салон, дома, зал, онлайн, выезд) — в записи указывается место (`workplace`, F-00-073). Кабинет показывает только функции своей сферы (F-00-145, `useSphere`, `useTerms` — «клиент/пациент», «мастер/врач/тренер»).
- Снятое, что легко построить по ошибке здесь: платные напоминания WhatsApp/SMS и «за монеты» (клиенту — только пуш, Снято 11); звонки внутри приложения и скрытие номера мастера (Снято 12); закрытая оценка 1–5 (Снято 9).

## Стыки с другими разделами (что должна дать наша сторона)

- **Окно записи открывается по адресу**: `/biz/journal?booking=<id>` и `/biz/journal?new=1&staff=<id>&start=<YYYY-MM-DDTHH:mm>` (+ по желанию `client=<id>`, `services=<id,id>`, `waitlist=<id>`). Нужно листу ожидания (resources F-16-161), карточке клиента, уведомлениям-колокольчику (notify), поиску клиента.
- **Хост `bookingWindow`**: вкладки clients → finance → loyalty → stock → resources → notify → online (порядок из `pairs.ts`), в пропсы — `mode`, `bookingId`, `businessId`, `locationId`, `draft`, `onDraftChange`. Правки черновика от вкладчиков (скидка, ресурс, клиент) принимаем в свой черновик. У нас остаются: параметры (левая зона), услуги и товары (центр), короткий ввод клиента (телефон, имя, подсказка, новый клиент), статусы, повторы, история.
- **Плитки левой панели** ведут на чужие экраны: «Продажа товара», «Каталог товаров» → stock; «Новый платёж» → finance; «Лист ожидания» → `/biz/waitlist` (resources); «Список услуг» — наше окно поверх журнала.
- **Групповые события**: мы рисуем их в сетке и даём выбор «Запись / Событие»; окно события, участники, серии, отчёт — resources.
- **Вклады раздела**: `src/areas/journal/extensions/ClientCard.tsx` («Визиты» клиента, смотреть `/dev/ext/clientCard/journal`), `src/areas/journal/extensions/SettingsHub.tsx` (карточка «Цифровой журнал» со ссылкой на `/biz/journal/settings`).
- **Подпункты меню** (`src/areas/journal/nav.ts`): «Журнал» `/biz/journal`, «Записи» `/biz/records`, при желании «Настройки журнала» `/biz/journal/settings`.
