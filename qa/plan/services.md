# План раздела «Услуги: каталог, категории, карточка услуги, цены от–до, длительность, фото, дипломы, материалы» (services)

Составил планировщик раздела 24.09.2026. Отдельного файла ТЗ Altegio у раздела нет. Источники:

- `00-our-decisions.md` §8: F-00-082…F-00-091, 10 функций. Только их считает `node scripts/fids.mjs --area services`.
- Функции каталога услуг из файлов 01–16 и из других параграфов 00, у которых в поле «Где» указан каталог
  услуг кабинета: «Услуги / Администрирование → Услуги», «услуга → вкладка …», «форма / карточка услуги»,
  «категория услуг», вкладка «Услуги» в карточке сотрудника, сетевые «Настройки услуг». Сюда же вошли
  функции, которые планировщики других разделов прямо отдали services: schedule, online, finance, staff,
  network, settings, client.

Всего **91** функция. Каждая попала ровно в одну пачку или в notOurs. Пересечения, пропуски и лишние id
проверены скриптом.

## Ограничения для всей работы

- **Снято №15:** правила «5 фото к услуге + 20 в галерею» нет. У каждого мастера 6 мест всего,
  галерея и фото к услугам считаются вместе (F-00-085).
- **⭐ F-00-168:** всё новое (фото, диплом, своя услуга с текстом) до проверки клиенту не видно. Проверку
  ведёт платформа: отправляем через api platform, показ — через их `isVisibleToClients`.
- **⭐ F-00-061:** вместо «вы уверены?» и ввода слова «УДАЛИТЬ» (F-16-170, F-12-126) — «Отменить» в
  течение 5 секунд. Перед удалением показываем, что пострадает: число мастеров, будущих записей и
  событий, пакетов с этой услугой.
- **⭐ F-00-040:** каждая правка услуги, категории, цены или мастера пишется в журнал staff через
  `logChange()`.
- **⭐ F-00-172…174:** языки ru, hy и en. Названия, описания и категории хранятся как `LocalizedText`,
  показываются через `pickText`. Шаблонные услуги уже переведены. Свои тексты переводятся
  автоматически, с пометкой и возможностью поправить. Перевод не теряется ни при каких переносах
  услуги (F-03-115, F-15-142). Тексты раздела: ru и en сразу, hy позже.
- **⭐ F-00-145:** шаблоны услуг и слова зависят от сферы: `useSphere()` и `useTerms()`. «Выбор оттенка
  при записи» доступен только в сферах с `has('palette')`, в остальных — список вариантов вручную
  (F-00-094).
- **⭐ F-00-001:** кабинет бизнеса — это одновременно приложение и веб. Все экраны раздела работают на
  телефоне шириной 390 px; F-14-114 покрывает эти же экраны, отдельного «приложения» нет.
- **Деньги** — целые драмы. Цена «от–до» показывается через `moneyRange`, длительность — через
  `duration`. У длительности «от–до» бронируется верхняя граница (F-00-057, считает движок schedule).
- **Данные ядра** уже есть в `src/domain/core.ts`: `Service` (`kind`, `capacity`, `priceMin/Max`,
  `durationMin/Max`, `bufferAfterMin`, `repeatIntervalDays`), `ServiceCategory`, `Staff.serviceIds`.
  Всё остальное храним в своём срезе `src/mock/slices/services.ts` с ключом по id ядра:
  - цена и длительность мастера по услуге;
  - название для онлайн-записи у категории и услуги;
  - чековые поля (F-07-149);
  - «выбор при записи» (F-00-094);
  - фото, места для фото, документы, материалы, стерилизация, жалобы.
- **Техперерыв:** `bufferAfterMin` пусто — берётся общий; `0` — явно без перерыва; `N` — свой. В списке
  эти три состояния должны различаться (баг Altegio не повторяем, F-02-060).
- **Технически:** Excel заменяем CSV (выгрузка и загрузка, не больше 500 строк). Экраны строим только
  из `src/ui`, цвета берём только из токенов. Дизайн и тексты свои, не как у Altegio.

|---|---|---|

| `/biz/services/templates` | «Добавить из шаблона»: готовые услуги сферы на трёх языках, выбор галочками, длительность по умолчанию | 1 |
| `/biz/services/excel` | «Операции с Excel»: выгрузить CSV, загрузить CSV (≤500 строк, колонка «Tech. break» в секундах), отчёт об ошибках строк | 3 |
| `/biz/services/photos` | фото работ: 6 мест на мастера, привязка к услуге или к галерее, статусы проверки, «Купить место» за монеты; владелец выбирает мастера | 2 |
| `/biz/services/documents` | дипломы и сертификаты: загрузка, статусы (ждёт / проверен / отклонён), отметка «документы проверены» | 2 |
| `/biz/services/materials` | материалы (метки сферы + свой текст, привязка к услугам, товары склада с галочкой «показывать клиентам») и блок «Стерилизация» | 2 |
| `/dev/ext/staffCard/services` | вклад «Услуги» в карточку сотрудника: услуги мастера, его цена и длительность, назначить / снять | 2 |
| `/dev/ext/settingsHub/services` | карточка раздела в хабе настроек: ссылки на каталог, шаблоны, Excel, фото, документы, материалы | 3 |

Меню (`src/areas/services/nav.ts`): «Каталог услуг» `/biz/services`, «Фото работ»
`/biz/services/photos`, «Документы» `/biz/services/documents`, «Материалы» `/biz/services/materials`.
Шаблоны, Excel и категории открываются кнопками из каталога. Пункт меню добавляется на том этапе, где
строится его страница.

Персоны: `owner` и `admin` видят весь каталог (у admin — по правам). `master` видит каталог только для
чтения и свои фото, документы и материалы. `individual` видит всё о себе. `network` — каталог
филиала с замками на сетевых полях (F-11-084).
