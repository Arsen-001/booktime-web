## Сквозные правила для всех пачек

- Клиент = номер телефона (+374 по умолчанию): один номер — одна карточка, дубль не создаётся (F-00-128, F-04-049).
- Клиенту из CRM ничего не показываем: заметки, суммы, история видны только бизнесу (F-00-130).
- Деньги через CRM не принимаем, только записываем; «Продано» растёт только от «Клиент пришёл»; баланс = оплачено − продано (F-00-126, F-04-165).
- Каналы клиенту — пуш нашего приложения; SMS не шлём; рассылки — новости подписчикам (F-00-114, F-00-120).
- Каждая правка клиента, включая удаление, пишется в журнал изменений с автором и временем (⭐ к F-04-207, F-00-040).
- Карточка клиента — наш хост `clientCard`: вкладки вкладчиков (journal, finance, loyalty, notify, online) вставляем через `useExtensions('clientCard')` + `<ExtensionSlot>`, их содержимое строят они (см. notOurs).
- Наш вклад в окно записи — `src/areas/clients/extensions/BookingWindow.tsx` (мини-карточка, данные сети, примечание); поля выбора/создания клиента в самом окне строит journal.
- Чего нет в фундаменте (тонкие права 26 штук, поле в ядре, срок потери клиента из reports) — просьбой в `qa/requests/clients.md`, пока — в своём срезе.
- В каждой пачке: метки `data-f="F-…"` на элементах функций; `node scripts/fids.mjs --area clients`, `node scripts/measure.mjs --area clients --persona owner,admin,master --lang ru,hy --device phone,desktop`, `node scripts/check-tokens.mjs --area clients`.
