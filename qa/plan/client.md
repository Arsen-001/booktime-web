## Маршруты раздела

Приложение клиента (`src/app/(client)/`, экраны — в `src/areas/client/`):

| Маршрут | Экран |
|---|---|
| `/` | Главная: ряд сторис, место под баннер, горящие окна, ближайшие записи, мои мастера, карусели абонементов/сертификатов/карт, кэшбэк |
| `/search` | Каталог «кто когда свободен»: «Что ищете?», категории, «Рядом со мной», фильтры, пустой результат «Не нашли?» |

| `/places/[businessId]` | Карточка места (салона): сведения, мастера, услуги, сторис и промоблок салона, кэшбэк, мои записи здесь, филиалы сети |
| `/places/[businessId]/cashback` | Детали кэшбэка: сумма, на что потратить, как заработать |
| `/login` | Вход клиента: имя, телефон, код в WhatsApp/Telegram (SMS запасной), согласие; `?next=` |
| `/book` | Поток записи: мастер → услуга → окно → оттенок → для кого → вход → итог (`?staff=&service=&slot=&membership=`) |
| `/bookings` | Мои записи: предстоящие / прошедшие / отменённые + мой лист ожидания |
| `/bookings/[bookingId]` | Запись: статус, подтвердить, отменить, перенести, повторить, ★, связь, предоплата «Я оплатил», оплата и лояльность |
| `/bookings/[bookingId]/reschedule` | Перенос: окна того же мастера |
| `/favorites` | Мои мастера + подписки ❤ (новости вкл/выкл) |
| `/notifications` | Лента уведомлений и новостей с кнопками действий |
| `/profile` | Личный кабинет: фото, имя, язык, формат даты, крупный шрифт, установить приложение, «Мой бизнес», выход; вклады clientProfile (loyalty, finance) |

| `/diary` | Дневник клиента |
| `/cards` | Абонементы / Сертификаты / Карты лояльности (вкладки), покупка |
| `/cards/memberships/[id]`, `/cards/certificates/[id]` | Карточка абонемента / сертификата |
| `/stories/[storyId]` | Просмотр сторис: «Записаться», пометка «Реклама» |

## Что нужно от других разделов и фундамента (к просьбам в `qa/requests/client.md`)

- **online** — правила мастера (часы звонков F-00-105, срок бесплатной отмены F-00-098, предоплата и реквизиты F-00-097,
  «кого принимаю», видимость «Только мои клиенты»): клиент только читает через `readArea('online')` в `src/api/client.ts`.
- **schedule** — `getFreeSlots` / `getNearestSlots` для каталога, записи и переноса (не менять, только вызывать).
- **stock** — палитра оттенков и остатки для F-00-094…096 (чтение).
- **loyalty / finance** — вклады в хост `clientProfile` (карты, абонементы, сертификаты, баланс) уже заведены; данные для `/cards` и оплаты в записи — чтение их срезов.
- **resources** — лист ожидания `/biz/waitlist`: запись клиента в лист (F-00-102) — через api раздела resources, пока нет — свой срез + просьба.
- **platform** — баннеры (F-00-163) и проверка сторис (F-00-168…170): клиент читает одобренные из среза platform.
- **settings** — баланс и списание монет за сторис/продвижение/новости сверх лимита (`/biz/coins`).
- **Фундамент** — поле «источник записи» и «для кого» в `Booking` ядра (F-00-093, F-00-125); ссылки на приложение для бизнеса внизу меню
  кабинета (F-14-002); нижняя панель кабинета на телефоне (F-14-084); пара хост/раздел `bookingWindow ← client`, если «Напомнить» (F-00-121) нужен прямо в окне записи.

## Снято — не строить (из 00 «Снято»)

Звонки внутри приложения и скрытие номера мастера; закрытая оценка 1–5 и плохие отзывы; сторис «только для подписчиков»
и сторис без предела мест; платные напоминания через WhatsApp/SMS; «мастер сам появляется в Моих мастерах по номеру из CRM»;
встроенная карта, карты Google/Apple, «Вызвать такси» — только ссылка на Яндекс Карты; кошелёк клиента и 5% — отложено (F-00-028).
