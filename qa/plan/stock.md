## Ограничения, которые действуют на все пачки

- **⭐ F-00-050, F-00-133:** у каждого салона (филиала) свой склад, данные не смешиваются; ключ — `businessId` + `locationId`. Склад ведёт и мастер-одиночка (персона `individual`), не только салон.
- **⭐ F-00-001, F-08-136:** кабинет бизнеса — и приложение, и веб: весь склад работает на телефоне 390 px (каталог, приход, списание, инвентаризация, сканер камерой).
- **⭐ F-00-145, F-00-146, F-00-148:** склад и его части показываются по сфере (`useSphere().has('stock')`, палитра — `has('palette')`); «клиент/пациент», «мастер/врач» — `useTerms()`.
- **⭐ F-00-126, F-00-028:** деньги только записываем, через нас не проходят; онлайн-продажи товара нет, продажа по ссылке отложена до кошелька.
- **⭐ F-00-040:** каждая правка склада (товар, цена, операция, дата, удаление) — строка «кто, когда, что»; в документе — своя история (F-08-052), общий журнал — у staff (просьба №7).
- **⭐ F-00-061:** «Отменить» 5 секунд вместо «вы уверены?»; для необратимого — ввод слова (F-08-030).
- **⭐ F-00-002, F-00-172:** деньги — целые драмы (֏), телефон +374, время 24 ч; тексты ru + en сразу, hy позже; названия товаров для клиента — `LocalizedText`.
- **Снято №13, №14 (F-00-164):** никакого аккаунта «поставщик» и никаких данных мастеров поставщику; поставщику уходит только текст «заказать» из WhatsApp салона. Реклама у склада (F-00-165) — не наша (хозяин client, §14), место под неё не строим.
- Баги Altegio не повторяем: пересчёт количества при смене единицы (F-08-020, F-08-056), «шт.» вместо единицы товара в оплате (F-08-070).
- Технически: пакетов ставить нельзя — Excel = CSV, PDF = страница для печати, штрихкод генерируем сами (EAN-13 + SVG), камера — `BarcodeDetector` с ручным запасным вводом. Экраны — только из `src/ui`, цвета — только токены. Дизайн и тексты свои, не Altegio.
