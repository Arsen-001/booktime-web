## Починено
1. **Права в /biz/apps (major, безопасность).** Права взяты те же, что в вебе (A8).
   - Страницы закрыты `AppGate` (новый src/areas/client/apps/AppGate.tsx, это PermissionGate с плашкой «Нет прав»):
     «Команда» — staff.view, «Услуги» — services.view, «Визит» и «События» — journal.view, «Своё приложение», «Продвижение» и «Сторис» — billing.manage, «Новости» — notify.mailings, «Напоминания» — clients.phones.
   - Плитки хаба и «кэшбэк в приложении» (loyalty.rules) скрыты по тем же правам.
   - «Аналитика»: вкладки «Сегодня», «Период» и «Филиалы» требуют reports.view, «Z-отчёт» — finance.view, «Моя» доступна всем.
   - «Команда»: действия требуют staff.manage. У владельца нет кнопок «Уволить» и «Удалить», переключатели доступа выключены, есть подпись «передача владения только в вебе». Роли «Владелец» в форме добавления больше нет. Вкладка «Аналитика» чужой карточки требует reports.view.
   - «Услуги»: без services.edit экран только для чтения.
   - В api (моковый режим, src/api/client.ts) стоят те же проверки через assertCan:
     - отчёты: getDaily/Period/NetworkDayStats требуют reports.view, getDayZReport — finance.view, getMyAnalytics по чужому сотруднику — reports.view;
     - «Команда»: create/fire/restore/delete/setEmployeeAppAccess/durations требуют staff.manage, с владельцем эти действия запрещены всегда (`assertStaffManage`). Без staff.view listAppStaff отдаёт только свою строку;
     - «Визит»: продажа, оплата, возврат и удаление оплаты требуют journal.edit по мастеру визита (для чужого визита нужно journal.others). Список визитов фильтруется по journal.view;
     - «Услуги» и «Категории» требуют services.edit; брендовое приложение, буст и сторис — billing.manage; новости — notify.mailings; кэшбэк — loyalty.rules.
   - Проверено действием на телефоне и десктопе:
     - мастер: в «Аналитике» только вкладка «Моя», «Команда» закрыта, «Зарплата» только своя;
     - админ: «Команда» только для чтения, ни у кого нет кнопки «Уволить»;
     - владелец и сеть: на карточке владельца «Уволить» и «Удалить» = 0, на карточке мастера кнопки есть.
