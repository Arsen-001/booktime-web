## Починено
1. `src/areas/schedule/CalendarScreen.tsx` — «Календарь мастера» при ошибке загрузки списка мастеров показывал
   «Здесь будет календарь мастера · Пригласите мастера» (владелец думает, что мастеров нет). Теперь ErrorState с
   «Повторить». Проверено `?api=error` на телефоне (`fix-calendar-error.png`).
2. `src/areas/schedule/ScheduleScreen.tsx` — на телефоне неделя на стыке месяцев («28 сентября – 4 октября») не
   влезала, стрелка «›» уезжала одна на отдельную строку (`scr-owner-phone-_biz_schedule.png`). Теперь навигация в одну
   строку (`fix-phone-periodnav.png`). tsc/eslint по файлам чисто (старое предупреждение exhaustive-deps осталось).

3. **Решение владельца 01.10: «В отпуске до…» не переносит записи сам.**
   - `src/api/schedule/calendar.ts` `setVacationUntil(staffId, until, actorName, force?)`: без force проверяет записи
     (txFindAffected; в режиме api — findAffectedBookings) и возвращает `{ ok: false, affected }`, с force пишет отпуск.
     Действием не проверено: ни один экран функцию не вызывает. Отпуск ставится через «Отсутствие…», а оно уже шло через
     проверку записей.
   - `components/AffectedBookingsNotice.tsx` (общий список F-02-106: панель графика, «Отсутствие», журнал): метка
     «Повторяющаяся» у записей серии; строка «Со всеми сразу»: «Перенести все к…» (только мастера, свободные для каждой
     записи) и «Отменить все с уведомлением» (с подтверждением; серии не останавливаются). Ключи — ru/en/hy
     `schedule.affected.*`.
   - Проверено действием: Ани, отпуск 06–08.10 → «7 записей не помещаются» + «Со всеми сразу» → одну перенёс к Еве,
     «Отменить все» → тост «Отменено 6 записей» → «Отметить» → клетки «Отпуск», у Евы 06.10 появилась запись
     (`vac-1…vac-4`). 12–16.10: 5 записей, у серийной «Ани Мелкумян, вт 11:00» есть метка «Повторяющаяся»,
     «Перенести все к…» предлагает Еву (`vac-6-series.png`). Ошибок консоли нет, tsc/eslint чисто.

  сервера; повторно не воспроизвелось.
