# Предоплата для клиента, который уже не приходил — отчёт (01.10.2026)

## Решения
- **Счётчик — у каждого мастера свой (В-07, ANSWERS.md: «мастер видит неявки клиента только у себя»).** Считается по
  записям: статус «Не пришёл» + отмена клиентом позже срока (`cancelledLate`, F-00-098), только записи к ЭТОМУ мастеру,
  за последние M месяцев. `Client.noShowCount` (счётчик бизнеса, в сиде не совпадает с записями) не используется.
- **Правило — часть правила предоплаты мастера** (`Staff.prepayment.onlyAfterNoShows = { count, months }`), второго
  потока нет: процент, «только предоплата / вся сумма», реквизиты, срок ожидания, «Я оплатил», «Деньги пришли», касса —
  прежние. Нет поля — предоплата со всех (старые правила не меняются).
- **Где настраивается:** «Онлайн-запись → Правила записи → правило мастера» (единственное место предоплаты, решение
  владельца 01.10.2026). Новый блок «С кого брать предоплату»: **«Только с тех, кто уже не приходил»** (по умолчанию при
  включении, 2 раза / 12 месяцев, порог 1–5, срок 3/6/12/24 мес.) или «Со всех клиентов». Выключено — как раньше.
  Правит сам мастер (как и остальную предоплату); владелец видит правило в «Финансы → Предоплата».
- Правило не включается само у мастеров без реквизитов: без «куда переводить» клиент не сможет заплатить.
- Только онлайн-запись (приложение, ссылка/виджет, каталог → приложение). Запись из журнала сотрудником — без предоплаты.
- Перенос клиентом не снимает такую предоплату (порог считали при записи).
- Абонемент в виджете по-прежнему главнее предоплаты (как было, 1155).
- «Правило для новых клиентов»: есть только в демо-политике оплаты Altegio (`PaymentPolicyConditions.clientScope`,
  F-07-105…109, онлайн-оплата «Скоро») — не дублировали, наше правило о другом.
- Тексты: слово «неявка» не используется; клиенту — без упрёков («визита не состоялись», «так мастер бережёт время для
  всех», «после оплаты время закреплено за вами»).

## Открытые вопросы (решил сам)
- В-07 «у себя» понял как «у этого мастера» (так и в задаче); в салоне пропуски у других мастеров салона не считаются.
- Поздняя отмена считается как «не пришёл» — так её уже считает ядро (F-00-098).
- По умолчанию при включении предоплаты выбрано «только с тех, кто не приходил» 2/12; у мастеров без реквизитов не
  включается.
- Замечено, не моё: в api заявка из приложения после «Я оплатил» не попадает в «Заявки» (в моке попадает); в сиде мока
  `Client.noShowCount` не совпадает с записями «Не пришёл».
