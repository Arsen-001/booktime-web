# «Пригласи подругу» — личная ссылка клиента (01.10.2026)

ТЗ: F-06-081…F-06-085 (06-loyalty.md), QUESTIONS F-06-084 → «приглашённый — впервые у этого владельца». Награда — прежняя
логика рефералки салона (скидка приглашённой + бонус пригласившей) при оплате первого визита.

## Что сделано

**Правила (одни на фронт и сервер)** — `src/domain/rules/referral.ts` (+ тесты `tests/referral.test.ts`), копия на сервере
`booktime-backend/src/modules/loyalty/referral.rules.ts`: код 6 знаков без похожих (0/O, 1/I/L), ссылка `/b/<slug>?ref=<код>`,
привязка только если программа салона включена, код этого бизнеса, не сам себе (та же карточка / номер / пользователь
приложения), у клиента ещё нет пригласившего и нет ни одной неотменённой записи в бизнесе, кроме создаваемой. Отказ или
неверный код запись НЕ ломают — она создаётся без привязки.

**Клиент**
- «Вы записаны» в приложении (`BookingDone` → `areas/client/referral/InviteFriendForBooking`) и в виджете/по ссылке
  (`areas/online/booking/InviteFriendCard`, по хэшу записи): ссылка + код, «Скопировать ссылку», WhatsApp (wa.me с готовым
  текстом), Telegram (t.me/share). Компонент `src/ui/ShareLinkPanel.tsx` (+ `src/lib/share.ts`).
- Профиль: вход «Пригласите подругу» со счётчиком («Пригласили 1 человека · бонусов 500 ֏») → `/profile/invite`: ссылка по
  каждому салону с программой, кого пригласил («Мари П.» — без фамилии), статус «Есть запись → Визит состоялся → Бонус
  начислен / Запись отменена», «Получено N ֏».
- Подруга открывает ссылку: код запоминается в браузере на 30 дней по адресу салона (`src/lib/referralCapture.ts`), над
  страницей салона и записью — «Ани М. приглашает вас в «Nuri Nail Studio» · Вам — скидка 10% на первый визит»
  (`areas/online/public/ReferralWelcome`, в `app/b/[slug]/layout.tsx`). Виджет и приложение отправляют `referralCode`,
  после записи код забывается.

**Кабинет**
- Карточка клиента: «Пришла по приглашению: Ани Мелкумян» (ссылка на карточку пригласившей), у пригласившей —
  «Привёл(а) 1 человека · пришли на визит: 1» (`areas/clients/components/card/ClientReferralBadges`, право clients.view).
- Окно записи → «Лояльность»: у приглашённой по ссылке строка «Скидка по приглашению · Ани М.» подставляется сама
  (как абонемент/автоакция, можно убрать); убрали — «По приглашению: Ани М. [Применить]» вместо ввода телефона.
  «Провести оплату» — скидка подруге, бонус пригласившей (`referralAccrual`).
- Решение: у пригласившей нет карты лояльности → карта выдаётся автоматически при начислении (тип: на который смотрит
  бонусная акция → с автовыдачей → первый). Раньше бонус в этом случае не начислялся вовсе.

**Данные / api**
- Мок: поля ядра `Client.referralCode / referredByClientId / referredAt`; привязка — `attachReferralTx` (`src/api/referral.ts`)
  внутри request() записи (`bookAppointment`, `createOnlineBooking`).
- Сервер: таблицы `referral_codes`, `client_referrals`; привязка в едином потоке `BookingsService.place()` в той же
  транзакции (`attachReferralInTx`, только онлайн-источники); `referralCode` в телах `POST /v1/me/bookings` и
  `POST /v1/public/b/{slug}/bookings`; маршруты `GET /v1/me/referrals`, `GET /v1/me/referrals/{businessId}`,
  `GET /v1/public/bookings/{id}/referral?h=`, `GET /v1/public/b/{slug}/referral/{code}`, `GET /v1/biz/{b}/clients/{c}/referral`
  (clients.view). Ядро порта лояльности видит `referredByClientId` (runner.loadCore) — оплата без телефона.
- Пока миграция не применена: всё работает как раньше, рефералка молча «выключена» (чтения → null, привязка пропускается).
- Найдено и исправлено попутно: в api `getReferralEligibility` с пустым телефоном отвечал 400 (проверка аргументов порта
  требовала непустую строку) — пункт «Приведи друга» в оплате в режиме api не показывался вообще. Тип `string | null`, порт
  пересинхронизирован (`sync-loyalty-port.mjs`).

## Решения по умолчанию / открытые вопросы
- «Новый клиент» = нет неотменённых записей в этом бизнесе (не во всей сети) — у сети коды по филиалам. Расширить на сеть — по слову владельца.
- Ссылка показывается только если у салона рефералка включена и выбраны обе акции.
- Название «Пригласите подругу» во всех сферах (у барбершопа уместнее «друга») — оставил имя владельца, можно сделать по сфере.
- Награда — как раньше, при оплате первого визита через «Лояльность»; если визит оплачен только деньгами во вкладке «Оплата», бонус не начислится (так было и до этого).
- Копия базы `booktime_referral_qa` в MySQL оставлена (не удалял данные); можно `DROP DATABASE booktime_referral_qa`.
- Клиентское приложение (запись из карточки мастера) проверено кодом и общим путём; сценарий с экраном BookingDone не снимал (тот же компонент, что в профиле).
