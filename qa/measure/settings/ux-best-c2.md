## 1. Подписка: число мастеров — рядом чипов, срок — карточками, итог с детализацией справа (major, Р6)
- **У них [видел]:** Altegio «Управление лицензией»: количество сотрудников — ряд чипов «до 1 · 2 · 3 … 20 · Безлимит»; срок — 3
  карточки «3 месяца · +1 мес. бесплатно · 6.3€/мес», «6 месяцев · +3 мес.», «1 год · +9 мес.»; справа «Детализация»: срок, цена
  за сотрудника, скидка по промокоду красным, старая цена зачёркнута, «Итого €100.72 · Перейти к оплате» (`13-billing-license.jpg`).
- **Сделать:** так же, в драмах: чипы числа мастеров, карточки срока с ценой **за месяц** и выгодой, панель итога (на телефоне —
  липкая снизу, Р1) с промокодом. Ничего не списывается без экрана итога.

## 2. Тип бизнеса — карточками с примерами услуг (minor, Р26)
- **У них [видел]:** Altegio «Цифровой журнал → Тип записи»: «Смешанная запись», «Индивидуальная запись: стрижки, маникюр,
  тренировки», «Групповая запись: фитнес, мастер-классы» (`11-settings-journal.jpg`).
- **Сделать:** такие же ChoiceCard в регистрации и в настройках: выбор сферы и формата с примером услуг из этой сферы.

## 3. Напоминание об оплате — только в «Подписке», не полосой на каждом экране (minor)
- **У них [видел, антиприём]:** Altegio: жёлтая полоса «Приветственный бонус… Скидка 30%… HELLO30 · Оплатить сейчас» стоит сверху
  **на каждом** экране кабинета (на всех снимках папки), ≈50 px.
- **Сделать:** срочность — точкой у пункта «Подписка» и карточкой на его странице; полоса во весь экран — только когда до заморозки
  ≤ 3 дня (вариант «в» из QUESTIONS.md), и её можно закрыть на сутки.

## 4. Помощь — «?» с номером бизнеса и чатом (minor)
- **У них [видел]:** Altegio: «?» внизу меню → «У вас есть вопросы?»: «Location ID #1396651» (готово для поддержки), «База знаний»,
  «Видео», вкладки Telegram / WhatsApp с QR (`14-help-support.jpg`).
- **Сделать:** в настройках (и в меню — просьба к фундаменту) «Помощь»: номер бизнеса с «Копировать», чат поддержки в WhatsApp/Telegram
  (иконка + подпись, Р18), короткие статьи по разделам.
