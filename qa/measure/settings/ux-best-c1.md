## 2. Быстрый старт = 3 шага до первой записи: услуга → мастер → график (major, F-00-018/019)
- **У них [видел]:** Altegio после регистрации — окно поверх кабинета «Шаг 1 из 3: Создайте услугу» → «Добавьте сотрудника» →
  «Выберите рабочий график» (дни кнопками, 4 популярных варианта часов, «График будет создан на месяц вперёд») (`05-quickstart-service.jpg`,
  `07-quickstart-schedule.jpg`); затем тур журнала 4 экрана с «Посмотрю позже» (`08-journal-tour-1.jpg`).
  Сфера — плитками с иконками (`02-business-type.jpg`), цели — плитками «несколько на выбор» (`04-goals.jpg`).
- **Сделать:** `/biz/onboarding`: сфера плитками → услуги из готового списка галочками → «Кто работает» (я один / нас несколько)
  → часы из 4 вариантов → «Готово: ваша ссылка» (копировать, QR, WhatsApp). Полоса «Шаг 2 из 4», «Пропустить» на каждом шаге,
  всё сохраняется сразу. После — чек-лист «Что ещё настроить» в журнале, пока не закрыт (как «Что настроить до запуска» в online).
