Дата: 25.09.2026. Дев-сервер: localhost:3710 (уже работал, не перезапускал). Персоны: owner (`?demo=owner`), master
(`?demo=master`, для проверки прав). Устройства: телефон 390×844, десктоп 1440×900. Языки: ru, en; hy не проверял
(в работе только en+ru — CONVENTIONS §0.4).

**Метод:** сначала `grep -rl "F-0X-XXX" src` по каждой функции — найдены ли атрибуты `data-f` в коде вообще (не
только упоминания в комментариях). Дальше — `scripts/measure.mjs` (снимки, консоль, i18n, сырые ключи, вылет,
мелкие зоны) и свои сценарии Playwright в `qa/scenarios/schedule/*.json` (клик → сохранение → `goto` того же
маршрута в той же сессии браузера → проверка, что значение осталось — это и есть «сохранение после
перезагрузки»). Экраны-хозяева «Карточка сотрудника» (staff) и «Настройки» (settings) ещё не построены их
разделами, поэтому вклад schedule смотрел через `/dev/ext/staffCard/schedule` и `/dev/ext/settingsHub/schedule`,
как велит правило CONVENTIONS.

## Главный результат

Из 21 функции пачки g3-2 **в коде и на экране есть только 5**: F-02-059, F-02-066, F-02-081, F-02-082, F-02-083 —
все они рёбра карточки сотрудника / настроек, отданные через `/dev/ext/staffCard/schedule` и
`/dev/ext/settingsHub/schedule`. Остальные **16 функций не имеют ни одного `data-f` нигде в `src/`** — не только в
schedule, я проверял по всему репозиторию: экрана, поля или переключателя для них попросту не существует. Это
`block` по каждому пункту «Готово, когда» этих 16 функций.
