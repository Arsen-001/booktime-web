**Метод и его честные границы.** Часть пунктов проверена настоящим действием в браузере
(клик по ячейке, выбор мастера, смена языка/устройства) — это помечено «действием». Часть —
только статическим просмотром отрендеренного экрана и `data-f`-разметки на нём без клика внутрь
(панели/визарды/подтверждения) — помечено «экраном»: сама функция и её UI на месте, но
многошаговый сценарий кликами не прогнан. Это НЕ равно «работает» — это «есть на экране,
кликами до конца не проверено». Такие пункты — ❌ в счёте «passed», не ✅.

**Сквозной автозамер (все 32 страницы, ru+en, phone+desktop):** 0 ошибок консоли, 0 предупреждений,
0 ответов ≥400, 0 сырых ключей, 0 вылетов по ширине, 0 зон нажатия < 40px, 0 «висящих загрузок».
hy (8 стр., phone, owner): 0 сырых ключей, 0 ошибок; армянских букв на экране не найдено — это
**ожидаемо**, не дефект: CONVENTIONS.md §0.4 (25.09.2026) — «hy НЕ пишем и НЕ проверяем, пока
