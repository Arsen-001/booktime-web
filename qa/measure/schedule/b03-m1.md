## Дефекты

1. **[major] F-00-059 — «Задерживаюсь» не уведомляет следующего клиента.** Проверено действием: бейдж «Задержка 10 мин» появляется только на экране самого мастера. `sendDelayNotice()` (`src/api/schedule.ts:1251`) по собственному комментарию пишет только в свой срез (`delayNotices[bookingId]`); нигде за пределами `src/areas/schedule` и `src/api/schedule.ts` это поле не читается — клиент никакого пуша не получает. Пункт «Готово, когда» не выполнен буквально.
   - Как понял: `grep -rn "delayNotice" src/areas src/api` — совпадений только в `schedule`.

2. **[major] F-00-064 — создание повторяющейся серии практически «зависает».** Действием создал серию (каждые 3 дня, 6-недельный горизонт): записи реально появляются один за другим, но с интервалом ~7–8 секунд НА КАЖДУЮ, кнопка «Создать серию» крутит спиннер без обратной связи по прогрессу. При полных ~14 повторах это далеко за 8-секундный порог «висит загрузка» из собственных правил проекта (`measure.mjs`) — обычный пользователь примет это за зависшую форму. Похоже на то, что `resolveOccurrence()` (`src/api/schedule.ts:1323`) при каждом повторе честно перебирает до `SERIES_MAX_SHIFT_DAYS=14` дней с двумя мок-запросами на попытку, и это никак не распараллелено и не показано пользователю прогрессом («создано 3 из 14»).
   - Повторил дважды (два разных мастера, две серии) — оба раза одинаково медленно.

3. **[minor/не решено] F-02-020 — подтверждение «Убрать из графика» не заменено 5-секундной отменой.** ТЗ прямо помечает это черновиком со знаком вопроса («❓ обсудить для этого действия»), поэтому не считаю это провалом «Готово, когда» — просто фиксирую расхождение с записанным ⭐-решением на случай, если решение примут: сейчас это модальное окно `Отмена`/`Всё равно убрать`, а не toast с «Отменить».

4. **[minor, вне раздела]** В момент замера параллельный агент правил `src/areas/client/memberships/MembershipsScreen.tsx` — в `.dev.log` виден `Parsing ecmascript source code failed` (незакрытый JSX). К `schedule` не относится, файлов не трогал, страницы `schedule` собирались и открывались нормально всё время.
