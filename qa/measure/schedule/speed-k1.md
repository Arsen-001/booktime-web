# schedule · speed-k1 — секундомер новичка

2026-09-25 · проверка «новичок с секундомером» (код не правил). Главный риск продукта — «клиент видит свободно, а
занято», поэтому отметить занятость должно быть можно **за 1–2 нажатия** (00 §1, F-00-054). Телефон 390×844,
персона individual (Мариам Нерсесян), ru. Снимки: `qa/shots/speed/t03-*`, `t04-*`.
Время — оценка для человека (нажатие ≈1,5 с, экран прокрутки ≈1,5 с); дев-сервер был перегружен.

## Замер

| Задача | Сейчас | Цель |
|---|---|---|
| Мастер отмечает «занято 14:00–15:00» сегодня | 7 нажатий + 3 экрана прокрутки, ≈30 с | 2 нажатия, ≤5 с |
| Мастер в режиме «всё занято» открывает окна на следующую неделю | 8 нажатий + прокрутка, ≈35 с | 2 нажатия |

Путь сейчас (T03): меню → «Мой календарь» → прокрутить до карточки «пятница» (каждая карточка дня ≈490 px, сегодня —
5-я) → первое пустое поле времени → 14:00 → второе → 15:00 → «Отметить занято».
Путь сейчас (T04): меню → «Мой календарь» → «Всё занято — открываю свободное» → «Следующий период» →
«Открыть весь день» × 4 рабочих дня (между ними прокрутка).

## Замечания

1. **major · «Мой календарь» открывается на понедельнике, а не на сегодня** — до сегодняшней карточки 3 экрана
   прокрутки. Как: при открытии прокручивать к карточке сегодняшнего дня (или показывать неделю списком коротких
   строк «пт, 25 · 10:00–18:00 · занято 14–15», а подробности дня — в `Sheet` по тапу).
      ✅ исправлено (fix-schedule): неделя — короткие строки (весь список на 1–2 экрана), сверху «Занято сегодня».
2. **major · отметить занятое — 7 нажатий вместо 1–2** (F-00-054 «провести пальцем по часам»). Как: у сегодняшнего
   дня — полоса часов (10…18) крупными клетками 44 px; тап по часу = занят/свободен, протяжка пальцем = отрезок;
   сверху чипы быстрых действий «Занят сейчас 1 ч» · «До конца дня» · «Открыть весь день». Сохранять сразу,
   тост «14:00–15:00 занято» с «Отменить». Было 7 → станет **2** (тап 14, тап 15 или одно протягивание).
      ✅ исправлено (fix-schedule): TodayHoursStrip — час одним нажатием, повторное — свободно; 1–2 нажатия.
3. **major · нет отклика после «Отметить занято»**: тоста нет, поля «с/до» не очищаются, появляется только маленький
   чип «14:00–15:00 ×» — новичок жмёт второй раз. Как: тост + очистить поля.
      ✅ исправлено (fix-schedule): тост «Занято 16:00–17:00 · Отменить», поля очищаются.
4. **major · пустые поля «с» и «до» без подписи** — две рамки с иконкой часов, placeholder не виден
   (`TimePicker placeholder={t('calendar.from')}` не рисуется). Как: подпись «с» / «до» внутри или над полями.
      ✅ исправлено (fix-schedule): подписи «С» / «До», ошибка у поля.
5. **major · нет «Открыть всю неделю»** (F-00-054, F-00-055). После смены режима баннер «На следующей неделе не открыто
   ни одного часа — клиенты не смогут записаться» есть, но действия в нём нет. Как: в баннер — primary-кнопка
   «Открыть по рабочим часам» (все рабочие дни недели по шаблону за раз), тост с «Отменить». Было 8 → **2** нажатия.
      ✅ исправлено (fix-schedule): «Открыть по рабочим часам» (баннер и «Ещё»), один запрос, «Отменить».
6. **major · «Как на прошлой неделе» говорит «Скопировано с прошлой недели», когда копировать было нечего** —
   ничего не открылось, а тост зелёный. Как: если на прошлой неделе нет открытых окон — кнопка неактивна с подсказкой
   «На прошлой неделе окон не было» или тост-предупреждение «Нечего копировать».
      ✅ исправлено (fix-schedule): «На прошлой неделе нечего было копировать».
7. **minor · случайный тап «Добавить перерыв» сразу меняет график** (появился перерыв 13:00–14:00 без вопроса и без
   «Отменить»). Как: тост «Перерыв добавлен» с «Отменить».
      ✅ исправлено (fix-schedule): перерыв — в шторке дня, сохраняется только «Сохранить» с «Отменить».
8. **minor · в каждой карточке дня 8 пунктов выпадающего списка типа дня** («Больничный», «Прогул», «Оплачиваемый
   выходной»…) — для мастера-индивидуала лишнее; прятать редкие типы в «Ещё».
      ✅ исправлено (fix-schedule): «Работаю / Не работаю», редкие типы — в «Причина».
9. **minor · нет пути из журнала** (стартовая страница мастера) к отметке «занято»: мастер открывает приложение на
   журнале и не видит, где закрыть час. Как: в журнале у своей колонки долгий тап по пустому часу → «Занято» /
   «Новая запись» (просьба к journal — совместно).
      ⏳ позже (fix-schedule) — журнал (путь journal).
