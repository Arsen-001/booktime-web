## Найденное между делом

1. **major — `src/ui/Stepper.tsx:90-98`.** Активная подпись шага в десктопном степпере не
   ограничена по ширине (`whitespace-nowrap` без `max-width`/`truncate`) и при длинном тексте
   («Время до начала визита») наезжает на кружок-номер следующего шага. Воспроизведено действием на
   `/biz/schedule/slots` → «Редактировать правила» → фиксированный тип → шаг 4.
   Снимок: `qa/shots/schedule/g3-1-m1/wizard/biz-schedule-slots__owner-nails-ru-light-desktop__10-fixed-back-to-step4.png`.
   На телефоне бага нет (свой блок «Шаг N из 5»). Общий компонент — может проявиться в других
   визардах проекта, не только в schedule.
2. **minor (повтор из m0, подтверждено снова действием) — выделение ячеек в F-02-005** — сплошная
   заливка primary вместо «пунктирного предпросмотра» по букве ТЗ; по смыслу эквивалентно (видно,
   что выбрано, до сохранения).
3. **Наблюдение, не дефект** — создание серии из 15 записей идёт заметно (мок 400–1200 мс на
   попытку × до 15 попыток ≈ 6–18 с), но UI честно показывает прогресс «Создаём записи: N из 15» —
   не зависание, соответствует конвенции «отклик на каждое действие».
