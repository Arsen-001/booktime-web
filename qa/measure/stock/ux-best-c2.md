## 1. Смена единицы не портит введённое количество (major)
- **У них [видел]:** Altegio, приход: строка «Тест гель-лак · 1500 ֏ · 0.2 фл · 300»; смена единицы в выпадашке пересчитала уже
  введённые «2» в «0.2» (`c-06-receipt-unit-bug-0_2.jpg`, `CYCLE-REPORT.md`, «Ошибки Altegio»).
- **Сделать:** единица выбирается **до** количества (по умолчанию — единица товара), а смена после ввода показывает пересчёт явно:
  «2 фл = 20 мл» и не меняет смысл введённого без подтверждения. Рядом — итог строки «2 фл · 3 000 ֏».

## 2. Количество — в одной понятной форме с обеими единицами (minor, Р11)
- **У них [видел]:** Altegio, «Складские операции»: «−0.2 флак. (−2 мл)», «2 флак. (20 мл)» — и тара, и объём (`c-06-storage-ops-writeoff.jpg`).
  Приём хороший, но дробь тары («0.2 флак.») мастеру ни о чём не говорит.
- **Сделать:** основная — единица расхода «−2 мл», в скобках тара «(0,2 фл)». Остаток — «осталось 18 мл · ≈9 процедур» (из техкарты).

## 3. Три способа добавить товар в документ — один поиск (minor, Р2)
- **У них [видел]:** Altegio, приход: три кнопки во всю ширину — «+ Добавить товар», «Добавить из списка», «Загрузить из Excel»,
  а над ними пустые поля документа (`c-06-receipt-unit-bug-0_2.jpg`).
- **Сделать:** одно поле «Найдите товар или отсканируйте код» с выпадающим списком; под ним чипами — 5 товаров, которые приходовали
  последними («как в прошлый раз»). «Загрузить из Excel» — в «⋯».

## 4. Пустые черновики не остаются (minor)
- **У них [видел]:** Altegio: после удаления строк документ прихода остаётся открываемым по адресу пустым («Итого 0»), удалить его
  целиком кнопки нет (`CYCLE-REPORT.md`).
- **Сделать:** документ без строк не сохраняется; черновик, из которого удалили всё, удаляется сам с тостом «Черновик удалён · Вернуть».
