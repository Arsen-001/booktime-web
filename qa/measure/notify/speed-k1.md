1. **major**: через 10–15 минут после конца записи мастеру — уведомление «Нане пришла? 7 000 ֏» с кнопками
   «Пришла» / «Не пришла» прямо в уведомлении (и в колокольчике кабинета); «Пришла» открывает шторку суммы
   (подставлена) + «Готово». Это самый быстрый путь для F-00-127 — мастеру не нужно искать запись в журнале.
   - ⏳ позже (notify-b01-fix1) — требует движка «событие → тип → каналы» из b01-каркаса плюс интеграцию со статусом
     визита в journal (чужой раздел); не в списке 4 дефектов этой пачки, беру в следующую доделку.
2. **minor**: в воскресенье — «Откройте окна на следующую неделю» (F-00-055) с кнопкой, которая сразу открывает
   неделю по графику (см. schedule/speed-k1 п.5).
   - ⏳ позже — то же, вне бюджета этой пачки.
