# notify — измерение доделки g2-2 (m0)

Раздел `notify`. Проверял живыми действиями через `scripts/measure.mjs` (32 стр. baseline + 8 hy +
10 сценариев с кликами) под персоной `owner`/`network`, сфера `nails`, телефон 390×844 и десктоп
1440×900, ru/en, hy — только сырые ключи/шрифт. Браузеры закрыты (headless, через `pw-slots`, слот
освобождён каждым прогоном).

**Baseline** (`qa/measure/notify/g2-2-m0-report.json`): 32 стр., 0 ошибок консоли, 0 4xx/5xx, 0 сырых
ключей, 0 вылетов по ширине, 0 зон нажатия < 40px, 0 «висит загрузка», data-f найдено 37 id.
**hy** (`…-hy-report.json`): 8 стр., 0 ошибок, 0 сырых ключей, армянского текста на экране нет (hy
по правилам проекта сейчас выключен — `CONVENTIONS.md §0.4`, «hy НЕ пишем и НЕ проверяем»), поэтому
это ожидаемое поведение, не дефект.

## Права (F-05-110…113) — общий итог

Ни разу не прогонял живым переключением на персону без соответствующего права (`notify.manage`,
`notify.mailings`, `notify.log`, `clients.phones`) — в бюджете этого замера не хватило времени на
полный набор персон × прав. Это осталось непроверенным и для builder'а («не прогонял живым
переключением персоны» — дословно в `qa/build/notify-g2-2.md`), так и осталось. Рекомендация
следующему кругу — целиком отдельная пачка «права».
