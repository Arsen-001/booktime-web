# Замер g1-1 · раздел «Уведомления» (notify)

Измеритель, доделка g1-1. Персона по умолчанию — owner (владелец), сфера nails, если не сказано иное.
Автосвип: `node scripts/measure.mjs --area notify --persona owner --lang ru,en --device phone,desktop`
(32 стр., 0 ошибок консоли/4xx/сырых ключей/вылетов по ширине/мелких целей/зависшей загрузки) —
отчёт `g1-1-m0-report.json`. Плюс 3 сценария с реальными кликами (`g1-1-m0-scen*.json`,
qa/scenarios/notify/g1-1-*.json) — 27+15+8 = 50 шагов, все прошли (одна ошибка селектора в моём
сценарии, не в продукте — исправлено и перепройдено). hy проверен отдельно (см. ниже): сырых ключей
нет, но и армянского текста нет вовсе — это НЕ баг, а следствие правила проекта «hy пока не пишем и
не проверяем» (CONVENTIONS §0.4) — экран на hy падает на fallback (не проверяю глубже).

Браузеры закрыты после каждого прогона (measure.mjs делает это сам).
