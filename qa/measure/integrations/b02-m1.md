Дата: 26.09.2026. Измеритель — код НЕ правил (только сценарии в `qa/scenarios/integrations/` и этот отчёт).

Дев-сервер: :3710 (`scripts/ensure-dev.sh`, не трогал чужой). Персона «разработчик» = `owner` (в ТЗ «разработчик —

Языки: ru, en (полный прогон), hy — только на проверку отсутствия сырых ключей/шрифта (по правилу 0.4 hy сейчас

## Как мерил

1. Статический снимок всех экранов пачки (`node scripts/measure.mjs --routes … --persona owner --lang ru,en --device phone,desktop`, 36 стр.) — ошибки консоли/4xx/сырые ключи/вылет по ширине/мелкие цели/зависшая загрузка.
2. 7 сценариев Playwright (`qa/scenarios/integrations/*.json`) — реальные действия: регистрация кабинета разработчика,
   создание приложения (публичного и приватного), прохождение всех 4 вкладок приложения, выпуск/отзыв ключей и
   токенов, сохранение доступа к API, переключатель вебхуков и сущностей, весь жизненный цикл заявки на модерацию
   (черновик → на модерации → демо-решение), проверка сохранения после полной перезагрузки страницы (`page.goto`).
3. Разворачивал раздел документации API и смотрел содержимое аккордеона.
4. Снимки смотрел глазами (7 экранов детально — Read png).

**Не проверено действием** (см. причины по F-id ниже): F-13-051 (реальный вызов API — в разделе намеренно нет
бэкенда), F-13-053/060/061/068/069/072 — то же самое: пункты «Готово, когда» описывают поведение настоящего
бэкенда/вебхука/AI-токена, которого в проекте нет по правилу раздела («только интерфейс, без настоящих
подключений» — см. код-комментарий в `AboutTab.tsx`). Для них смотрел ТОЛЬКО то, что можно проверить в интерфейсе
(поля видны, сохраняются, выглядят как в ТЗ), и это помечено отдельно, а не как «работает».
Межперсональная изоляция F-13-028 (другой сотрудник того же бизнеса не видит чужой кабинет) проверена ПО КОДУ
(`ownerStaffId`, не `businessId`, в `src/api/integrations.ts`), а не вторым живым браузером — persona меняется
только между независимыми запусками измерителя (свежий контекст/localStorage), а не внутри одной сессии, поэтому
живой кросс-персональный тест здесь не поставить без второго профиля. Это инференс из чтения кода, не факт,
подтверждённый действием — помечено ⚠️.
