## Найденные дефекты (сводка)

1. **MAJOR — F-13-018.** `activationDeadline()` (`src/domain/integrations.ts:171`) пишет дедлайн через `new Date(...).toISOString()`
   (UTC, с секундами и `Z`), а весь проект хранит «сейчас» в ереванском формате `YYYY-MM-DDTHH:mm` без `Z`
   (`nowDateTime()`, `src/lib/date.ts`). `isActivationOverdue()` сравнивает обе строки как есть — из-за разных
   форматов свежесозданный `pendingActivation`-install почти всегда считается «просроченным» СРАЗУ после подключения,
   а не через час. Видно в интерфейсе: подключаешь приложение → через <1с статус «Не работает» вместо «Ждём
   активации партнёром». Демо-кнопка «Продолжить активацию» в реальности не видна пользователю почти никогда.
   Снимки: `qa/shots/integrations/b01-connect/biz-integrations-apps-ia-2__owner-nails-ru-light-desktop__app-card-after-connect.png`,
   `qa/shots/integrations/b01-misc/biz-integrations-installed__owner-nails-ru-light-phone.png` (пример «АвтоЗвонок»).
   Это раздел integrations (свой домен), можно чинить самим.

2. **MAJOR — F-13-015.** `ConnectSheet` получает `availableLocationIds={locationIds}` (все локации бизнеса) в
   `AppScreen.tsx:276` — без вычитания локаций, где приложение уже подключено. В листе подключения такие локации
   показываются обычным выбираемым чекбоксом. Снимок: `qa/shots/integrations/b01-connect/biz-integrations-apps-ia-2__network-nails-ru-light-desktop__connect-sheet-multi-location.png`.

3. **MAJOR — F-13-008.** На карточке приложения нет хлебных крошек с категорией («Интеграции · <категория>») —
   только «← Назад». Для скрытых категорий (chatbots, tips) это единственный путь по ТЗ узнать категорию с самой
   карточки; сейчас узнать неоткуда. Снимки: любые `*apps/ia_*` в `b01-connect/`, `b01-misc/`.

4. **MINOR — F-13-009.** В каталоге раздела нет ни одной карточки без блока цены («только Подключить») — критерий
