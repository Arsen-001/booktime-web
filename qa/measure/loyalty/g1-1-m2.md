## Свежая проверка m2 (действием, сегодня)

### 1. F-06-030 — устройство удаления типа карты сменилось (наблюдение + повторное подтверждение дефекта)

Код изменился со времени m1: список «Типы карт» теперь имеет вкладки «Активные»/«Архивные», а на карточке
типа кнопка «Удалить тип» видна **только при `issuedCount === 0`** (`CardTypeFormScreen.tsx:374`,
комментарий в коде `questions-q4 В-40: «Удалить» только у типа без выданных карт — у остальных подсказка
«В архив»`). У типа «Постоянный гость» выдано 44 карты — кнопки «Удалить» у него теперь нет вообще, вместо
неё подсказка **«Есть 44 выданные карты — удаление недоступно, отправьте тип в архив»** и кнопка
«Архивировать». Текст диалога подтверждения удаления (`deleteConfirmText`) тоже упростился до «Действие
необратимо» — предупреждения про выданные карты в нём больше нет, потому что удалить с картами теперь
физически нельзя. Это осмысленное дизайн-решение по В-40, не самовольный отход (в `00-our-decisions.md`
для раздела `loyalty` — «Наши функции раздела: —», совпадающих решений нет), помечаю **assumed** в пользу
сборщика — но фактически критерий «Готово, когда» — «удаление требует подтверждения с предупреждением про
выданные карты» — для типа С картами теперь неприменим буквально (нет ни удаления, ни этого текста
предупреждения); для типа БЕЗ карт (`issuedCount === 0`) в этом заходе не проверял отдельно (не входит в
список изменённых файлов, бюджет).

Прошёл вживую новый путь — архивирование: открыл «Постоянный гость» → «Архивировать» → тост «Тип
отправлен в архив» → кнопка сменилась на «Восстановить» (подтверждено скриншотом
`…03-after-archive.png` / `…fail-5.png`) → **жёсткая навигация** (`goto` на тот же URL, не мягкий переход)
на список → **тип снова во вкладке «Активные» (счётчик 1), вкладка «Архивные» пуста** (EmptyState «В
архиве пока пусто»). То есть архивирование в рамках сессии работает и видно пользователю, но **не
переживает перезагрузку** — тот же фундаментный дефект `QuotaExceededError` в `src/mock/db.ts`
(`[mock-db] не удалось сохранить в localStorage QuotaExceededError: ... exceeded the quota`), что в m0/m1,
подтверждён заново свежим действием на новом UI-пути. Второй пункт критерия («после удаления карт этого
типа нет у клиентов») по-прежнему **major** — не мой путь, фундамент.

- **Вылет по ширине** — 0 (phone 390×844, desktop 1440×900).

- **Пусто / загрузка / ошибка** — EmptyState вкладки «Архивные» настоящий: иконка, текст «В архиве пока
  пусто», без кнопки первого действия (архивировать можно только из карточки существующего типа — логично
  для пустого архива). Видел свежо в `…05-archived-tab.png`.

- **Права (чужая персона не видит)** — не проверял отдельно в m2 (F-06-175/176/177 block по отсутствию
  экрана — «чужая персона не видит» неприменимо, экрана нет ни у кого).
- **Снимки глазами** — просмотрел все свежие снимки (список типов, форма типа с новой подсказкой про 44
  карты и кнопкой «Восстановить», список после hard-nav, пустой архив): наложений, обрезки, слишком
