## Дефекты

1. **[major] `/biz/loyalty/deposits/types` — ошибка гидратации в hy.** При языке hy (телефон и
   десктоп, персона owner) консоль даёт: `Hydration failed because the server rendered HTML didn't
   match the client` + «Can't perform a React state update on a component that hasn't mounted yet».
   На ru/en та же страница — 0 ошибок. Экран после самопочинки Reactʼом выглядит нормально (текст на
   русском — ожидаемый fallback), но ошибка реальная и воспроизводимая. Снимок:
   `qa/shots/loyalty-m1-hy/biz-loyalty-deposits-types__owner-nails-hy-light-phone.png` (бейдж «2 Issues»
   внизу). Не относится к F-06-135 напрямую по тексту, но экран принадлежит этой функции — чинить в
   `src/app/biz/loyalty/deposits/types` (side-effect в рендере, судя по тексту ошибки).

2. **[major] `/biz/loyalty/auto-apply` — ошибка роутера на пустом бизнесе.** Персона `owner-empty`,
   ru, десктоп: консоль — `Internal Next.js error: Router action dispatched before initialization`.
   Экран визуально рисуется правильно (пустое состояние «Для использования акций необходимо завести
   хотя бы один тип карт»), но ошибка попадает в консоль при каждом заходе нового бизнеса на эту
   страницу (частый путь: b01 «Быстрый старт» → сразу открыть автоприменение). Не воспроизводится у
   `owner` с непустыми данными. Снимок: `qa/shots/loyalty-m1-auto2/biz-loyalty-auto-apply__owner-empty-nails-ru-light-desktop__full.png`
   (бейдж «1 Issue»). Относится к F-06-078/F-06-079/F-06-080.

3. **[minor] F-06-100 «Сертификаты» — нет колонок «место продажи» / «место использования».** ТЗ явно
   требует их в списке сети; в демо (один адрес) могли быть скрыты намеренно (решение F-00-049 —
   бизнесу с одним адресом «сеть» не нужна), но пункт ТЗ не помечен как снятый в `00-our-decisions.md`
   для loyalty (там «—», решений нет). Нужна сверка с автором раздела: скрывать колонки для
   одноадресных бизнесов или показывать всегда.

4. **[minor] F-06-105 «Типы абонементов» — вкладки Активные/Архивные тесны на телефоне 390px.**
   Вкладка «Архивные типы абонементов» обрезана до одной буквы «A», справа — кружок-шеврон для скролла
   вкладок. Не вылет за экран (measure.mjs вылета не нашёл, цель ≥40px), но неудобно: не видно счётчика
   архивных типов без скролла табов. Снимок:
   `qa/shots/loyalty-m1-empty/biz-loyalty-memberships-types__owner-empty-nails-ru-light-phone.png`.
