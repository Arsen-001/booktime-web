## Отдельная находка (за рамками одного F-id)

**Клик по строке списка абонементов не открывает карточку абонемента.** На `/biz/loyalty/memberships`
клик по названию абонемента в мобильной карточке (`text=Маникюр × 5`) не переводит на
`/biz/loyalty/memberships/{id}`, хотя в коде `Table.tsx` (мобильные карточки, стр. 356–390) и
`MembershipsScreen.tsx` (`onRowClick={(r) => router.push(...)}`) переход заявлен и должен работать.
Прямой переход по URL на `/biz/loyalty/memberships/lm_biz_nuri_1` открывает карточку корректно — то есть
сам экран цел, сломан именно переход из списка. Это блокирует обычный путь пользователя к F-06-125 и
F-06-126 (владелец не может дойти до заморозки/правки баланса кликом, только зная ID в адресной строке).
Не привязано к конкретному F-id из батча — **major**, чинить в списке абонементов
(`src/areas/loyalty/MembershipsScreen.tsx` / `src/ui/Table.tsx`).
