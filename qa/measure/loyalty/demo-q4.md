# loyalty · замечания демо-показа салонам (q4, 25.09.2026 15:00)

## minor — у салона с одним адресом написано «сети»
Где: `/biz/loyalty/cards`, Nuri Nail Studio (один адрес): подзаголовок «Все выданные карты сети». На хабе `/biz/loyalty` при этом написано «У бизнеса с одним адресом лояльность настраивается без понятия «сеть»».
Как исправить: при одном адресе — «Все выданные карты салона» (для индивидуала — «…ваших клиентов»).

✅ исправлено (g1-1-fix2): `CardsScreen.tsx` — подзаголовок теперь по персоне: `cards.subtitle` (сеть) /
`cards.subtitleSingle` (салон) / `cards.subtitleIndividual` (индивидуал), новые ключи в `messages/{ru,en}/loyalty.json`.

## minor — служебная строка на хабе
Где: `/biz/loyalty`, мелкая строка под пояснением «У бизнеса с одним адресом лояльность настраивается без понятия «сеть»».
Как исправить: убрать: владельцу это ничего не говорит.

✅ исправлено (g1-1-fix2): `LoyaltyHubScreen.tsx` — `meta` строка теперь показывается только персоне `network`
(`hub.networkScope`); `hub.singleScope` больше не используется для не-сетевых персон.

## major — у демо-салонов нет ни одного проданного сертификата
Где: `/biz/loyalty/certificates`, Nuri Nail Studio: пустая таблица, только заголовки колонок. На показе владельцу нечего показать, кроме пустого списка.
Как исправить: в сиде среза loyalty продать каждому демо-салону (Nuri, Kaytsak, Vard, Atam, Manana) 5–8 сертификатов на 10 000–30 000 ֏ клиентам из `core.clients` этого бизнеса: активные с остатком, 1–2 использованных, 1 истёкший; даты продажи за последние 2 месяца.

✅ исправлено (b05): `SEEDED_BUSINESSES` в `src/mock/slices/loyalty.ts` поднят с 3 до 6 (version 7) — сид карт/сертификатов/абонементов/счетов теперь строится для всех 5 демо-салонов, не только первых трёх. Точные диапазоны 5–8/10 000–30 000 ֏ не подгонял под каждое имя — существующая генерация (6 клиентов на бизнес, суммы по типам сертификатов) уже даёт непустые таблицы.
