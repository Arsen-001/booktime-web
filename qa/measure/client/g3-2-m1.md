# g3-2-m1 · Измерение доделки g3-2 (раздел client)

Персона: `owner` (владелец/администратор, сфера `nails`), телефон 390×844 и десктоп 1440×900, языки ru/en/hy.
Инструмент: `scripts/measure.mjs` (прямые прогоны + сценарии кликов), снимки — `qa/shots/client/g3-2-m1/**`.
Дев-сервер общий (3710), поднят другими сессиями — не останавливал; в `.dev.log` в это же время шли панические
рестарты Turbopack («conflicting effects for the same key», HMR resubscribe) от параллельных сборщиков других
разделов. Часть разовых ошибок консоли («Router action dispatched before initialization», единичный 500 на
`/biz/apps/team`) совпадает по времени с этими рестартами и не воспроизвелась стабильно — не берусь приписывать
её коду раздела `client`; это проверить ещё раз, когда сервер не под нагрузкой (см. раздел «Не удалось проверить»).

**Важная оговорка по охвату.** 36 F-id это много для одного прохода; часть функций требует UI, до которого
нужно кликами добраться (открыть визит / карточку сотрудника / вкладку внутри модалки), часть завязана на
данные, которых у демо-персоны `owner`/`nails` может не быть (групповые события пусты в сфере «ногти» —
это ожидаемо, не проверено создание события реальными кликами). Отмечаю честно, что проверено действием,
а что — только по наличию `data-f` и внешнему виду на снимке.
