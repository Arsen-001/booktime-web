## major

1. **Запись на «выезд к клиенту» из приложения создаётся сразу и записывается как «в салоне»** (F-00-079, решено: «выезд — ВСЕГДА только с подтверждением мастера, не отключается»). Мастеру это опасно: время закрыто, а приехать некуда — адреса нет.
   - Проверено в браузере, контекст V:
     1. Клиентка открыла `/book?staff=st_vard_zara&service=sv_vard_brows_visit&slot=2026-09-26T10:00`. У этой услуги место только «выезд».
     2. Нажала «Подтвердить запись».
     3. В базе запись `workplace: 'salon'`, `status: 'scheduled'`. В «Моих записях» она «Подтверждена». Адрес не спрашивали.
     4. Снимок: `c-book-zara-visit.png`.
   - Для сравнения: у Давида (индивидуал, весь график — выезд) запись правильная, «Ждёт подтверждения». Значит, ошибка в выборе места: оно берётся из графика, а не из услуги.
   - Где:
     - в `BookAppointmentInput` нет поля `workplace` (`api/client.ts:537`), поэтому `bookAppointment` его не передаёт;
     - `planBooking` берёт место из графика (`slot.workplace`);
     - в `BookScreen` нет шага «Где» и нет поля адреса.
   - Как исправить:
     - место записи брать из `service.workplaces`. Если место одно — его. Если мест несколько — шаг «Где: в салоне / у меня дома / выезд ко мне», как в `online/booking/BookingWizard.tsx`;
     - передать `workplace` в `placeBooking`, тогда ядро само даст «Ждёт подтверждения»;
     - для выезда спросить адрес: он виден только мастеру после подтверждения (F-00-080). Проверить район по `staff.visitDistricts`;
     - окна для выезда считать по графику выезда (`getBookingDays` с `workplace`).
