## 1. Ресурс — для чего он и насколько занят (major, Р33)
- **У них [видел]:** Altegio «Ресурсы»: таблица «Название · Описание · Количество 1» и карандаш (`c-11-resource-list.jpg`). Каким услугам
  нужен кабинет и занят ли он сегодня — не видно.
- **Сделать:** строка ресурса — «Кабинет 1 · нужен для 3 услуг · сегодня занят 4 ч из 10». Тап — день этого ресурса в журнале
  (вид по ресурсам, `c-11-journal-resource-view.jpg`).

## 2. Освободилось окно — сразу предложить из листа ожидания (major, Р31)
- **У нас [видел, в соседнем разделе]:** у клиента в «Моих записях» есть блок «Мой лист ожидания — сообщим, когда освободится»
  (`qa/shots/ux-best-c3/flow/book-5-after-confirm.png`).
- **Сделать:** когда в журнале отменяют запись, в тосте отмены — «Это время ждут 2 клиента · [Предложить]». Предложение уходит пушем первому
  по очереди. **[вывод]** У Altegio лист ожидания есть (`c-05-waitlist-*`), но сам он окно не предлагает.

⏳ позже (b01-fix1) — то же самое (`notifyFreedSlot`).

## 3. Групповое событие — свободные места в каталоге клиента (minor, Р8)
- **У них [видел]:** Altegio: групповая услуга создаётся типом «Групповое событие» (`c-11-group-service-created.jpg`).
- **Сделать:** у клиента в «Свободно рядом» групповое занятие видно как окно «Йога 19:00 · осталось 2 места из 8». Запись — теми же
