# Демо для салонов · замечания разделу clients · q1 (2026-09-25)

Сид ядра обновлён (SEED_VERSION 3): у салонов теперь 60–90 клиентов, у индивидуалов 28–35, у каждого мастера есть свои постоянные. Смотрел `/biz/clients` под owner (nails, hair) и individual (barber), десктоп.

## major · Список по умолчанию начинается с клиентов без визитов
- Где: `/biz/clients`, таблица «Клиентская база».
- Что не так: первые строки — «Продано 0 ֏ · Визиты 0 · Последний визит —». Владелец на показе видит пустую базу, хотя в ней десятки постоянных.
- Как исправить: сортировка по умолчанию — «Последний визит, новые сверху» (клиенты без визитов — в конце).
✅ исправлено (fix-clients): сортировка «Последний визит, новые сверху», без визитов — в конце

## major · Отрицательный «Баланс счёта» у обычных клиентов выглядит как долг
- Где: там же, колонка «Баланс счета» (−7 000 ֏, −9 500 ֏, −88 500 ֏ красным) — значения из сида среза clients.
- Что не так: у демо-клиентки «Ани Мелкумян» «−9 500 ֏» при одном визите. Владелец спросит «она мне должна?». Для показа это пугает и не соответствует записям (записи в сиде не имеют долгов).
- Как исправить: в сиде среза держать баланс 0 у большинства, долг — у 1–2 клиентов с понятной причиной; колонку «Баланс» показывать только если он не ноль (или прятать по умолчанию).
✅ исправлено (fix-clients): сид: у большинства баланс 0, ~1/12 — небольшая недоплата, ~1/8 — аванс; ноль в строке телефона не показывается

- `/biz/clients/[clientId]` ещё «Раздел строится» — ждёт раздела; на показе не открывать.
✅ исправлено (fix-clients): карточка построена
