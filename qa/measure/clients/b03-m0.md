## Найденные дефекты

1. **[major] Двойной тост «Визит добавлен» при сохранении визита.** Воспроизведено дважды подряд
   (сценарии `clients-b03-add-visit-newclient` и мой `persist`): после одного клика «Сохранить
   визит» на экране появляются ДВА одинаковых тоста «Визит добавлен» друг под другом. Данные,
   похоже, не дублируются (сегмент «Новый» вырос ровно на 1 при повторной проверке), но
   пользователю кажется, что сохранение сработало дважды/что-то не так — нарушает «Отклик на
   каждое действие» (CONVENTIONS §0). Снимки:
   `qa/shots/clients-b03-m0/clients-b03-add-visit-newclient/biz-clients__owner-nails-ru-light-phone__after-save-new.png`,
   `qa/shots/clients-b03-m0/persist/biz-clients__owner-nails-ru-light-phone__after-save.png`.
2. **[minor] Подписи вкладок карточки клиента обрезаются по бокам скроллера.** На телефоне
   (390 px) стрелки `‹ ›` перекрывают текст соседних вкладок — видно «иента» вместо «Профиль
   клиента», «визитов» вместо «История визитов», «Стати» вместо «Статистика», «В долг» неполный
   при листании фильтра. Функция работает (клики по вкладкам проходят), но с первого взгляда
   неясно, что это за вкладка — противоречит «Понятные слова»/«трёхсекундному» правилу.
   Снимки: `qa/shots/clients-b03-m0/clients-b03-card-tabs/*history-tab.png`, `*stats-tab.png`,
   `*calls-tab.png`.
3. **[minor] Автокомплит подсказки услуги перекрывает кнопку «Добавить услугу» без явного разрыва.**
   Всплывающая опция `+ Добавить «…»` в поле «Название услуги» ложится поверх соседней кнопки —
   читаемо, но выглядит как один слипшийся блок. Снимок:
   `qa/shots/clients-b03-m0/persist/biz-clients__owner-nails-ru-light-phone__before-save.png`.

## Что НЕ проверено (честно, не додумываю)

- F-04-038/039/040/041 (тексты рассылок, PUSH, справочник категорий) — прошёл только по коду/
  data-f и self-report сборщика, реальными кликами по формам не гонял (бюджет круга).
- F-04-091 (строка «Посетители») — не нашёл клиента с посетителем под рукой за отведённое время;
  нужен целевой id из мока.
- F-04-095, F-04-156 (уведомление мастеру), F-04-226 (сам процесс отмены записи) — требуют выхода
  в чужие разделы (`journal`/`notify`/`reports`), не проверялись.
- Устойчивость к перезапуску браузера (не в рамках одной сессии Playwright) — `measure.mjs` создаёt
  новый контекст на каждый вызов, так что «пережило перезагрузку» подтверждено только в пределах
  одного прогона (`goto` в той же сессии, тот же localStorage); полный рестарт браузера не
  эмулировал.
- hy: по действующему правилу CONVENTIONS §0.4 армянский выключен и не проверяется по смыслу;
  проверил только то, что требуется — 0 сырых ключей, 0 ошибок консоли на `/biz/clients` и
  `/biz/clients/cl_001` (`qa/shots/clients-b03-m0/hy.json`). Экран, ожидаемо, весь на русском
  (фолбэк), это не баг при выключенном hy.
- Права «чужая персона не видит»: проверил только persona `master` на тех же двух маршрутах — 0
  ошибок, экран открывается (детальную проверку урезанных прав master по конкретным полям карточки
  не делал).
