## Опровергнуто

### [major] F-04-002 — клиент не находится по телефону в том виде, как он написан в таблице
- **Где:** `/biz/clients`, поле поиска + «Найти».
- **Что:** в таблице телефон показан как `+374 00 196 143`. Поиск `+374 00 196 143` → «не найдено ни
  одного клиента»; `196 143` → не найдено; `0 196` → не найдено. Находит только сплошные цифры
  (`00196143`, `+37400196143`). Код: `r.phone.includes(q)` без нормализации (`ClientsListScreen.tsx`, `searched`).
  Человек копирует номер из таблицы или вводит его с пробелами — и не находит клиента, который есть.
- **Как исправить:** для телефона сравнивать только цифры: `digits(r.phone).includes(digits(q))`, если в
  запросе есть хотя бы 3 цифры (так же для номера карты — без пробелов/дефисов).
✅ исправлено (fix-clients): поиск по цифрам: «+374 00 196 143», «196 143», «00196143» находят клиента (`matchesSearch`)

### [major] Права мастера на клиентскую базу (замечание m1 «для master «Добавить клиента» и «Операции с Excel» скрыты/задизейблены» — неверно)
- **Где:** `/biz/clients` и `/biz/clients/<id>` под персоной `master`.
- **Что:** у мастера по `src/config/permissions.ts` есть только `clients.view` (нет `clients.phones`,
  `clients.edit`, `clients.export`). На деле мастер видит все 90 клиентов салона с телефонами, кнопка
  «Добавить клиента» активна, «Операции с Excel → Выгрузить в Excel» отрабатывает («Выгружено 90 клиентов»),
  в карточке клиента есть «Изменить». В коде раздела нет ни одной проверки прав.
- **Как исправить:** через `usePermission` прятать телефоны без `clients.phones` (маска `+374 •• ••• 143`),
  «Добавить»/«Изменить» — без `clients.edit`, Excel — без `clients.export`; решить, видит ли мастер всю базу
  или только своих клиентов.
✅ исправлено (fix-clients): мастер: телефоны маскированы, «Добавить», Excel и «Изменить» нет, суммы скрыты; api проверяет права
