## Замечания

1. **major · список клиентов не читает `?q=` — общий поиск в шапке ничего не находит.** Шапка (и на телефоне, и на
   десктопе по Enter) ведёт на `/biz/clients?q=Гаяне` / `?q=878`, а поле поиска на странице пустое и показаны все
   клиенты (на десктопе 26 карточек вместо одной). Как: при открытии страницы брать `q` из адреса в поле поиска
   (и держать их в синхроне). Одна строка — и общий поиск начнёт работать.
   ✅ исправлено (fix-clients): поле берёт `?q=` из адреса и следит за ним; ввод пишет `?q=` обратно
2. **major · найденный клиент на 579 px — ниже половины экрана** (k2 п.2). Над списком: «Добавить клиента»,
   «Операции с Excel», «Добавить визит» (три кнопки во всю ширину), поиск, «Фильтры», 5 сегментов, «Лиды из чата».
   Карточка клиента в списке — 265 px высотой, на экран влезает 2,5 клиента.
   Как: на телефоне «Операции с Excel» и «Добавить визит» — в «⋯»; сегменты — одной прокручиваемой строкой; строка
   клиента — 64–72 px (имя, телефон, последний визит), остальные цифры — в карточке. Поиск — первым под заголовком.
   ✅ исправлено (fix-clients): см. speed-k1 №2
3. **major · из карточки клиента нельзя записать его** (k2 п.3). Главные кнопки карточки — «Добавить визит» (это
   прошлый визит без записи в календаре, форма «Мастер* / Дата* / Время* / Услуги / Оплачено») и «Изменить».
   Администратор, у которого клиент на трубке, ищет «Записать».
   Как: primary «Записать» → окно новой записи журнала с этим клиентом и его прошлой услугой (`/biz/journal?new=1&client=…`,
   если журнал примет параметр — просьба в `qa/requests/clients.md` к journal). «Добавить визит» — secondary или в «⋯».
   ✅ исправлено (fix-clients): см. speed-k2 №3
4. **minor · поле общего поиска на телефоне не в фокусе после открытия.** Тап по лупе → шторка → надо ещё раз тапнуть
   в поле (это фундамент, но смысл — для clients: результаты должны появляться прямо в шторке, по 3 цифрам, с переходом
   в карточку в 1 нажатие; просьба `searchProvider` клиентов, если фундамент его даст).
   ⏳ позже — шторка общего поиска — каркас (src/shell), не путь раздела
