## Что понравилось (проверено действием)

- Форма «Добавить клиента»: воздух, один primary («Добавить»), обязательные поля с `*`, телефон с
  несъёмным «+374» — ровно по CONVENTIONS.md §0. Toast «Клиент добавлен» + автопереход в карточку
  нового клиента.
- Меню колонок и фильтр «Важность» — приятная деталь: чекбокс «Имя» задизейблен (нельзя скрыть
  обязательную колонку), а его замок тоже задизейблен (`isName` в `ColumnsMenu.tsx`) — колонка-ссылка
  на карточку не может потеряться из вида. Не дефект, поведение осмысленное.
- Армянский (hy): весь основной текст экрана (заголовок, колонки, кнопки) корректно откатывается на
  русский без единого сырого ключа; меню слева и общие элементы (шапка, кнопка поиска) — на настоящем
  армянском шрифте (Հանախորդներ, Մատյան…), не квадраты. `m1`-прогоны — 0 ошибок консоли, 0 сырых ключей,
  0 вылетов по ширине, 0 мелких зон нажатия во всех 24+ страницах и во всех новых сценариях.
- Телефон 390×844: таблица → карточки, «Добавить клиента» — единственная заметная синяя кнопка,
  фильтры/сегменты не вылезают по ширине (`biz-clients__owner-nails-ru-light-phone.png`).
- Разделение данных между бизнесами (перенесено из m0, не перепроверялось действием в m1): Kaytsak
  Barbershop показывает свой список, не пересекающийся с Nuri Nail Studio.
