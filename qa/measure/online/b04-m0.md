## Дефекты

1. **[BLOCK] F-03-130 — «Пакет услуг (комплекс)» не существует.** Ни сущности, ни онлайн-конфигурации, ни
   ограничения «один пакет за раз», ни выбора мастеров на услуги пакета. В сиде есть услуга с похожим словом в
   названии («Комплексная мойка»), из-за чего первый текстовый прогон измерителя ошибочно принял её за пакет —
   поправлено после проверки кода `src/domain/services.ts` и `src/mock/seed/services.ts:296`.
2. **[BLOCK] F-03-095 — политика «депозит / гарантия картой» отсутствует.** Есть только обязательная 100%-предоплата
   (F-03-094). Нет холда карты без списания, нет частичного депозита.
3. **[MAJOR] F-03-107 — кнопка продажи абонементов/сертификатов настраивается, но нигде не рендерится клиенту.**
   `onlineSalesNetworkId` сохраняется в `updateLink`, но ни один файл `src/areas/online/public/**` /
   `src/areas/online/booking/**` его не читает. Даже у сетевого бизнеса с включённой настройкой кнопка в виджете
   не появится — «Готово, когда» первый пункт не выполнен.
4. **[BLOCK] F-03-114 — «какой язык увидит клиент» не реализовано.** `BookingLink.defaultLocale` существует в
   данных, но не используется нигде на клиентских экранах для выбора языка по умолчанию у новых/неавторизованных
   клиентов — виджет всегда берёт язык из общего cookie приложения.
5. **[BLOCK] F-03-116 — формат даты/времени, страна и часовой пояс для виджета не настраиваются.** Сам проект уже
   фиксирует этот пробел в тексте ТЗ; поля нет ни в данных ссылки, ни в форме настроек.
6. **[MINOR] F-03-115 — перевод названий услуг/категорий работает, но не помечен `data-f`.** Функция есть
   (`pickText` по локали в `BookingWizard.tsx`), просто не размечена — влияет только на охват `fids.mjs`, не на
   пользователя.
