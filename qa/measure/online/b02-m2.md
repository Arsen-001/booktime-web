## Подробности проверки (действием)

### F-03-077 — код подтверждения телефона теперь обязателен
Сценарий `qa/scenarios/online/booking-submit-no-code.json` переигран как есть (guest, телефон 390px, ru):
имя+телефон заполнены, согласие поставлено, код **не запрошен** → нажатие «Записаться» **не создаёт запись**.
На экране под блоком кода красный текст «Подтвердите номер кодом, чтобы записаться» + такой же тост.
Скриншот: `qa/shots/online/b02-m2/scn-nocode/b-nuri-nail-studio-book__guest-nails-ru-light-phone__after-submit.png`.
Отчёт прогона: `qa/shots/online/b02-m2/scn-nocode/report.json` (0 ошибок консоли, все 23 шага сценария прошли).

### F-03-100 — после отмены можно записаться снова
Старый JSON-сценарий `booking-cancel2.json` больше не проходит автоматически дальше кнопки «Получить код»
(код теперь случайный — это уже отмечено сборщиком в `_note` самого файла и в `qa/requests/online.md`), поэтому
написал разовый Playwright-скрипт `qa/scenarios/online/b02-m2-verify-cancel-full.mjs` (читает код из текста
тоста, вводит его, доводит запись до конца, отменяет, проверяет итог) — **полный флоу проверен действием заново**,
не переиспользован отчёт сборщика:
1. Код получен и введён → «Номер подтверждён» → «Записаться» → запись создана.
2. «Отменить» → диалог «Отменить запись?» → «Отменить запись».
3. После обновления (проверено с запасом по времени, 2.5с) статус карточки — бейдж **«Запись отменена»**,
   и вместо старого ряда из 4 кнопок — **одна** кнопка **«Записаться ещё»**.
4. Клик по ней уводит на `/b/nuri-nail-studio/book`, шаг 1 из 4, выбор услуг — то есть реально можно
   записаться заново с этого экрана.

Скриншоты: `qa/shots/online/b02-m2/scn-cancel-full/03-cancel-confirm.png` (диалог), `04b-cancelled-longwait.png`
(итоговое состояние — бейдж + кнопка), `05-after-book-again-click.png` (переход на `/book`).

Отдельно отмечу для будущих замеров: первая попытка со скриншотом через 800мс после подтверждения отмены
(`04-cancelled.png`) поймала **гонку самого замера**, а не бага продукта — карточка ещё не успела
перерисоваться после инвалидации запроса, и на снимке видно старое состояние (бейдж «Вы записаны» + все 4
кнопки) поверх тоста «Запись отменена». Пересъёмка с 2.5с ожидания показала правильный итог. Оставляю оба
снимка как иллюстрацию для правила «не спешить со скриншотом после мутации».
