## 1. `src/api/online.ts:659` — семь неиспользуемых деструктурированных полей
- Серьёзность: **major**
- Где: `src/api/online.ts`, строка 659 (eslint `@typescript-eslint/no-unused-vars`) — `_locationIds`,
  `_showInWidget`, `_apiKey`, `_editableByUser`, `_showInAdminUi`, `_alwaysShowInEditWindow`,
  `_requiredOnArrived` внутри `.map(({ locationIds: _locationIds, … , ...field }) => field)`.
- Что не так: паттерн «деструктурировать и отбросить лишние поля через `...rest`» уже следует правилу
  проекта «неиспользуемое — с `_`», но текущий `eslint.config.mjs` не настроен с
  `argsIgnorePattern`/`varsIgnorePattern` под `^_` для деструктуризации объекта, поэтому лычка всё равно
  светится как warning — 7 штук в одной строке.
- Как исправить: в разделе — ничего (код уже сделан по конвенции); настройка `argsIgnorePattern: '^_'`
  (или аналог для деструктуризации) — файл фундамента `eslint.config.mjs`, не в путях раздела online,
  подниму хранителю фундамента отдельно через `qa/requests/build-q2.md`.

## 2. `src/api/online.ts:107` — сырой цвет `#060f07` вместо токена
- Серьёзность: **major**
- Где: `src/api/online.ts`, строка 107: `widgetButtonColor: '#060f07'`
- Что не так: `check-tokens.mjs` ловит hex прямо в API-слое — значение по умолчанию для цвета кнопки
  виджета задано сырым hex, а не токеном/переменной темы.
- Как исправить: если это значение ПО УМОЛЧАНИЮ для настройки, которую бизнес выбирает сам (в
  `LinkSettingsScreen.tsx`/`WidgetScreen.tsx` ниже) — пометить строку комментарием `tokens-ok` (цвет
  из данных, не из компонента); если это цвет системной кнопки виджета — взять токен из
  `src/styles/tokens.css`.
