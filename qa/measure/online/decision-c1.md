## minor

2. **Адрес клиента для выезда видит владелец до подтверждения** (F-00-080, предл.: «адрес клиента видит только мастер,
   только после подтверждения»). `RequestsScreen.tsx:119–122` показывает `r.address` всем с `online.manage`
   (владелец/сеть) ещё в заявке. Как: в заявке — только район; адрес — мастеру этой записи после «Подтвердить».

3. **«Напомнить перед записью» обещано веб-клиенту без приложения** (F-00-120 — решено: напоминания только пушем из
   приложения; платных SMS/WhatsApp нет). В мастере записи по ссылке (`BookingWizard.tsx:967`, тексты
   `booking.details.reminder*`, «пуш-напоминания включены») человек в браузере выбирает «за 60 минут», но пуш ему прийти
   некуда — выполнить обещание можно только платным SMS/WhatsApp. Как: для веба — «Напоминания приходят в приложении»
   + ссылка скачать; выбор времени — только если вход из приложения. Текст `codeSentDemo` «…WhatsApp/Telegram/SMS» —
   SMS только как запасной канал (F-00-032).

4. **Мастер «Только мои клиенты» недоступен по ссылке даже своим клиентам** (F-00-065: «его клиенты видят его окна и
   записываются»; предл.: «чужой по ссылке — только заявка»). `isStaffOnlineVisible` (`online.ts:159`) убирает такого
   мастера со страницы целиком. Как: показать мастера с пометкой «Записывает только своих клиентов»; незнакомый номер —
   запись в статусе «ждёт подтверждения» (заявка), свой клиент (есть визит) — как обычно.

5. **Публичная страница отдаёт `Staff` целиком — с `homeAddress`, телефоном и логином** (F-00-077/F-00-010). Уже в
   `arch-a1.md` №5 — подтверждаю как нарушение решения «точный адрес дома — только после подтверждённой записи».
