## Права и состояния — что измерил инструментально

- **Права:** персона `master` (нет `online.manage`) на `/biz/online` получает **не** пустой экран, а
  честную заглушку `PermissionGate`: иконка замка + «Нет прав на это действие» / «Попросите владельца
  открыть доступ», `data-f` = 0 (страница реально не рендерится дальше). Персона `owner` видит 8 меток
  `data-f`. Снимок: `qa/shots/online/b01-perm/biz-online__master-nails-ru-light-phone.png`.
- **Консоль/сеть:** по прямому прогону `--area online` (40 страниц: owner, ru/en, тел/деск, все
  4 роута раздела + `/b/nuri-nail-studio` + 5 `/dev/ext/*/online`) — **0 ошибок консоли, 0 предупреждений,
  0 ответов ≥400, 0 сырых ключей, 0 вылетов по ширине** ни на одной из 40 страниц. Отчёт:
  `qa/measure/online/b01-report.json`.
- **hy:** на `/b/nuri-nail-studio` шрифт армянских букв настоящий (веб-шрифт, не квадратики) для owner и
  guest. На `/biz/online` (owner) инструмент не нашёл армянского текста на экране вообще — похоже,
  весь видимый текст этой страницы ушёл в откат на русский (`hy→ru` фолбэк = 42 случая суммарно по
  4 страницам замера), сырых ключей при этом не было. Это ожидаемо, если раздел ещё не добрал переводов
  до финала — не блокер по правилам проекта, но стоит отметить отдельно от «шрифт не работает».
- **Зоны нажатия < 40px:** 3 разных элемента, все — инлайновые текстовые ссылки внутри заголовков
  (название ссылки 22px, URL-строка 20px, имя бизнеса 33px), не кнопки. Технически меньше порога, но
  это типичный паттерн текстовой ссылки, а не непопадание пальцем по кнопке.
- **Путь клиента по ссылке — сквозной сценарий** (`qa/scenarios/online/b01-client-path.json` +
  `b01-full-wizard.json`, живые клики Playwright, не снимки): `/b/nuri-nail-studio` → клик «Записаться»
  (F-03-012) → визард `/b/nuri-nail-studio/book`, шаг 1/4 «Услуги» → клик по услуге → чекбокс встал,
  кнопка «Продолжить» разблокировалась. Дальше (выбор мастера/времени/деталей/подтверждение) не прошёл —
  бюджет прогона кончился на этом шаге, это честно записано как «не проверено» у F-03-084/090/091/093/097/098,
  а не как «работает».
