Сервер: `scripts/ensure-dev.sh` (порт 3710, уже работал — не трогал). Персона `owner`, сфера `nails` (Nuri Nail
Studio), десктоп 1440×900 и телефон 390×844, языки ru/en; hy — только сырые ключи и шрифт (проверка вложена в
`measure.mjs`). Инструменты: `scripts/measure.mjs --area online` (48 страниц, полный отчёт
`qa/shots/g1-1-m0/report.json`) + свои сценарии `qa/scenarios/online/g1-1-*.json` (клики в реальном браузере,
Playwright, отчёты `qa/shots/g1-1-m0/*-report.json`, снимки `qa/shots/g1-1-m0/scenario/`).

Сначала прогнал `grep -rl "F-03-0NN" src/ messages/` по каждой из 30 функций пачки — так сразу разделил их на
«есть код с `data-f`» и «нет нигде» ещё до захода в браузер; дальше по «есть» ходил в браузер и проверял каждый
пункт «Готово, когда», по «нет» — перечитал сам блок ТЗ, чтобы не считать функцией то, что наше решение
уже сняло другим способом.

## Итог

**checked (пунктов «Готово, когда»): 47 → passed: 21**. 17 функций из 30 не построены вообще (нет `data-f` в
коде и на экране, «функции нет») — это единственная причина большинства ❌ ниже: если функции нет, ни один её
пункт не мог быть проверен «действием», и он засчитан невыполненным.

Общий замер по 48 страницам раздела online (`report.json`): ошибок консоли 0, предупреждений 0, 4xx/5xx 0,
сырых ключей 0, горизонтального вылета 0, зон нажатия < 40px 0, «висит загрузка» 0 — сама инфраструктура раздела
чистая, проблема именно в недостроенных функциях этой пачки.
