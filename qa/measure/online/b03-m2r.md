## 🔴 БЛОКЕР — весь дев-сервер отдаёт HTTP 500 на любой адрес (не мой раздел, не online)

Проверено действием только что (curl, а не предположение):

```
$ curl -s -o /dev/null -m 10 -w 'health:%{http_code}\n' http://localhost:3710/dev/health
health:500
$ curl -s -o /dev/null -m 10 -w 'online:%{http_code}\n' http://localhost:3710/biz/online
online:500
$ curl -s -o /dev/null -m 10 -w 'routes:%{http_code}\n' http://localhost:3710/dev/routes
routes:500
```

Тело ответа `/biz/online` (обрезано) — Next.js отдаёт страницу ошибки компиляции для **любого**
маршрута, потому что Turbopack не может собрать `src/areas/platform/OverviewScreen.tsx`:

```
"message":"./src/areas/platform/OverviewScreen.tsx:7:1\nError: Export listCallbacksToday doesn't
exist in target module\n ... The export listCallbacksToday was not found in module
[project]/src/api/platform/index.ts [app-client] (ecmascript). Did you mean to import listCallbacks?"
"Import trace": "./src/areas/platform/OverviewScreen.tsx" → "./src/app/platform/page.tsx"
```

`.dev.log` подтверждает вторую постоянную ошибку в том же модуле:

```
Error: Export SPHERE_SERVICE_TEMPLATES doesn't exist in target module [project]/src/api/platform/index.ts
  at src/areas/platform/ConnectScreen.tsx
```

Проверено в исходниках (только чтение, не правил — файл не мой):
`src/api/platform/index.ts` не реэкспортирует `SPHERE_SERVICE_TEMPLATES` (объявлена только внутри
`src/api/platform/connect.ts:27`) и не реэкспортирует `listCallbacksToday`, хотя `OverviewScreen.tsx`
её импортирует из барреля `@/api/platform`. Это внутренняя недоделка раздела **platform**
(нарушение его же барреля из CONVENTIONS §2: «API — папка с `index.ts`, реэкспортирующим всё») —
не мой код, не трогаю.

**Это тот же самый блокер**, что был зафиксирован в `b03-m2.md` (предыдущий заход) — за прошедшее
время он не исправлен. Дев-сервер (`node … next dev -p 3710`, PID 17098, поднят ещё в 02:39, сейчас
06:52) я не останавливал, как и требует правило «работающий сервер никогда не убивать»; `ensure-dev.sh`
корректно сообщает «уже слушает» — сервер жив, но Turbopack держит один общий скомпилированный бандл
и падает при рендере ЛЮБОЙ страницы, пока в дереве есть эта ошибка компиляции, даже у страниц без
единой связи с `platform` (root layout инициирует общий build).

**Следствие:** ни один сценарий `scripts/measure.mjs` не смог загрузить `/biz/online`,
`/biz/online/page`, `/biz/online/widget`, `/biz/online/settings`, `/biz/online/places`,
`/biz/online/requests`, `/b/<slug>`, `/dev/ext/*/online` — под любой персоной, языком, устройством.
«Готово, когда» проверяется реальным действием в браузере; действие невозможно, если браузер получает
HTTP 500 вместо страницы. Ни один из 57 пунктов «Готово, когда» по 32 функциям пачки не подтверждён.
