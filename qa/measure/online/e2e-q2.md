# online · сквозные сценарии e2e-q2

Дата: 2026-09-25. Проверка: сквозные цепочки `qa/e2e/` (итог — `qa/e2e/report-q2.md`). Повторить:
`node qa/e2e/run.mjs --only C05,C15`. Код раздела не правил.
Что работает: публичная страница салона без входа, запись по ссылке «мастер → услуги → время → детали» с кодом,
модалка «Кого принимает мастер», запись попадает в журнал с именем и в CRM по номеру (C15.S1–S4 ✅), страница нового
салона из «Подключить салон» и фото с визита (C11.S3–S4 ✅), экран «Правила записи» по мастерам.

## major

1. **«Правила записи» не пишут в ядро** (C05.S0, F-00-066, F-00-098). Гаяне → «Бесплатная отмена, часов до записи» = 72 →
   «Сохранить»: в срезе online `cancelWindowHours: 72`, `Staff.bookingRules` пуст. Приложение этого не видит (у него свой
   черновик, 24 ч), журнал тоже. По AREAS «Хозяева сущностей» online пишет поля ядра `Business/Staff.bookingRules`,
   `Staff.confirmMode`, `Staff.onlineBookingEnabled`. Как: сохранять `bookingRules.cancelWindowMin = часы × 60`,
   `rescheduleWindowMin`; читать через `effectiveBookingRules`; черновик среза удалить (поднять `version`).
2. **Запись по ссылке — мимо `placeBooking`** (C15.S5): статус и правила считаются своим кодом (`createOnlineBooking`).
   Сейчас по ссылке статус верный («сразу» → «Записан»), но две реализации разойдутся снова. Как: `placeBooking` ядра.
3. **Вкладка «Источник» в окне записи пуста для записи из приложения** (C01.S10, F-00-093): вкладка есть, внутри ничего
   (снимок пробы — `qa/e2e/probe.mjs admin "/biz/journal?date=…&booking=bk_0081" desktop --click 'role=tab[name="Источник"]'`).
   Как: для `source: 'app'` — «Записался через приложение», дата и время записи; пустой вкладке — EmptyState.

## minor

4. Напоминание в деталях записи: «За 60 минут / За 180 минут / За 1 440 минут» — людям «За час / За 3 часа / За сутки».
5. Код подтверждения по ссылке — случайный из тоста, в приложении клиента — всегда «0000»: два разных входа по номеру.
   Если это демо — одинаково в обоих местах; вход по ссылке не создаёт `AppUser`, поэтому «Мои записи» такому клиенту
   потом не показать (F-00-007, F-00-032).
6. На публичной странице кнопка «Личный кабинет клиента скоро будет здесь» — служебный текст людям.
