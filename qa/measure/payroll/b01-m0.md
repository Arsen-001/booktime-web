## 🔴 Корневая причина, из-за которой ломается «после перезагрузки»

На **чистом** браузерном контексте (без чужих правок, `newContext()` без storageState) уже на первом
сохранении в консоли:
```
[mock-db] не удалось сохранить в localStorage QuotaExceededError: ...
Setting the value of 'bp-mock-db' exceeded the quota. at flush (src/mock/db.ts:176)
```
Сид (демо-данные), которые пишутся при первой загрузке, уже больше лимита localStorage — до всякой
правки пользователем. UI при этом показывает **ложно-успешный** тост «Схема сохранена» /
«Настройки сохранены» — ошибка уходит в консоль, а не пользователю. Это фундамент
(`src/mock/db.ts`), не экран payroll — просьба записана в `qa/requests/payroll.md`. Ниже везде, где
пункт «после перезагрузки» помечен ❌, причина эта, а не логика payroll-экрана.
