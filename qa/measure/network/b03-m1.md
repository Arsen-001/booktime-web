## Как мерил

1. `node scripts/fids.mjs --area network` — все 31 функция пачки помечены `data-f` в коде (список путей — см. ниже). Структурно охват 100%.

## Найденные дефекты

### [BLOCK] Нет проверки прав на всех экранах сети — см. отдельный блок выше.
Затрагивает: все 31 функцию пачки (право на просмотр/правку сетевых сущностей персоной без сетевых прав).

### [MAJOR] #1 — F-11-081: в форме сетевой услуги нет поля «изображение»
ТЗ прямо перечисляет поле «изображение» в форме сетевой услуги, и проект сам объявляет фото у услуг решением по умолчанию (F-00-085, см. AGENTS/00-our-decisions). В снятой полной форме (`Название рус/англ/для записи → Категория → Вид услуги → Описание → Цена и длительность → Запреты в филиале → В каких филиалах`) поля загрузки фото нет ни в одном месте.
- Где смотрел: `qa/measure/network/shots-b03-full/biz-network-services-new__owner-nails-ru-light-phone__full.png`

### [MINOR] #2 — F-11-102: гонка при быстром клике по селектору сразу после захода на страницу
При сценарии «открыть `/biz/network/staff/migration` → сразу кликнуть на select "Из филиала"» словил ошибку консоли: `Internal Next.js error: Router action dispatched before initialization`. Экран при этом отрисовался и сработал корректно (список сотрудников филиала подгрузился), так что это, похоже, безобидная гонка роутера, а не сломанный экран — но консоль не должна кидать ошибку ни при каком клике. Не воспроизвёл повторно с более медленным сценарием (`shots-b03-scn6` — тот же клик прошёл чисто, 0 ошибок) — то есть флейк, зависит от тайминга.
- Снимок: `qa/measure/network/shots-b03-scn7/biz-network-staff-migration__network-hair-ru-light-desktop__location-picked.png` (внизу слева виден бейдж Next.js «1 Issue»)

### [MINOR] #3 — F-11-113: карточка сетевого товара не успела прогрузиться за 400мс в сценарии
Не факт, что дефект продукта — возможно, просто короткий `wait` в моём сценарии. `measure.mjs` штатным прогоном (не по сценарию) не показал «висящую загрузку» (`stuckLoading: false` на всех 60+ страницах) — то есть в норме экран догружается быстро, я просто рано сфотографировал. Отмечаю на будущее, не как реальный баг.

### [MINOR] #4 — F-11-120 (и во всех сферах): предупреждение `[mock-db] обращение к базе вне request()`
На `/biz/network/goods/stock` (и, возможно, шире, но целенаправленно проверял только этот маршрут) в консоли два предупреждения при каждой загрузке:
```
[mock-db] обращение к базе вне request() — оберните в request(() => …) внутри src/api/<раздел>.ts
  at readCore … at networkBusinesses (…)
  at readArea … at getNetworkGoodsStock (…)
```
Это внутренний guardrail мок-БД, не пользовательский баг (страница работает), но по правилам CONVENTIONS такие обращения должны быть обёрнуты в `request()`. Собирателю раздела стоит поправить `src/api/network.ts` (функции `networkBusinesses` и `getNetworkGoodsStock`).
- Отчёт: `qa/measure/network/shots-b03/report.json`, страница `/biz/network/goods/stock`

## hy (армянский)

Проверено по правилу задания: только отсутствие сырых ключей и наличие настоящего шрифта, когда есть армянский текст.
