## Замечено, но не дефект

При первом прогоне сценария `/biz/network/services/subdivisions` (owner/ru/desktop, холодный компилят
дев-сервера — страница грузилась 15.8 с) один раз словился `pageerror`: «Hydration failed because the
server rendered HTML didn't match the client» + консольная ошибка «Can't perform a React state update on a
component that hasn't mounted yet». Перепроверил **4 раза подряд** тем же маршрутом/персоной/языком/
устройством (`b01-m1-recheck2.json` + 3 одиночных запуска `measure.mjs --routes`) — все 4 раза 0 ошибок
консоли, 0 `pageerror`, загрузка 2.6 с. Не воспроизвелось повторно ни разу → похоже на разовый артефакт
первой (холодной, ещё не скомпилированной Turbopack-ом) загрузки маршрута дев-сервером, а не на настоящий
баг рендера; не завожу как дефект без повторяемости, но фиксирую на случай, если у кого-то повторится.

Также по-прежнему видно (не дефект `network`, тот же общий инфраструктурный шум, что и в m0):
`[mock-db] не удалось сохранить в localStorage QuotaExceededError…` на нескольких страницах — переполненная
общая мок-БД от параллельных прогонов других разделов, не код `network`.
