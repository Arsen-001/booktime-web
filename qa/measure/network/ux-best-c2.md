## 1. «Задано для всей сети» — объяснение и путь, а не серые поля (minor, Р17)
- **У них [видел]:** Altegio: сетевая товарная категория в филиале открывается только на чтение — поля серые, кнопок нет, ни слова
  почему (`c-99-goods-network-category-readonly.jpg`).
- **Сделать:** над такими полями — полоса «Это задано для всей сети. Изменить может владелец сети · [Открыть в сети]». Если у человека
  нет прав на сеть — «Попросите владельца сети: Нарине А.».

## 2. У бизнеса с одним филиалом слоя «сеть» не видно (minor)
- **У них [видел]:** Altegio: у одиночного кабинета типы карт, акции и абонементы живут в меню «Сеть Arsen Knyazyan → Лояльность», и
  в заголовке кабинета — «Сеть …» (`c-09-promo-step1.jpg`, `c-09-promo-step5.jpg`).
- **Сделать:** пока филиал один, слова «сеть» и выбора филиала нет нигде. Появляются, когда добавлен второй филиал.

## 3. «Где действует» — все филиалы выбраны заранее, с числом (minor, Р6)
- **У них [видел]:** Altegio, последний шаг акции: «В каких локациях будет действовать акция» — пустой чекбокс у единственной
  локации; без галочки акция не работает нигде (`c-09-promo-step5.jpg`).
- **Сделать:** по умолчанию «Во всех филиалах (3)», раскрытие — чекбоксы. Если не выбран ни один — кнопка сохранения неактивна с
  подсказкой «Выберите хотя бы один филиал».
