## Дефекты

1. **major — F-11-102, мутный заголовок.** `/biz/network/staff/migration`: секция со списком сотрудников филиала,
   ещё не сетевых (с кнопками «Перенести всех» / «Перенести выбранных»), подписана как «Сотрудники сети»
   (`t("staff.title")` переиспользован не по смыслу — см. `src/areas/network/StaffMigrationScreen.tsx:154`,
   `messages/ru/network.json` `staff.title`). Пользователь может решить, что переносит сотрудников ИЗ сети,
   хотя переносит их В сеть. Нужен отдельный ключ («Сотрудники филиала: не в сети» — в духе спеки).
2. **major — F-11-082/083/084/099/107, архитектурный пробел.** Локальная сторона «запрета» (цена/описание сетевой
   услуги только для чтения в филиале; карточка сетевого сотрудника только для чтения) физически нечем показать:
   host-экраны `serviceCard`/`staffCard` в других разделах либо заглушки, либо не принимают `network` как
   вкладчика в `src/extensions/pairs.ts`. Сетевая часть (переключатели, сохранение флагов) работает; ⚠️ когда
   `services`/`staff` достроят карточки, `network` нужно будет зарегистрировать вкладчиком в `pairs.ts`, иначе
   переключатели в сетевой форме будут «сохраняться в никуда» с точки зрения пользователя филиала.
3. **minor — F-11-087, телефон.** Таблица «Миграция услуг» на 390px обрезает колонки филиалов без всякого
   намёка на горизонтальную прокрутку (нет fade-градиента по правому краю). Прокрутка технически работает
   (`overflow-x-auto`), но её не видно.
