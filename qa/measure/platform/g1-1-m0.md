## Дефекты, найденные в этом круге (новые, не были в `qa/gaps/platform-*.md`)

### 1. `major` — «Без проверки» показывает контент, загруженный бизнесом (не только шаблон/визит)

- **Что видно**: `/platform/moderation` → вкладка «Без проверки» → 3 строки, у каждой
  `Источник: Загрузил бизнес`. Пример: «Фото — Atam Dental», «Диплом — Гор Мартиросян».
- **Почему это противоречит F-00-169**: правило («сторис из шаблона и одобренных фото появляется
  без очереди проверки») подразумевает, что БЕЗ проверки проходит только `source: 'template' /
  'visit' / 'reuse'`, а не обычная загрузка бизнесом. Здесь источник явно «Загрузил бизнес».
- **Где в коде**: `src/mock/slices/platform.ts`, генератор очереди модерации (~строка 113–116):
  `status` берётся из массива `statuses[(bi * 3 + k) % statuses.length]` (включает `'auto'`),
  а `source` — из отдельной, никак не связанной формулы `kind === 'story' && k === 2 ? 'template' :
  'user'`. Из-за рассинхрона индексов на части бизнесов совпадает `status: 'auto'` + `source: 'user'`
  — данные сида сами нарушают собственное правило платформы.
- **Снимок**: `qa/measure/platform/g1-1-mod2/platform-moderation__platform-nails-ru-light-desktop__auto.png`

### 2. `minor` — подпись поля источника в карточке бизнеса всегда «Сам зарегистрировался:», даже когда источник другой

- **Что видно**: `/platform/businesses` → клик по любому бизнесу → вкладка «Сведения» → первая строка
  всегда начинается с `Сам зарегистрировался: …`, даже у бизнесов, подключённых на визите. У
  `Kaytsak Barbershop` (подключён на визите) буквально написано «Сам зарегистрировался: Подключили на
  визите» — само предложение противоречит себе.
- **Где в коде**: `src/areas/platform/BusinessesScreen.tsx:112` —
  `<p>{t('businesses.source.self')}: {...}</p>` — метка подписи жёстко взята из значения `self`
  вместо `t('businesses.sourceLabel')` (эта строка уже есть и используется в колонке таблицы на
  строке 38 того же файла).
- **Снимки**: `qa/measure/platform/g1-1-biz-export/…01-detail.png` (Nuri — совпадение маскирует баг),
  `qa/measure/platform/g1-1-biz-export2/…01-detail.png` (Kaytsak — видно чётко).

### 3. `minor` — тост-напоминание перекрывает карточку визита на телефоне

- **Что видно**: `/platform/visits` на 390×844 — при заходе на экран всплывающий тост «Сегодня
  перезвонить: 1» появляется поверх второй строки списка и на снимке частично закрывает её поля
  «Район»/«Перезвонить» у следующего визита. Тост исчезает сам через несколько секунд, но в момент
  снимка/первого взгляда мешает читать список.
- **Снимок**: `qa/measure/platform/shots-g1-1-m0/platform-visits__platform-nails-ru-light-phone.png`
