## Права (чужая персона)

Пробовал сравнить owner vs master на `/biz/records` — вывод неоднозначный из-за архитектуры измерения:
`measure.mjs` открывает каждую комбинацию персона×устройство в **новом контексте браузера**, то есть
localStorage (мок-БД) не переживает между прогонами разных персон/комбинаций — увидеть у master ту же
удалённую запись Ани Саргсян, что видел owner, я не смог, т.к. это два независимых сеанса с одинаковыми
исходными данными. **Не смог проверить «чужая персона не видит»** в этом заходе — нужен один сценарий
(один JSON-объект, не массив) с явным переключением персоны внутри одной сессии, либо API для предзаполнения
БД перед замером. Записал как открытый пункт, не как «проверено».
