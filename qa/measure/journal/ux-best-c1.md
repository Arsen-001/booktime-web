## 1. Окно записи: клиент, услуга и время — на одном экране, без вкладок (block для F-00-004)
- **У них [видел]:** Altegio открывает окно записи **тремя колонками сразу**: слева дата/время/длительность, в центре поиск по
  услугам (вкладки «Услуги / Товары», «Все услуги»), справа клиент — имя, телефон «+374», email (`01-journal-new-record.jpg`).
  Всё главное видно без переключений; кнопка «Сохранить пустую запись» меняет текст, когда что-то выбрано.
- **У нас:** окно переделано под Altegio, но **разложено по вкладкам** «Запись · Клиент · Оплата · Лояльность · Расходники ·
  Ресурсы · Уведомления · Источник» (на 1440 обрезано на «Уве…»). На первой вкладке сверху — специалист, место работы, дата,
  начало/конец/длительность, перерыв, комментарий, «Расширенные поля», 8 статусов, и только **под сгибом** — «Частые услуги
  мастера» чипами (хорошо, но их не видно без прокрутки). **Клиента на первой вкладке нет**: он на вкладке «Клиент», где сейчас
  заглушка «Здесь будет вклад раздела «Клиенты и CRM»» (слот ещё не заполнен разделом clients — это не дефект сборки, но место
  выбрано неудачно). Путь «клиент + услуга» = вкладка «Клиент» → найти → «Запись» → прокрутить → услуга → сохранить: 6+ нажатий
  против цели 3. Кнопка внизу «Сохранить пустую запись» зовёт сохранить пустое (`*new-window.png`, `*new-window-phone.png`,
  `new-window-client-tab.png`).
- **Сделать:** первый экран окна = ровно то, что нужно для записи:
  1. **Клиент** — одно поле-поиск (телефон или имя), под ним сразу 5 «недавних» клиентов этого мастера чипами (F-00-060
     «клиент — из недавних»); нет совпадения → «+ Новый: +374 91 234 567» и поле имени.
  2. **Услуга** — поиск + 4–6 частых услуг этого мастера чипами «Маникюр · 45 мин · 5 000 ֏»; у выбранного клиента — его
     прошлая услуга уже выбрана (F-00-060 «услуга — подставлена прошлая»).
  3. **Когда** одной строкой: «пт, 25 сент · 15:00–16:00 · Ани Саргсян ✎» (правка раскрывает дату/время/мастера/место).
  Вкладки Оплата/Лояльность/Расходники/Ресурсы — ниже, в раскрывающемся «Ещё» или только у открытой (сохранённой) записи.
  Поле клиента — вклад раздела clients (`src/areas/clients/extensions/BookingWindow.tsx`), поэтому хосту нужно дать ему место
  **над** блоком «Когда», а не отдельную вкладку; если точки расширения для этого нет — просьба в `qa/requests/journal.md`.
  8 статусов у новой записи не показывать (по умолчанию «Записан»).
  Кнопка — «Записать» (активна, когда есть клиент или галочка «Без клиента»), тост «Лилит записана на пт, 15:00 · Отменить».

## 4. Свободный промежуток в сетке — видимый «+», а не угадывание клика (major)
- **У них [вывод]:** в Altegio запись создаётся кликом по пустой ячейке (`CYCLE-02`, `details/01-journal.md`); подсказки при
  наведении на снимках не видно.
- **У нас:** клик по пустой ячейке открывает окно (`journal-ux-r1/d03-cell-click.png`), но ничего не подсказывает, что так можно;
  на телефоне пустая ячейка ничем не отличается от нерабочей, кроме оттенка серого.
- **Сделать:** при наведении (десктоп) пустая ячейка показывает «+ 15:00» тонким текстом; на телефоне первый показ журнала —

  нерабочее — штриховка (не только оттенок), F-00-051.
