## 🔴 Блокер: дев-сервер лежал весь прогон (не моя правка)

`bash scripts/ensure-dev.sh` — сервер на 3710 уже был запущен, но отвечал 500 на **каждый** маршрут, включая
`/dev/health`. Причина видна в `.dev.log`: чужая незавершённая правка в разделе **client** —
`src/areas/client/bookings/BookingDetailScreen.tsx` импортирует `getBookingPaymentBreakdown` из `@/api/client`,
а этой функции там нет (`The export getBookingPaymentBreakdown was not found in module .../src/api/client.ts`).
Это ломает сборку модуля для ВСЕГО приложения (Next.js падает на компиляции), не только для `/bookings/*`.

Ждал восстановления ~4 минуты (проверка `/dev/health` каждые 15 с, 8+ попыток) — не ожил. Правило раздела
запрещает второй `next dev`, чужие файлы не трогаю, работающий сервер не убиваю. Поэтому пункты «Готово, когда»
из ТЗ **не пройдены действием в браузере** ни для одной из 29 функций пачки g1-3 — оценка ниже сделана
статическим анализом кода (`grep`/`Read`), это НЕ замена браузерной проверке персон/языков/вьюпортов, требуемой
заданием, и результаты по умолчанию отмечены ❌/🔲, а не ✅, там, где нужен был реальный клик.
