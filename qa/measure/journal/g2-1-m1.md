## Главная находка (BLOCK, подтверждено действием) — база НЕ сохраняется вообще, ни разу

Прямая проверка: свежий браузерный контекст → `/biz/journal` → `localStorage.getItem('bp-mock-db')`
= `null` **ещё до каких-либо моих действий** (сидовые данные уже превышают квоту при первом `flush()`).
Затем — реальное действие: открыл запись «Ани Саргсян», нажал «Удалить» (`data-f="F-01-118"`,
запись пропала с сетки, 17→16 блоков), подождал — `localStorage.getItem('bp-mock-db')` **снова `null`**.
То есть смена состояния существует только в памяти вкладки; при полной навигации (`page.goto` на
`/biz/records`, обычный переход пользователя, не перезагрузка F5) изменение **исчезает без следа** —
проверено дважды отдельными прогонами.

Это фундамент (`src/mock/db.ts`), уже отправлено соседям как просьба (`qa/requests/journal.md`,
«g2-1 fix1», 25.09) — **не почин ено с прошлого захода**. Для раздела `journal` последствие прямое и
затрагивает почти весь список задания: «сохранение после перезагрузки» как критерий «Готово, когда»
**физически не может выполниться** ни у одной функции журнала, пока это не почин ено — не только
F-01-033 (совместная работа), а вообще у всего (открытая панель листа ожидания, статус визита,
удаление/восстановление, комментарий — всё живёт только до навигации). Отмечаю как BLOCK для замера
(не как дефект кода `journal` — код раздела пишет корректно, `coreTx.update(...deletedAt...)` в
`src/api/journal.ts` отрабатывает, проблема ниже, в персистентности).

## Другие находки за этот заход

- **`@/ui/Select`** (фундамент, не `journal`) рендерит частично через нативный `<select>`/`<option>` —
  Playwright-локатор `text=...` резолвился в `<option value="materials">…</option>` внутри формы
  «Новый платёж». Если это действительно голый `<select>` без кастомного UI поверх, это противоречит
  правилу §0.3 CONVENTIONS.md («Запрещено … `<select>`»). Не мой путь (`src/ui/`) — не завожу как
  дефект журнала, но стоит проверить архитектурному измерителю (`arch-*`).
- Console/pageerror за весь заход (десятки навигаций, кликов, удалений) — **0** ошибок. Инструмент и
  живые прогоны согласуются.
- Все известные из m0 наблюдения (кластер групповых событий как вероятно не построенный, BLOCK по
  localStorage) в этом заходе переведены из «инференс» в «подтверждено прямым действием».
