# journal · сквозные сценарии e2e-q3

Дата: 2026-09-25. Цепочки C01, C04, C07–C09, C12, C14, C24–C26 (`qa/e2e/scenarios.md`, итог `qa/e2e/report-q3.md`). Код раздела не правил.
Повторить: `node qa/e2e/run.mjs --only C04,C07,C08,C09,C12,C14,C26`.

**Починено с q2:** журнал прячет номер клиента от мастера и от администратора без права `clients.phones` (C20.S1, S4 ✅);
в окне записи виден источник «Приложение · Автор: Клиент» (C01.S10 теперь падает только на оттенке). «Повторение записи»,
«Пришёл», «Отменил мастер» работают из окна (C08.S1, C24.S4, C25.S3 ✅).

## major

1. **День без графика прячет записи клиентов** (C26.S6, новое). Индивидуал поставил субботу «Нерабочим днём»; окно правки
   графика честно предупредило «На эти даты уже есть 3 записи — они не будут удалены или перенесены», но журнал на этот день
   показывает только «Расписание не установлено» — ни одной из трёх записей (снимок `qa/shots/e2e/C26-S6-fail.png`).
   Клиенты придут, мастер их не видит. Как: записи рисовать всегда, день без графика — серым фоном с пометкой «вне графика».
2. **Отменённая клиентом запись стоит в сетке как активная** (C04.S6, повтор): «10:00–10:45 · Маникюр классический · Ани М.».
   Как: `occupiesTime`/`isCancelled` из `@/domain/rules`, отменённые — приглушённо или в «Отменённых».
3. **Сеть: журнал не слушает переключатель филиалов** (C09.S2–S3, повтор): «Все филиалы» — только Нор-Норк; выбран
   Шенгавит — ни Гора, ни Арпи. Как: `activeLocationIds` из `useCurrent()`.
4. **Домашняя запись мастера видна админу салона как обычная** (C07.S4, повтор): «11:00–11:45 · Маникюр классический · Ани М.».
   Как: `busyForViewer` ядра — «занято · дома» без имени и услуги.
5. **Серия из «Повторения записи» теряет клиента приложения и не помечена** (C08.S2–S3, повтор): 0 из 3 повторов с `appUserId`,
   в окне записи повтора нет «часть серии». Как: одна команда серии (schedule `createSeries` поверх `placeBooking`).
6. **Отметка мастера «занято» не видна в журнале** (C14.S4, повтор) — админ записывает клиента на закрытое время.
7. **Полный номер постоянного клиента → «Новый клиент — будет добавлен в базу»** (C12.S2, повтор), пока не нажмёшь подсказку —
   легко создать дубль. Как: точное совпадение номера (`findClientByPhone`) подставляет клиента сразу.
