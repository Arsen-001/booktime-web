# Пустые состояния — /biz/journal (empty-d1)

Замер d1 (хранитель демо, 25.09.2026): пустые персоны `?demo=owner&empty=1` («Новый салон — пусто») и `?demo=individual&empty=1` («Новый мастер — пусто») — бизнес без услуг, мастеров, клиентов, записей, графиков. Повторить: `node scripts/measure.mjs --persona owner-empty,individual-empty --routes <адрес> --device phone,desktop --full`. Консоль: 0 ошибок, 0 предупреждений, 0 ответов ≥ 400.

EmptyState есть («Расписание не установлено», кнопки «Настроить график работы» / «Добавить сотрудников в день»), но:

## 1. Первое действие не то, что нужно пустому бизнесу — major
- У бизнеса нет ни услуг, ни мастеров; пустой экран зовёт настраивать график. Нужен путь новичка по порядку:
  «Добавьте услуги → мастеров → график» (или одна кнопка на следующий недостающий шаг), а не график первым.
- Главная кнопка «Новая запись» активна — в пустом бизнесе записать некого и не на что. Показывать её вторичной или с подсказкой,
  почему пока нельзя (CONVENTIONS §0: «недоступное — с подсказкой почему»).
- ✅ исправлено (journal g2-3-fix1): `EmptyDayState.tsx` теперь принимает `hasServices`/`hasStaff` и до графика
  зовёт по порядку — «Сначала добавьте услуги» → «Добавьте сотрудников» → «Настроить график работы» (последнее
  только когда услуги и сотрудники уже есть). Кнопка «Новая запись» в шапке (десктоп, обычная и DropdownMenu с
  пакетом) теперь `disabled` с `Tooltip`, поясняющим, чего не хватает, пока `staffWithSchedule` пуст или услуг
  нет (`canCreateBooking` в `JournalScreen.tsx`); Fab на телефоне и так была скрыта в этом случае.

## 2. Панель фильтров над пустотой — major
- Шесть выпадающих («День», «По должностям», «Все должности», «Статусы», «15 минут», «⋯») при пустом журнале — шум; на телефоне
  они занимают весь первый экран, пустое состояние начинается ниже середины. Прятать фильтры, пока нечего фильтровать.
- Последний выпадающий показывает «⋯»: нет ключей `journal.toolbar.breakMode.longest` / `journal.toolbar.breakMode.sum` (ru) —
  14 сообщений `[i18n:missing]` на 4 страницах, сырой ключ в [data-f=F-01-133].
- ✅ исправлено (journal g2-2 fix1): фильтры на телефоне теперь одной кнопкой «Фильтры» (Sheet), над
  пустым состоянием только «Сегодня ‹ ›» + дата + кнопка — переснял `owner-empty`, EmptyState начинается
  сразу под шапкой, не ниже середины. Ключи `breakMode.longest/sum` в `messages/{en,ru}/journal.json` на
  месте — 0 сырых ключей и 0 `[i18n:missing]` на повторном замере, похоже на более раннюю правку, чем эта
  пачка; сообщение стало неактуальным.

## 3. Боковая колонка на десктопе — minor
- В колонке под календарём — «Продажа товара», «Новый платёж», «Список услуг», «Каталог товаров»: для бизнеса без товаров и услуг
  это пустые ходы. Достаточно календаря.
