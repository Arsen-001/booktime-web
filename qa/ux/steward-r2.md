# Хранитель дизайна · проход 2 (25.09.2026)

Цель та же: всё, что собирают разделы, выглядит современно и дружелюбно — **через общие компоненты и каркасы**,
без правки разделов. Публичные API не менялись (имена, пропсы, экспорты прежние). Цвета в `tokens.css` не тронуты.
Новое — только внутреннее: хук `src/ui/hooks/useScrollEdges.ts`, утилиты `fade-x-*` в `polish.css`,
атрибут `data-icon-button` у IconButton (по нему PageHeader и FilterBar отличают квадратные кнопки).

## Что было видно на снимках «до»
- Телефон: кнопки шапки страницы — «лесенка» разной ширины, прижатая влево (`/biz/clients`: «Операции с Excel» и «Добавить клиента»).
- Телефон, кабинет: в верхней полосе поиска не было вовсе; знак «A» — такой же круг, как аватар пользователя справа.
- Десктоп, меню кабинета: если активный пункт внизу (Услуги, Сотрудники, Ресурсы) — он за краем меню, его не видно.
- Таблицы: имена клиентов ломались на две строки («Ани / Мелкумян»), строка 66 px вместо 52; пустая таблица — серая строчка «Нет данных».
- StatCard: в узкой карточке подпись теснилась с иконкой, «+12,5% к прошлому / периоду» рвалось посреди фразы.
- Вкладки на телефоне обрезались на полуслове («Отмен»), и было не понять, что их можно листать.
- FilterBar на телефоне: кнопка «Фильтры: 1» сжимала поиск до «Имя ил…».
- Заглушка «Раздел строится» говорила языком разработчика: «ТЗ», «Наши решения», «/biz/services» — крупно, в первой строке.
- Рамки у outline-кнопок такие же тёмные, как у полей ввода: экран из пяти outline-кнопок и чипов выглядел шумно.
- Клиентское приложение на десктопе: верхняя полоса (max-w-6xl) и колонка (max-w-4xl) не совпадали по краю — логотип «висел» левее содержимого.

## Что изменено

### Каркасы (src/shell)
- **Верхняя полоса кабинета на телефоне — поиск.** Кнопка-лупа рядом с колокольчиком открывает шторку снизу:
  крупное поле (`SearchInput`, свой крестик очистки) + кнопка «Поиск» под большим пальцем, Enter тоже ищет (`TopSearch.tsx`).
- **Меню кабинета/панели прокручивается к активному пункту** — и в левом меню десктопа, и в выезжающем меню телефона.
  Двигается только прокрутка меню, страница не прыгает (`NavList.tsx`).
- **Знак продукта** — скруглённый квадрат с мягким градиентом primary → primary-hover и тонким внутренним бликом: больше не
  путается с круглым аватаром пользователя (`Logo.tsx`).
- **Клиентское приложение:** верхняя полоса и колонка содержимого — одна ширина `max-w-5xl`, край логотипа совпадает с краем контента
  (`ClientShell.tsx`, `ClientTopBar.tsx`).
- **Заглушка раздела** — дружелюбное пустое состояние: иконка на «подушке», «Раздел строится», одна фраза; служебные сведения
  для команды ушли вниз, в приглушённую полосу в две колонки (`AreaPlaceholder.tsx`, только существующие ключи).

### Компоненты (src/ui)
- **PageHeader:** на телефоне кнопки действий тянутся на всю строку — ровный столбец под большой палец; квадратные кнопки-иконки
  остаются квадратными. С `sm` — как было, справа от заголовка.
- **Table:** первая колонка («кто/что») — полужирнее и не уже 11rem, имена больше не ломаются; числа справа — `tabular-nums`
  (и в карточках телефона); пустая таблица по умолчанию — компактный `EmptyState` с иконкой.
- **StatCard:** иконка компактнее (32 px), подпись с воздухом, изменение — пилюлей на мягком фоне (знак + иконка + цвет),
  «к прошлому периоду» не рвётся посреди фразы, подвал прижат книзу — в ряду карточек значения стоят ровно.
  StatCard внутри ссылки (как на `/platform`) приподнимается при наведении — видно, что это переход.
- **Tabs:** если вкладки не влезают — край мягко затухает (видно, что полоса листается); выбранная вкладка всегда видна в полосе
  (полоса докручивается сама, страница — нет).
- **FilterBar на телефоне:** рядом с поиском — квадратная кнопка фильтров с кружком-счётчиком, поиск занимает всю ширину;
  кнопки действий ниже — на всю строку.
- **ChartCard:** «Нет данных за период» — с иконкой графика на пунктирной подложке; скругление как у остальных карточек (xl).
- **Button/IconButton outline:** рамка мягче (`border-strong/55`), при наведении — полная. Поля ввода не трогал: у них рамка
  остаётся контрастной ≥ 3:1 (поле узнают только по рамке, кнопку — по подписи).

### Стили (src/styles/polish.css)
- Утилиты `fade-x-start / fade-x-end / fade-x-both` — затухание края прокручиваемой полосы (маска работает только прозрачностью,
  цвета в ней нет).
- Спрятан системный синий крестик `input[type=search]` (Chrome/Safari) — у SearchInput свой.

## Разделам на заметку (чужие пути — не правил)
- **journal** (`JournalScreen.tsx:186`): кнопки шапки обёрнуты в свой `<div>` — поэтому на телефоне «Новая запись» не тянется на
  всю строку. Передайте кнопки фрагментом `<>…</>` — PageHeader выровняет сам. На десктопе по-прежнему 63 цели меньше 40 px.
- **clients:** поиск из верхней полосы уводит на `/biz/clients?q=Ани`, но, судя по снимку, список параметр `q` не подхватывает (не проверял код раздела; снимок
  `after-shell/…search-result.png`: поле поиска пустое, список полный).
- **platform** (`OverviewScreen.tsx:79`): график «Записи через приложение» собран вручную из `div` — при нуле записей пустая рамка
  с датами. Стоит взять `ChartCard` с `empty` (там теперь понятное «Нет данных за период» с иконкой). Плашка «Сегодня нужно
  перезвонить» — тоже своя; для таких подсказок есть `HintBanner` в `src/ui/onboarding`.
- **client:** кружки сторис на главной показывают букву «с» вместо фото/имени; `SlotPicker.tsx:76` — `text-white`.
- **online** (`/biz/online`): подзаголовки групп КАПСОМ («ИНФОРМАЦИЯ О КОМПАНИИ») — против §0 «без капса».
