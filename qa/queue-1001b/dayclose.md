# «День закрыт» — уведомление владельцу в колокольчик (01.10.2026)

Решение владельца 01.10.2026. Сделано в режимах mock и api одинаково.

## Как работает
- Администратор закрывает кассовую смену («Закрыть день» в «Итогах дня» журнала или «Кассовая смена» финансов — это одно и то же
  закрытие) → снимок итога дня: **выручка** (= «Оказано услуг», как строка «Выручка» в «Итогах дня»), **наличные** за день
  (как «Деньги в кассе → Наличные»), **излишек/недостача** (сумма по сменам, закрытым в этот день; 0 — не показывается), кто закрыл.
- Получатели: владельцы бизнеса — роль «Владелец», роль-шаблон «Владелец», `Business.ownerStaffId`, владелец сети; **кроме закрывшего**
  (на сервере — и по его входу). Нет получателей (закрыл сам владелец-одиночка) — ничего не пишется.
- Колокольчик: «День закрыт · Лилит» / «Выручка 148 500 ֏ · наличные 61 500 ֏ · недостача 500 ֏», иконка кошелька, красная при недостаче;
  строка с цифрами переносится, чтобы недостача не обрезалась. Та же строка — в «Центре уведомлений». Нажатие → `/biz/journal?date=<день>&workday=dayClose`
  — журнал открывает «Итоги дня» за эту дату (параметр сразу убирается из адреса, повторное нажатие снова откроет).
- Дубли: один снимок на бизнес и день. Повторное закрытие/переоткрытие с теми же цифрами — ничего не меняется (та же строка, прочитанное остаётся
  прочитанным). Цифры изменились — снимок заменяется, строка снова «не прочитана» (одна, не две).
- id строки свой у каждого получателя (`dc_<день>_<хэш>`, ≤ 32 символов) — прочитанное у одного владельца не гасит строку у другого,
  хотя «прочитано» в ленте по-прежнему общее на бизнес.
- Выключение: «Уведомления → Каналы отправки → Уведомления в Web-версии → **Закрытие дня**» (рядом с «Операции с записями», по умолчанию
  включено; старые сохранённые настройки без поля — тоже включено). Лента теперь сама учитывает обе галочки (мок и сервер): колокольчик «молчит»
  только когда выключены обе.

## Решил сам (assumed)
- «Выручка» = «Оказано услуг» (визиты «Пришёл» дня) — та же цифра, что в «Итогах дня» под заголовком «Выручка», куда ведёт уведомление.
- Расхождение — за день (сумма по всем сменам, закрытым в этот день), а не только последней смены: иначе переоткрытие «теряло» бы утреннюю недостачу.
- Заголовок по-русски без рода («День закрыт · Лилит») — пола у сотрудника в данных нет; en «Лилит closed the day», hy «Օրը փակված է · …».
- Галочка — на бизнес, в «Уведомления в Web-версии», где выключаются остальные строки колокольчика (личных настроек колокольчика у сотрудника нет;
  таблица «Тип уведомления × каналы» сотрудника — про SMS/Email/пуш, колокольчик не задевает). Только колокольчик — без пуша/SMS.
- Хранится до 30 последних дней на бизнес.
