# 08 · Открытые вопросы бэкенда

Вопросы, без ответа на которые серверное правило нельзя записать окончательно. Номера «00 №…» — пункты
раздела «Открыто (ждёт решения)» в `00-our-decisions.md`; остальные — новые, всплыли при переносе на
сервер. У каждого — моё предложение, чтобы можно было ответить «да» или «нет».

---
