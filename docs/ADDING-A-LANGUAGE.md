# Как добавить язык

Сейчас включены **ru** (основной) и **en** — решение пользователя 25.09.2026. Армянский (hy) поддержан кодом
(шрифт Noto Sans Armenian, форматы дат dayjs `hy-am`), но выключен.

1. Если языка нет в `SUPPORTED_LOCALES` (`src/i18n/config.ts`) — добавить код туда, локаль dayjs в `src/i18n/useFormat.ts`,
   `LocaleCode` в `src/domain/core.ts`; проверить, что шрифт в `src/app/layout.tsx` рисует буквы языка.
2. Создать папку `messages/<код>/` — скопировать `messages/en/*.json` (20 файлов: common, ui и по одному на раздел) и
   перевести значения; ключи не менять. Непереведённый ключ сам возьмётся из ru и появится в консоли `[i18n:fallback-ru]`.
3. Добавить код в `LOCALES` — язык появится в переключателе.
4. Проверить: `node scripts/measure.mjs` по главным адресам с `?lang=<код>` — нет сырых ключей, текст не вылезает.

Правила для разделов: все тексты только через `useT(ns)`, никаких строк в JSX; даты/деньги/числа — только через
`useFormat`; склонения — через ICU (`{count, plural, one {…} few {…} many {…} other {…}}`), не склейкой строк; длина
текста может вырасти на 30% — вёрстка не должна ломаться; порядок слов не собирать из кусков.
