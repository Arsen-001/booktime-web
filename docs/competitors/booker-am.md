# Конкурент: Booker.am — разбор на 03.10.2026

Источники — только открытые: сайт booker.am, его публичный API (тот же, что вызывает сайт без входа), файлы перевода сайта,
App Store / Google Play, staff.am, Instagram. На Booker не регистрировались, ни с кем не связывались.

Сайт booker.am — одностраничное приложение на Vue (Laravel + Vite, внутреннее имя «zelo», приложения на Capacitor). Без JavaScript
страница показывает только «Չհաջողվեց բացել Booker-ը» («Не удалось открыть Booker»), поэтому тексты взяты из файлов перевода,
которые грузит сам сайт:
- **[RU-A]** публичная часть: https://booker.am/build/assets/ru-CP-FOPbE.js
- **[RU-B]** кабинет бизнеса: https://booker.am/build/assets/ru-CxvMpyOJ.js

(имена файлов меняются при каждой выкладке; эти действовали 03.10.2026)

## 1. Что это
**Для клиентов** (https://booker.am, [RU-A]):
- Каталог/маркетплейс салонов красоты и здоровья, только Армения. Поиск по месту, району, дате и времени; категории: парикмахерские,
  ногти, макияж, салоны красоты, барбершопы, брови/ресницы, medspa.
- Онлайн-запись по реальной занятости; «Booker AI» — поиск и подсказки на естественном языке, голосовой ввод ([RU-A]).
- Отзывы только после записи («Оценка основана на отзывах… только при написании отзыва» — [RU-A]); избранное/подписка на салон, чат с салоном,
  пакеты посещений и подарочные карты — **без онлайн-оплаты** («Онлайн-оплаты нет. После заявки компания свяжется с вами» — [RU-A]).
- Вход: телефон + SMS-код, Google, Facebook ([RU-A]). Telegram и WhatsApp для входа не упоминаются нигде (0 вхождений «Telegram» в обоих файлах).
- Вакансии салонов (https://booker.am/jobs), публичные страницы мастеров `/specialists/...` (29 в sitemap).
- Клиентского приложения нет: в подвале «Клиентское приложение — Скоро» ([RU-A]); Play по `am.booker.client` — 404.

**Для бизнеса** ([RU-A] блок «Для бизнеса», [RU-B] кабинет):
- Журнал/календарь команды и по мастерам, редактор записи, статусы (подтверждена/завершена/неявка/отмена).
- Клиентская база: история, траты, заметки, импорт CSV/XLSX (10 000+ строк в фоне), сегмент «в зоне риска», удержание.
- Финансы: касса, смены, приходы/расходы, наличные/безнал, раздельная оплата, чаевые мастеру.
- Зарплаты: процент, оклад, почасовая, оклад+процент, расчётные периоды и листы, бонусы/удержания.
- Склад: товары, остатки, приход, поставщики, перемещение между филиалами, инвентаризация, списание материалов на визит.
- Подарочные карты, пакеты/абонементы, «Лояльность» в карточке клиента, автоматизации (напоминание, день рождения, вернуть неактивного,
  наградить лояльного, лист ожидания, «спасибо за чаевые»).
- Аналитика: записи, неявки, выручка, средний чек, рейтинги специалистов и локаций.
- Филиалы (локации), роли доступа: владелец, менеджер, ресепшн, специалист.
- Встроенный чат клиент–салон; AI-ассистент «Мэри»/ресепшен для звонков и чатов (WhatsApp, Instagram, Messenger) — платное дополнение,
  оплата из «AI-кошелька» за каждый ответ; Instagram пока «ждёт одобрения приложения Meta» ([RU-B]).
- Фискализация HDM (касса) — платное дополнение ([RU-B]).
- Автоперевод названий услуг HY/EN/RU ИИ ([RU-B]); тёмная тема кабинета.

## 2. Модель денег
- Публичный API тарифов https://booker.am/api/pricing-plans (03.10.2026):
  `{"currency":"AMD","independent":{"flat_monthly_amd":1400,...},"team":{"per_bookable_specialist_monthly_amd":700,"minimum_billable_specialists":2,"minimum_monthly_amd":1400}}`
  → **частный мастер 1 400 ֏/мес; команда 700 ֏ за участника/мес, минимум 2 (1 400 ֏)**. Страница: https://booker.am/for-business/pricing
  (цены подгружаются из API; при сбое — «Не удалось загрузить цены»). Это очень низкая цена — возможно, промо-уровень; другого прайса не нашли.
- **2 месяца бесплатно без обязательств** («businessPlanFreeUntil», «Старт бесплатный на 2 месяца» — [RU-A], [RU-B]); бесплатная настройка поддержкой; демо-салон.
- Комиссии с записи/оплаты клиента нет: клиент при записи не платит («Оплата не требуется» — [RU-A]). Слово «комиссия» в кабинете — только зарплата мастеров.
- Дополнения: **HDM Fiscal 2 900 AMD/мес за локацию**, 7 дней пробно ([RU-B]); **AI-ассистент** — подписка + пополняемый кошелёк, «каждый ответ списывается с баланса» ([RU-B]); цену не нашли.
- Оплата подписки: AmeriaBank (Visa, Mastercard, ArCa) и iDram, автосписание с сохранённой карты ([RU-B]).
- Признак массовых бесплатных продлений: у 23 из 55 салонов `subscription_ends_at = 2026-12-31` (публичный API салонов, см. п. 7).

## 3. Напоминания клиентам
- Каналы автоматизаций: **email, SMS, WhatsApp** («Каждую автоматизацию можно настроить по… каналу: email, SMS или WhatsApp» — [RU-A]);
  пуш — в бизнес-приложении для команды. В тарифе: «Email, SMS и напоминания в приложении» (https://booker.am/for-business/pricing, [RU-A]).
- WhatsApp подключается **сканированием QR-кода как «связанное устройство»** с телефона салона ([RU-B]) — то есть неофициально, через номер салона, не через WhatsApp Business API (риск блокировки номера).

## 4. Онлайн-оплата и предоплата
- Клиент **онлайн не платит** ни за запись, ни за пакет, ни за подарочную карту ([RU-A]: «Оплата не требуется», «Онлайн-оплаты нет»).
- Предоплата в кабинете — **ручная отметка**: «Сумма предоплаты», «Предоплата не внесена/Оплачено»; у услуги флажок «С предоплатой» — запись помечается
  «ожидает предоплату» ([RU-B]). Есть настройка клиента «Требовать предоплату или данные карты для штрафов за отмену» ([RU-B]) — механизма приёма не видно.
  На маркетплейсе флажок включён у 1 услуги из всех 55 салонов.
- Idram/ArCa/карты — только для оплаты **подписки Booker** (AmeriaBank, iDram) ([RU-B]). Telcell — 0 упоминаний.
